`_dm_context` 保存绑定对象、账号代次与分 P，不能只保存 bvid：同一视频的新绑定不得接收旧绑定结果。
弹幕在取流成功后使用实际 cid 请求，避免与分 P 解析各自选择不同页面。
切 P 时先取消旧媒体请求、清空弹幕与字幕、释放预览，再解析下一 P。

取流期间原直播仍由本体持有；若用户已换房，取消或卸载只解除旧绑定，不停止新播放器、不还原旧房间。
页面请求在正常、异常和取消完成时清除自己的凭据副本。页面销毁会断开其结果和完成回调，
等待 100ms 仍未结束的请求交给应用级对象保活；完成后从集合移除，不保留已销毁 Qt 对象的 Python wrapper。
移交后立即检查完成状态，覆盖 finished 发生在 wait 超时与信号接线之间的竞态。
应用 aboutToQuit 等待尚在网络 I/O 中的请求结束，再允许 Qt 销毁线程；HTTP 仍受既有超时控制，
不使用 terminate，也不承诺弱网下整个进程即时退出。媒体请求仍按原有绑定生命周期收尾。

播放目标单独从本体弹幕格映射排除聊天位置，完整 Tile 集合仍用于绑定生命周期与退出还原。
默认网格目标宽 300px、最少两列；封面高度由宽度决定，不由窗口高度强制分成四行。
图片队列按可见区重新排序；监测只记录数值阶段耗时，每次打开最多十二条。

滚动合并保留当前卡片外观：将原有圆角、封面、时长徽章和进度线绘制预合成一张位图，
缓存签名包括原图、尺寸、DPR、历史进度、徽章、字体与调色板，释放封面时同步清空。
拉取范围仍为可见区邻行，已加载封面在更宽的四行保留带内复用；不扩大实际网络预取范围。
分页采用不可被连续滚轮重启的定时任务，网格每四张让出一次事件循环；删除和追加使用保留分页量的重排路径。
刷新在页头，回顶及状态提示位于滚动区外；复用公共 ActionButton，保留 F5 与既有状态接线。

点播底栏扩展区仍由本体 `TileControls.allocate()` 分配各控件宽度，插件只把已有空白移交给该分配器，
不把整个扩展区宽度直接写给进度条 wrapper。进度条最小宽度包含两个时钟标签和滑杆的实际布局需求；
空间不足由宿主隐藏 wrapper，控件保持可分配资格，拉宽后恢复。

图标由 Qt 圆弧与三角形独立绘制，视觉依据用户截图。hover 参考本地 BewlyCat 的
`src/components/Dock/Dock.vue`：外环固定，中央播放图形按 1 → 1.22 → 0.96 → 1 轻弹。
使用本体的 280/160ms 时长及 emphasized easing，未复制参考仓库的 SVG 路径或组件代码。

## 布局选位与独立设置（2026-11-17）

- `placement_layout.py`：只读宿主布局与 Tile 身份、占用内容，复用本体分隔比例几何引擎；图片仅取缓存／现有封面，不抓取原生视频窗口、不新发网络请求。
- `placement_picker.py`：Qt 对话框拥有布局图和可键盘操作的格子按钮；弹幕格可见但禁选。页面拥有待置入条目，点选时再取新快照，比较空间位置、目标身份与房间标识，变化则要求重选。
- `preferences.py`：默认值与校验；仅通过公开 context.setting／set_setting 读写本插件配置。
- `settings_dialog.py`：默认视图、自动／固定列数、卡片大小、自动连播的展示；取消不写设置，应用后页面重排，播放器绑定不重建。
- 页面拥有设置窗和位置选择窗；隐藏／shutdown 关闭子窗口。刷新按钮持有 QVariantAnimation，1s 线性旋转仅表达加载状态，结束、隐藏或系统关闭动画时停止并复位。
- 自动连播由插件的 EOF 路径协调，默认关闭。结束态只进入一次，延迟派发前复查开关、绑定身份、结束状态及下一项；继续复用原来的先下一 P、再下一视频路径。

空状态标题、说明和按钮组成固定自然高度的居中内容组；按实际可用宽度计算文字高度，测量前释放旧最小高度，避免文字裁切或每次重排累积高度。
卡片以删除图标代替更多图标；复制链接仍在右键菜单。顶部多选入口尺寸不变，删除确认／取消在带顶部分隔线的底栏。

## 状态留存、预览与下一项缓冲（2026-11-17）

- `browse_state.py`：页面拥有单一浏览快照，按视频 key 与局部偏移恢复并扩展分页；账号校验先于筛选。用户主动搜索／筛选／排序会作废待恢复位置。仅通过插件设置持久化公开账号标识及浏览状态。
- `card_preview.py`：每页一个活动悬停预览，复用 `VodPreviewProvider`；进入延迟 450ms、每 700ms 推进帧，鼠标可定位。离开、隐藏、点击、关闭设置或销毁卡片时恢复原封面。退休提供器由应用级 QObject 保活，池任务退出后才销毁，不在关闭页面时等待运行中的网络任务。
- `preferences.py`：`auto_play` 为入格自动播放，默认开；既有 `autoplay` 为结束后连播，默认关。`prefetch_next` 与连播相与。关闭自动播放时宿主启动期间暂时静音，接受暂停后恢复原静音状态；已有播放不因更改开关重建。
- `next_prefetch.py`：每个绑定至多一项，剩余 30 秒内准备下一 P／下一视频。键含账号代次、BV、分 P、画质；失败同键不循环重试。工作线程独占凭据副本，结束清空；取消复用 `request_retirement` 保活回收。
- `warm_media.py`：工作线程限量读取支持 206 Range 的媒体开头（视频 8 MiB＋音频 2 MiB），有效期 120 秒；交接复用本体 HlsProxy 的 session_factory，缓存范围内读取内存，其余范围透传。绑定拥有已激活代理 lease，替换或释放时停止；失败回正常解析，没有另建代理框架或磁盘媒体缓存。

设置参考 BewlyCat 视频卡片的分组、标题／说明和右侧开关层级，以宿主公开 SettingsSurface、SelectControl、ToggleSwitch 实现，长内容在 QScrollArea 中显示、应用／取消固定在底部。
性能结论需要真实软件与 CDN 证据；本机 HTTP Range 和实际宿主代理测试仅验证功能，不作为切换速度改善证据。

## 单窗口导航与平面材质（2026-11-17）

- `page_shell.py`：仅负责浏览器窗口壳、自绘标题栏及嵌入页面的完成信号。顶层窗口由 Page 持有；标题栏调用 Qt 的原生移动／缩放接口，关闭入口仍走原 Page 生命周期。平面背景与本体当前设置的深浅基色对应，以专项测试防止颜色漂移。

### 避让与完成过滤

`OrderAvoidance` 是 OrderList 子对象，单个 QVariantAnimation 持有可见模型行的临时槽位，不改变模型或条目所有权。抓起后以空槽标记源位置，鼠标跨越卡片半区时移动空槽，其余卡片按宿主160ms/easing过渡；中途反向从当前位置继续。绘制、可见图片需求和落点计算读取临时位置，滚动使用同一偏移。取消/离开恢复，放下后才由WatchOrder保存真实顺序；回原位以源行作锚点，避免改变搜索隐藏项的顺序。

### 窗口缩放与滚轮幅度

BrowserWindow在边缘持有八个无焦点ResizeHandle子控件，覆盖外侧8像素及16像素角落，不参与布局；显示、尺寸和窗口状态变化时更新几何及层级。原有父窗口mousePressEvent会被标题栏或子页面吃掉，独立边缘命中区域改由QWindow.startSystemResize处理，不实现另一套手动窗口几何逻辑。最大化/全屏/嵌入时隐藏，尺寸继续由Page原有400ms去抖及关闭保存路径持久化。

### 删除后撤回

单项删除入口直接委托既有RemoveRequest，只有服务器确认成功才从canonical列表移除并记录RemovalUndo。协调器由Page持有，记录最近10秒成功移除的条目、原canonical次序及本地观看顺序，不保存凭据或媒体URL；多选仍串行删除，失败后仅保留已成功部分的撤回。

UndoNotice是Page内的轻量提示，复用主题和StableActionButton，以宿主160ms/easing从底部进入，禁用动画时即时显示；不新增原生窗口或重排列表，悬停/键盘焦点保留操作机会。点击撤回后AddRequest通过同一API取消/凭据清理/风控路径串行POST add，复用Page的request_id/generation/active_operation与线程回收；成功后逐项恢复列表、本地次序并发布items_changed。失败不自动重试，尚未恢复项可手动重试；账号切换和卸载清记录，迟到结果由世代及请求号拒绝。平台重新添加可能改变网页添加时间/排序，不声明云端顺序回滚。

UndoEntries只处理头像叠放与可见行绘制，使用既有OrderModel的数据投影，不为每项建控件或播放器。头像复用Page的无凭据CoverLoader/缓存，通知中的可见头像加入现有图片优先级；只有相关图片到达才更新通知。提示持有展示投影，过期/清理时释放。展开保持底边不动，160ms可中断高度过渡；undo_expand_rows严格为1–10整数、默认4，通过既有SelectControl即时保存。空间足够时按设定条数与实际条目数计算整行高度，只有窗口高度不足才减行；余项内部像素滚动，窗口放大恢复。
