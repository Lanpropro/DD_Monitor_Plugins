# 稍后再看职责与生命周期

> 类型：参考 ｜ 状态：维护中 ｜ 适用版本：bili_watchlater 1.0 ｜ 更新：2026-11-17 ｜ 读者：插件作者、维护者

原提交 ZIP 的 SHA256：`1F1C1FE7B61E04A8FEB2A50ACE5EEA9256BAB4EFC940773FE6C5A7687A555546`。
包中未标注作者；本轮只进行宿主兼容和定向故障修复，不重构整个入口。

后续外部修复包 SHA256 为 `6383F6CBB92AE9CD2D45182BE6292EBACD2ECD959AB5F0ECA282CB4D687BFEEC`，
以本地验收候选 `13d9b90` 为基线逐项吸收，不覆盖既有界面、分 P、选格及风控修复。
相对 seek 由真实播放器执行，缺少 command 的替身才回退为夹取范围后的绝对位置。
DPI 通知仅登记一次延迟任务；处理期间和冷却期忽略重入，拖动时撤掉遮盖，卸载停止定时器。
分层透明绘制使用独立 Win32 函数对象与指针签名，避免修改本体 BadgeSurface 的 ctypes 参数定义。
应用级按键过滤器与 QShortcut 入口都使用相对 seek。弹幕键不再注册与本体重名的 QShortcut；
当前窗口存在可用宿主快捷键时让其处理，浮窗才沿用插件的单格处理，不广播到其他格子。

| 所有者 | 职责与收尾 |
| --- | --- |
| `plugin.py` | 唯一持有点播绑定；通过本体格子控件工厂接线，跟踪账号代次、请求与格子归属；卸载还原仍属于该绑定的合成房间 |
| `page_panels.py` | 复用 `ddm.ui` 设置卡片与选框；持有目标格选择与缩略图选中外观，不发网络请求；Qt 子对象随页面销毁 |
| `page.py` | 列表、筛选、删除操作和页面线程；关闭弹窗保留缓存，shutdown 作废结果，短暂收尾后移交仍在运行的页面请求 |
| `wheel_scroll.py` | 按帧累计滚轮量；视图切换／隐藏时落定残量，shutdown 摘除 viewport 过滤器并停止定时器 |
| `request_retirement.py` | 应用级 QObject 持有未退出的页面请求；完成后移出集合、清理快照并 deleteLater；应用退出信号中等待剩余请求收尾 |
| `entry_icon.py` | 按分辨率绘制稍后再看／外链图标；按钮持有 hover 动画，隐藏及键盘操作时复位，复用本体动画设置与 easing |
| `workers.py` | 工作线程持有捕获的凭据副本和独立 HTTP 会话；不访问本体 GUI 接口 |
| `bili_api.py`、`vod_stream.py` | B 站协议、请求超时及风控失败；风控直接结束，不再切换备用解析策略 |
| `covers.py`、`avatars.py` | GUI 线程持有 QNetworkAccessManager，解码在线程池进行；头像复用图片加载器，shutdown 中止网络回复 |
| `vod_preview.py`、`vod_danmaku.py`、`vod_subtitle.py` | 点播附属资源；绑定更换或切 P 时取消对应请求、释放预览、删除旧 SRT |
| 本体 | 持有真实 Tile、播放器和原生窗口；插件不修改宿主类定义 |

`_dm_context` 保存绑定对象、账号代次与分 P，不能只保存 bvid：同一视频的新绑定不得接收旧绑定结果。
弹幕在取流成功后使用实际 cid 请求，避免与分 P 解析各自选择不同页面。
切 P 时先取消旧媒体请求、清空弹幕与字幕、释放预览，再解析下一 P。

取流期间原直播仍由本体持有；若用户已换房，取消或卸载只解除旧绑定，不停止新播放器、不还原旧房间。
页面请求在正常、异常和取消完成时清除自己的凭据副本。页面销毁会断开其结果和完成回调，
等待 100ms 仍未结束的请求交给应用级对象保活；完成后从集合移除，不保留已销毁 Qt 对象的 Python wrapper。
移交后立即检查完成状态，覆盖 finished 发生在 wait 超时与信号接线之间的竞态。
应用 aboutToQuit 等待尚在网络 I/O 中的请求结束，再允许 Qt 销毁线程；HTTP 仍受既有超时控制，
不使用 terminate，也不承诺弱网下整个进程即时退出。媒体请求仍按原有绑定生命周期收尾。

播放目标单独从本体弹幕格映射排除聊天位置，完整 Tile 集合仍用于绑定生命周期与退出还原。
默认网格目标宽 300px、最少两列；封面高度由宽度决定，不由窗口高度强制分成四行。
图片队列按可见区重新排序；监测只记录数值阶段耗时，每次打开最多十二条。

滚动合并保留当前卡片外观：将原有圆角、封面、时长徽章和进度线绘制预合成一张位图，
缓存签名包括原图、尺寸、DPR、历史进度、徽章、字体与调色板，释放封面时同步清空。
拉取范围仍为可见区邻行，已加载封面在更宽的四行保留带内复用；不扩大实际网络预取范围。
分页采用不可被连续滚轮重启的定时任务，网格每四张让出一次事件循环；删除和追加使用保留分页量的重排路径。
刷新和回顶改为滚动区外的固定操作行，复用公共 ActionButton；删除不再使用的自绘悬浮按钮实现。

点播底栏扩展区仍由本体 `TileControls.allocate()` 分配各控件宽度，插件只把已有空白移交给该分配器，
不把整个扩展区宽度直接写给进度条 wrapper。进度条最小宽度包含两个时钟标签和滑杆的实际布局需求；
空间不足由宿主隐藏 wrapper，控件保持可分配资格，拉宽后恢复。

图标由 Qt 圆弧与三角形独立绘制，视觉依据用户截图。hover 参考本地 BewlyCat 的
`src/components/Dock/Dock.vue`：外环固定，中央播放图形按 1 → 1.22 → 0.96 → 1 轻弹。
使用本体的 280/160ms 时长及 emphasized easing，未复制参考仓库的 SVG 路径或组件代码。
参考地址：https://github.com/keleus/BewlyCat 。

## 设置式浏览与显式置入（2026-11-17）

页面复用公开 `TitleLabel`、`HintLabel`、`SettingsSurface`、`SelectControl` 和 `ActionButton`，最低宿主调整到 0.7.3。
页面拥有唯一缩略图选中 key；PlacementSelector 拥有目标格选择，插件提供真实格子和占用状态。
目标列表只在打开、下拉展开和显式操作前刷新，不增加轮询线程。刷新保留指定格；目标消失则取消选择，避免悄悄替换其他格。
封面、标题和双击只选中；按钮和明确的菜单操作才调用置入回调。空格置入，已有直播／视频直接替换。
插件执行前再次检查目标属于可用视频格；从右键选片进入的操作完成后关闭窗口，普通浏览保留窗口。
旧的自动选空格回调保留给既有内部调用，不接入本轮卡片按钮；媒体请求与线程回收生命周期不变。
