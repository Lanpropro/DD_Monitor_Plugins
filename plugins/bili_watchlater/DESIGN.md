# 稍后再看职责与生命周期

> 类型：参考 ｜ 状态：维护中 ｜ 适用版本：bili_watchlater 1.0 ｜ 更新：2026-11-16 ｜ 读者：插件作者、维护者

原提交 ZIP 的 SHA256：`1F1C1FE7B61E04A8FEB2A50ACE5EEA9256BAB4EFC940773FE6C5A7687A555546`。
包中未标注作者；本轮只进行宿主兼容和定向故障修复，不重构整个入口。

| 所有者 | 职责与收尾 |
| --- | --- |
| `plugin.py` | 唯一持有点播绑定；通过本体格子控件工厂接线，跟踪账号代次、请求与格子归属；卸载还原仍属于该绑定的合成房间 |
| `page.py` | 列表、筛选、删除操作和页面线程；关闭弹窗保留缓存，shutdown 作废结果并等待请求结束 |
| `entry_icon.py` | 按分辨率绘制稍后再看／外链图标；按钮持有 hover 动画，隐藏及键盘操作时复位，复用本体动画设置与 easing |
| `workers.py` | 工作线程持有捕获的凭据副本和独立 HTTP 会话；不访问本体 GUI 接口 |
| `bili_api.py`、`vod_stream.py` | B 站协议、请求超时及风控失败；风控直接结束，不再切换备用解析策略 |
| `covers.py`、`avatars.py` | GUI 线程持有 QNetworkAccessManager，解码在线程池进行；头像复用图片加载器，shutdown 中止网络回复 |
| `vod_preview.py`、`vod_danmaku.py`、`vod_subtitle.py` | 点播附属资源；绑定更换或切 P 时取消对应请求、释放预览、删除旧 SRT |
| 本体 | 持有真实 Tile、播放器和原生窗口；插件不修改宿主类定义 |

`_dm_context` 保存绑定对象、账号代次与分 P，不能只保存 bvid：同一视频的新绑定不得接收旧绑定结果。
弹幕在取流成功后使用实际 cid 请求，避免与分 P 解析各自选择不同页面。
切 P 时先取消旧媒体请求、清空弹幕与字幕、释放预览，再解析下一 P。

取流期间原直播仍由本体持有；若用户已换房，取消或卸载只解除旧绑定，不停止新播放器、不还原旧房间。
正常关闭会等待工作线程结束；尚未承诺 HTTP 阻塞期间的即时退出。

播放目标单独从本体弹幕格映射排除聊天位置，完整 Tile 集合仍用于绑定生命周期与退出还原。
默认网格目标宽 300px、最少两列；封面高度由宽度决定，不由窗口高度强制分成四行。
图片队列按可见区重新排序；监测只记录数值阶段耗时，每次打开最多十二条。

图标由 Qt 圆弧与三角形独立绘制，视觉依据用户截图。hover 参考本地 BewlyCat 的
`src/components/Dock/Dock.vue`：外环固定，中央播放图形按 1 → 1.22 → 0.96 → 1 轻弹。
使用本体的 280/160ms 时长及 emphasized easing，未复制参考仓库的 SVG 路径或组件代码。
参考地址：https://github.com/keleus/BewlyCat 。
