# B站稍后再看（bili_watchlater）

DD监控室CE 插件 · 版本 **1.0**

当前为最终集成验收源码，尚未公开发布。版本沿用1.0，以源码commit及暂存文件清单识别；架构整理后尚未生成新ZIP。

本轮在 `a349def` 的媒体浏览样式上，加入布局缩略图选位与独立设置。
点击视频后在同一窗口内显示当前布局、各格已有视频或主播、空格和弹幕格；点空格置入，点已有内容替换，弹幕格不可选。
设置支持默认视图、自动／固定列数、卡片大小、视频预览、浏览状态留存和播放行为。顶部为图标操作，卡片提供独立删除图标；
多选确认与取消位于有边界的底部栏，不挤压顶部控件。保留此前的取流、缓存、快捷键及线程回收功能。

在 DD监控室CE 内浏览、搜索和管理 B 站「稍后再看」，并把视频直接放进画面墙格子，用软件自带的播放器播放。复用本体已有的登录态、播放器、弹幕引擎与底栏按钮，不额外安装播放器或第三方依赖。

## 主要功能

- 稍后再看列表：搜索、筛选、排序；列表 / 自适应大卡片网格，切换视图保持滚动位置。默认窗口三列，封面保持 16:9，不强塞四行。
- 网格封面底部显示播放量／弹幕数图标和时长，下方是两行标题；头像、UP 主／日期与置入、外链、删除位于同一行。列表保留原信息结构。
- 进度达到 80% 时，网格和列表封面右上角显示白色「圆环＋勾」完成图标，无障碍描述保留「已看完」说明；右键可删除。
- 把视频卡片拖到任意画面墙格子，或点击视频／「置入视频」后在布局缩略图中选择位置；解析出的点播直链交给本体播放器。
- 播放形态：画面墙 / 全屏 / 多路小窗（画中画）自适应；进度条进底栏、隐藏时保留底部进度细线。
- 播放能力：画面弹幕、B 站字幕、清晰度切换、进度条拖动与悬停画面预览、结束后点击下一 P / 下一个视频。
- 三种形态下统一的键盘操作（见下表）。

## 安装

1. 从本仓库对应候选 commit 构建 `dist/bili_watchlater-1.0.zip`。
2. 在本体“设置 → 插件”导入 ZIP，勾选「B站稍后再看」，保存并重启。
3. 源码版从本体根 `run.cmd` 启动，按 [验收步骤](ACCEPTANCE.md) 测试。

安装副本位于本体当前数据目录的 `plugins_user/bili_watchlater/`，源码在本仓库
`plugins/bili_watchlater/`。后续修改在源码中完成后重新打包，不直接修改安装副本。

公开本体 **v0.7.3缺少观看顺序侧栏与共享拖影接口**，完整功能需配套开发源码，入口会检查这些接口。
清单0.7.3暂为开发环境数字下限，正式发布前将改成实际包含接口的本体版本；不能据此宣称正式v0.7.3完整兼容。
当前检查使用配套开发源码及PySide6 6.11.2，插件只使用宿主自带依赖，不依赖其他插件。
版本依赖及发布顺序见[发布草稿](../../docs/releases/DRAFT-bili-watchlater-v1.0.md)，实现边界见[兼容对照](PARITY.md)。

## 完整操作流程

1. 在本体登录 B 站并启用插件，点功能中心「稍后再看」。能看到列表说明列表读取成功，播放、声音、字幕还需分别验证。
2. 首次测试先在主窗口画面墙留一个空的视频格，保持普通窗口布局。搜索、观看状态分段筛选、排序都在已加载的列表内完成；需要重新获取账号列表时点页头刷新按钮或按 F5。
3. 点击封面、标题或「置入视频」按钮，切换到当前窗口内的选位页；缩略图按当前布局和分隔比例显示，已有内容显示缓存图片或名称，空格显示加号，弹幕格禁选。
4. 在选位页点空格会置入，点已有视频／直播格会替换，无额外确认。若布局或内容在打开后变化，会刷新缩略图并要求重新点选，不悄悄投放到别格；取消、返回箭头或 Esc 不播放。
5. 格子右键入口会把该格作为初始焦点；选定位置后关闭选片窗口。普通浏览选位后保留窗口，关闭列表不停止点播。拖放仍可直接操作指定格。
6. 播放后检查画面、声音、进度、暂停，再验收画质、字幕、预览、全屏和画中画。默认到结束卡停止；设置开启「自动连播」后先下一 P，再下一条，列表末尾停止。

| 操作 | 网格视图 | 列表视图 |
| --- | --- | --- |
| 单击封面或标题 | 打开布局缩略图，选位前不播放 | 打开布局缩略图，选位前不播放 |
| 双击封面、标题或卡片空白处 | 复用同一选位窗，不重复起播 | 复用同一选位窗，不重复起播 |
| 卡片操作区的外链图标 ↗ | 在浏览器打开对应视频页 | 在浏览器打开对应视频页 |
| 「置入视频」按钮或同名右键菜单 | 打开布局选位窗 | 打开布局选位窗 |
| 拖动视频卡到格子 | 播放到指定格 | 播放到指定格 |

两种视图的封面和标题操作一致；只有外链图标或明确的浏览器菜单项会打开浏览器。
例如 1+5 布局中三个主播、两格弹幕、一格空视频时，会完整显示六个位置，弹幕格不可选；选择空视频格才开始置入。

网格头像与操作同一行：宽卡片显示文字置入按钮，窄卡片切为加号图标，悬停提示和键盘名称保留；外链和删除始终独立。更窄的固定多列布局会隐藏头像并省略 UP 名称，优先保证三个操作完整可见。
日期优先显示发布时间，无发布时间时显示加入稍后再看的日期，均未知则留空。统计未知时隐藏，已知的零正常显示；没有额外请求未提供的点赞数据。
头像复用现有无 Cookie 图片加载器与缓存，B 站头像请求64px缩略图，当前封面排在头像请求之前；隐藏／离开保留区时释放卡片持有的头像。

## 视频卡片与播放设置

点击页头齿轮进入当前窗口内的设置页，更改立即生效并自动保存，没有应用／取消按钮；返回箭头或 Esc 只返回列表。设置按显示与预览、视频卡片网格、播放行为分组，平面材质与本体设置一致，组内使用细分隔线。
返回列表保留浏览位置，修改播放开关不强制切换当前浏览视图；配置只写入变化的项目。设置页不再提供恢复默认按钮。

选片、设置、选位和清空确认共用一个窗口。顶部是自绘拖动区、最大化／还原和关闭图标，没有 Windows 原生标题栏；拖动顶部空白处移动窗口，双击最大化／还原，拖动边缘调整大小。
右上角关闭会关闭整个稍后再看窗口；左上角返回只退出当前内页。单项删除直接执行，不进入确认页；清空全部仍需确认，返回或关闭不清空，账号切换后旧确认作废。

| 开关 | 默认 | 行为 |
| --- | --- | --- |
| 留存状态 | 开 | 本次运行中关闭选片页面后，重新打开恢复条目位置、偏移、视图、搜索、筛选和排序；退出软件后重置。切换账号清理，关闭此项后从默认视图顶部开始 |
| 自动播放 | 开 | 置入或替换后立即播放；关闭后进入暂停态，手动点击播放。调整设置不打断已经在播的视频 |
| 自动连播 | 关 | 自然结束后先下一 P，再下一条，列表末尾停止 |
| 提前加载下一条 | 关 | 仅自动连播开启时可用；关闭连播会取消此项。剩余约 30 秒时准备下一 P 或下一条，每路最多约 10 MiB 音视频开头缓存，额外占用内存和流量 |
| 启用视频预览 | 开 | 有可用 B 站预览数据时，悬停卡片约 450ms 后展示预览帧，移动鼠标定位；同时控制播放进度条预览。关闭后停止请求预览数据 |
| 关闭软件后仍保留视频 | 关 | 正常退出保存视频格位置、BV、分 P、画质、进度与暂停状态；同一账号和布局再次启动时恢复。自动播放关闭时恢复为暂停 |
| 显示观看顺序 | 开 | 在关注栏增加观看顺序内容页，保留本体顶部栏；单击选择、双击快捷播放、拖动排序或拖入格子 |
| 观看顺序包含已看完 | 开 | 关闭后在观看顺序和自动连播中排除已看完项，保留隐藏项的本地排序；开启后恢复显示 |

预览使用 B 站提供的 storyboard 图片帧，没有本地模型，也不会额外启动完整视频播放器。
浏览快照只保存在本次运行的页面内存中；退出软件后重新打开选片页面，从默认视图顶部开始，旧版持久化的浏览快照会清除。列表变化时优先按同一视频恢复，视频不存在则使用可用滚动范围。“关闭软件后仍保留视频”独立保存格子和播放进度，不受此调整影响。

视频恢复独立保存在插件设置，不把临时点播房写成宿主直播房。正常退出时先记录，再沿用原清理流程；重新启动后重新取流并定位进度，不保存旧签名 URL。
本体未提供公开UID时，用登录态的不可逆指纹隔离记录，不保存原始Cookie；同一登录态正常重启可恢复，重新登录／登录态变化后会跳过旧记录。
账号或布局改变、目标变为弹幕格、格子已放入其他内容时跳过恢复；关闭开关或切换账号清理记录。此项不承诺强制结束进程／断电恢复，不向 B 站上传进度。

提前加载缓存视频开头最多 8 MiB、音频开头最多 2 MiB，只准备下一项，通过本体已有 Range 转发交给播放器。
缓存最多有效 120 秒，取消、替换、账号切换或卸载会清理待用任务；预取失败、不支持 Range 或缓存过期时走正常取流。
这用于减少切换等待，不保证所有网络下零等待；从历史进度中部续播、缓存尚未完成时仍可能需要网络。
本机测试流只验证缓存读取与交接，真实 CDN 的提速效果待人工验收。

## 换片、回到直播与列表管理

- 换成其他视频：点击新视频，在布局缩略图中点要替换的格子；也可把新卡片拖入该格。拖入同一视频是重播；在普通布局里拖动格子本身才是交换位置。
- 回到直播：可以从本体关注列表把直播拖回该格，替换点播。关闭选片窗口不是停止点播。
  当前点播画面右键菜单未直接提供「还原为直播态」；底层已有恢复逻辑，但入口还不够直观，不能据此要求用户一定找得到该菜单。
- 单项删除：点击卡片删除图标或右键移除，直接发送删除请求。多选删除：点顶部垃圾桶进入选择态，勾选后使用底部「删除选中」执行；底部取消或 Esc 退出。
  删除成功后底部弹出提示及「撤回」，10秒内可重新加入B站稍后再看；鼠标停在提示上或键盘焦点进入提示时暂停过期。连续或多选删除合并为一批，失败停止后续删除，仍可撤回已经成功的部分；撤回失败保留重试入口，不自动重复请求。成功恢复后还原软件内位置及观看顺序；B站网页中的添加时间/排序由平台决定。账号切换、卸载或提示过期会清除撤回记录，过期不会再发送请求。
  单项提示显示UP头像与视频标题；多项使用前后叠放头像，右侧为「全部撤回」和展开按钮。展开后向上延伸，逐行显示本批视频的头像和标题，其余条目内部滚动。设置→显示与预览→「移除提示展开条数」默认4条，可选1–10条；仅窗口高度不足时临时减行，放大后恢复设定条数。
  展开列表每行右侧提供「撤回」，只重新加入对应视频，其他条目继续保留，可逐项撤回或使用底部「全部撤回」。请求进行期间禁用撤回操作以避免重复提交，失败保留该项供重试。
  删除会修改 B 站账号的真实稍后再看列表，与把视频从画面墙移开是两回事。
- 列表中的蓝色进度来自 B 站返回的历史数据。本插件不会将本次点播进度回传 B 站；本机重启续播需开启「关闭软件后仍保留视频」，与 B 站网页进度同步无关。

## 遇到提示时

| 提示或现象 | 含义与操作 |
| --- | --- |
| 「没有空格子了」 | 默认播放没有可投放位置；留一个空的视频格，或主动拖到要替换的格子 |
| 单击封面没有播放 | 当前交互打开同窗布局缩略图；选择位置后才置入。观看顺序侧栏则需双击快捷播放 |
| 双击后提示「当前布局暂不能无中断换格，视频保持原位」 | 初始候选会把一次双击派发成两次播放；已修复重复派发。当前候选封面不再触发播放，请使用独立操作按钮，不必重新登录 |
| 主动拖格时提示不能无中断换格 | 回到普通画面墙并等待布局稳定后再移动；不代表登录或取流失败 |
| 视频无声 | 先检查格子的静音、音量；再区分媒体确无音轨或 DASH 音轨挂载失败 |
| 没有字幕 | 有的视频不提供可用字幕，或当前账号无法获取；不代表视频不能播放 |
| 412 / 风控提示 | 停止重复点击，稍后再试；插件不自动循环重试 |

真实使用出现问题时，记录操作位置（封面/标题/卡片）、列表或网格、目标格是否为空、当时是否全屏/画中画，
以及本体日志时间段。反馈无需 Cookie 或完整带签名的媒体地址。

封面仍只做进程内缓存；新进程首次打开需要重新下载。滚动时优先当前可见封面，再预取邻行，
取消尚未发出的旧位置请求，网络并发保持四路。每次打开最多记录十二条 `cover timing`，
仅含排队、网络、解码和打开以来的毫秒数及队列数量，不含 URL、标题或账号。
若仍慢，保留打开窗口及滚动前后对应日志；真实网络耗时尚待用户复测，离线回归不作为提速证据。

## 快捷键

以下按键只对稍后再看的点播格生效；输入框聚焦、其它对话框以及其它按键一律让路给宿主。

| 按键 | 行为 |
| --- | --- |
| `空格` | 暂停 / 播放。全屏、画中画、画面墙行为一致，不会误触发底栏画质按钮 |
| `←` / `→` | 后退 / 前进 5 秒，可按住连发 |
| `B` | 打开 / 关闭画面弹幕（跟随本体「切换画面弹幕」快捷键设置，默认 B）；画中画浮窗激活时同样可用 |
| `F` / `Esc` | 进入 / 退出全屏（本体快捷键） |
| `↑` / `↓` | 音量（本体快捷键） |

## 字幕与播放进度说明

- 点击字幕按钮后才读取 B 站为当前分 P 提供的字幕轨；优先人工简体中文／其他中文，再选 B 站 AI 中文，最后使用可用的首条字幕。
- 下载带时间戳的字幕 JSON，转换为临时 SRT，通过本体播放器的 `sub-add` 加载并跟随视频时间显示。B 站 AI 字幕也是平台已经提供的文本；本插件不运行本地模型、不下载模型、不在本机做语音识别或翻译。没有可用字幕时提示，不自行生成。
- 本插件播放不发送 B 站历史心跳或进度上报，也不更新云端观看位置。插件内看过的位置不会同步到 B 站，退出后也不保存本次点播位置。
- 在 B 站播放后，手动刷新插件列表；如果稍后再看接口返回了最新 `progress`，新建单 P 点播绑定时以它续播。不是实时同步，不会让正在播放的格子跟随网页跳转；已绑定视频再次选择属于重播，多 P 视频从零开始，不猜分 P。
- 窄格底栏由宿主统一给进度条和字幕按钮分配宽度，两个时间标签完整容纳后才显示进度条；放不下时使用视频底边进度细线，放大格子后恢复。暂停与设置图标由本体统一提供。

## 画中画浮窗

- 浮窗拖到不同分辨率或不同缩放比例的显示器时，播放器重载画面期间会用纯黑遮盖盖住点播画面，避免短暂白屏；遮盖是纯本地视觉效果，不联网、不阻塞播放。
- 浮窗成为活动窗口后，左右方向键调进度与弹幕快捷键仍然有效。

## 隐私与安全

- 复用宿主当前登录的 B 站账号，不需要手动填写或导入 Cookie。
- 列表、Cookie 快照、点播直链、弹幕只在当前进程内存中处理，不做磁盘缓存，不写插件设置。
- 字幕开启后会生成临时 SRT，切 P、解除绑定及正常退出时清理；异常终止可能留下临时文件。
  窗口位置与尺寸使用独立 QSettings 保存。它们均不包含 Cookie。
- 插件日志不主动记录凭据，日志入口对 `SESSDATA` / `bili_jct` / `buvid3` / CSRF 等字段脱敏。
- 列表、取流、字幕和弹幕的 API 地址固定为 B 站接口，带凭据的请求拒绝重定向。
  图片、预览和点播媒体地址来自接口响应；目前这些路径尚未统一执行 CDN 域名白名单及响应大小限制。
  点播签名直链会过期，不缓存为永久地址。
- 遇到风控（412 / -352 / -401 / -403 等）不自动重试、不循环请求、不内置绕过能力。

## 已知限制

- 依赖宿主画面墙与播放器的内部结构做实例级能力探测；宿主升级若调整这些结构，可能需要同步适配。
- 清晰度档位由账号实际权限与接口返回决定，插件不绕过权限；部分视频的 DASH 分离音轨可能只有画面没有声音，此时可用「用浏览器打开」兜底。
- 画中画跨屏黑遮盖只遮挡视觉白屏，不改变播放器自身的重绘耗时。
- 卸载会取消页面请求并断开回调，短暂收尾后仍运行的请求由应用级对象保活，结束后移出集合并清除快照；应用真正退出时等待剩余线程结束。取消不能立即打断已阻塞的 HTTP，弱网退出仍可能等待既有超时。

开发职责见 [DESIGN.md](DESIGN.md)，功能范围见 [FEATURES.md](FEATURES.md)。

## 独立设置与顶部操作

点顶部线条齿轮打开插件设置，配置只写入本体的此插件配置段。
默认视图可选网格／列表；每行视频数可自动或固定 2–6 列。自动列数时按紧凑／标准／宽大卡片计算；固定列数随窗口缩放，窄卡片的操作按钮收为图标。
自动连播默认关闭，开启后只在当前绑定自然结束时进入下一 P／下一视频；关闭开关、替换该绑定或卸载会作废尚未执行的连播。
刷新和回顶均为图标；刷新请求期间圆箭头按 1s 线性循环，完成／失败／隐藏时停止，系统关闭动画时显示静态忙碌标记。F5 保留。

## 观看顺序与预览反馈

新版宿主关注栏的「观看顺序」入口只将下方关注卡片切换为纵向视频大卡片，上方标题和控件保持原结构；共享搜索框分别保留关注与视频的查询。设置 → 显示与预览 →「显示观看顺序栏」（默认开启）即时控制入口显示，关闭后保留已有本地顺序。栏内拖动排序，拖至边缘可自动滚动；拖入画面墙格子直接置入或替换。此顺序仅保存在本插件设置中，不提交 B 站，也不改变选片页的搜索、筛选或排序。自动连播、下一个视频、预加载和播放序号统一采用该顺序。账号切换清空旧列表并隔离保存的顺序；刷新会保留已有顺序，新增条目排到末尾。

单击顺序卡片只选中，双击才优先替换唯一的点播格；没有点播格时使用空格；多路点播或没有空格时进入同窗口布局选位，不自动替换直播。旧宿主没有公开侧栏页面接口时保留原选片入口和原始列表顺序。

卡片不再弹出标题/UP/完成状态详情浮层。支持预览时悬停会显示「预览加载中…」，缺少预览元数据立即提示「此视频暂无预览」，未取得可用预览显示「暂无可用预览」；仍可正常置入播放。失败在本次页面会话内记忆，手动刷新可重试，账号变更后清除，操作图标的简短提示和无障碍说明保留。预览反馈不表示完整视频无法播放。

真实流畅度调查：本候选限量记录前三个5秒操作窗口的滚动次数、预览/封面绘制耗时和事件循环最大间隔；不记录账号、BV号或媒体地址。模拟回归仅验证功能，不能证明真实滚动或预览性能改善。


观看顺序卡片交互反馈：卡片区域为手形指针，留白恢复箭头；悬停以160ms透明度过渡显示细描边和轻微明暗变化，按下压暗，拖动时显示本地排序插入线。不移动卡片布局，键盘选择即时响应，系统禁用动画时反馈即时切换。图片到达只刷新对应的可见卡片，其他图片和屏外条目不触发整列重绘。


拖动后切换列表修复候选：观看顺序改用只读列表模型，切回时不再销毁原生QListWidgetItem；拖动中刷新延后到结束应用，QDrag明确回收。拖影热点按鼠标抓起位置设置，复用关注卡片的抬起处理，保留系统动画/DPI行为。此变更针对实机崩溃现场，仍需按验收文档重复真实拖动手势确认。


拖动观看顺序卡片时，完整卡片跟随鼠标，原列表位置留出等大的空位；取消或放下后恢复。占位仅影响绘制，不删除行或修改本地观看顺序，排序仍只在放下时生效。


支持共享侧栏拖影接口的新宿主上，观看顺序与关注卡片使用同一应用内拖动会话：浮动卡片先出现，再让原位置留空，避免原生拖影接管前的空档；放下/取消统一恢复。旧宿主保留原生回退，候选需搭配已同步接口的根run.cmd验收。

拖动经过其他卡片时，卡片会以160ms过渡让出一个完整落点；离开列表或取消时回到原位，系统关闭动画时即时避让。模型和本地排序只在放下后变更，拖动期间刷新仍延后处理。

设置 → 显示与预览 →「观看顺序包含已看完视频」默认开启，沿用即时保存。关闭后观看顺序、下一条、自动连播和预加载跳过已看完视频，当前播放不被打断；隐藏条目的本地顺序保留，重新开启即可显示。完成状态沿用列表既有判断，不向B站写入进度。已看完卡片右上角显示白色圆环勾，无文字角标，并保留无障碍说明。

选片窗口支持拖动四边与四角调整大小，指针显示相应方向；设置和选位页面使用同一窗口边缘。最大化时隐藏缩放区域，还原后恢复；尺寸沿用原有窗口记忆。观看顺序栏采用与关注栏相同的20像素滚动步长（普通滚轮一格通常为60像素），不按视频卡片高度跳动，触控板沿用Qt像素滚动。
