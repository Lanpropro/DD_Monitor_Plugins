# B站稍后再看（bili_watchlater）

DD监控室CE 插件 · 版本 **1.0**

当前为本体兼容验收候选，尚未公开发布。清单版本沿用提交包的 1.0，候选以源码 commit 和 ZIP 的 SHA256 区分。

在 DD监控室CE 内浏览、搜索和管理 B 站「稍后再看」，并把视频直接放进画面墙格子，用软件自带的播放器播放。复用本体已有的登录态、播放器、弹幕引擎与底栏按钮，不额外安装播放器或第三方依赖。

## 主要功能

- 稍后再看列表：搜索、筛选、排序；列表 / 自适应大卡片网格，切换视图保持滚动位置。默认窗口三列，封面保持 16:9，不强塞四行。
- 列表显示播放量与弹幕数；进度超过 80% 标注「已看完」；悬停显示完整标题；右键可删除。
- 把视频卡片拖到任意画面墙格子，或点「播放」进第一个空格；解析出的点播直链交给本体播放器。
- 播放形态：画面墙 / 全屏 / 多路小窗（画中画）自适应；进度条进底栏、隐藏时保留底部进度细线。
- 播放能力：画面弹幕、B 站字幕、清晰度切换、进度条拖动与悬停画面预览、结束后点击下一 P / 下一个视频。
- 三种形态下统一的键盘操作（见下表）。

## 安装

1. 从本仓库对应候选 commit 构建 `dist/bili_watchlater-1.0.zip`。
2. 在本体“设置 → 插件”导入 ZIP，勾选「B站稍后再看」，保存并重启。
3. 源码版从本体根 `run.cmd` 启动，按 [验收步骤](ACCEPTANCE.md) 测试。

安装副本位于本体当前数据目录的 `plugins_user/bili_watchlater/`，源码在本仓库
`plugins/bili_watchlater/`。后续修改在源码中完成后重新打包，不直接修改安装副本。

清单最低宿主版本为 **0.7.2**；当前兼容检查使用本体 **0.7.3 开发源码及 PySide6 6.11.2**，
不代表已回归所有 0.7.2 构建。插件只使用宿主自带的 PySide6、requests 与播放器组件，
不新增第三方依赖；不依赖其他插件。接口边界与保留限制见 [兼容对照](PARITY.md)。

## 完整操作流程

1. 在本体登录 B 站并启用插件，点功能中心「稍后再看」。能看到列表说明列表读取成功，播放、声音、字幕还需分别验证。
2. 首次测试先在主窗口画面墙留一个空的视频格，保持普通窗口布局。搜索、筛选、排序都在已加载的列表内完成；需要重新获取账号列表时点右下角刷新按钮。
3. 选视频时区分操作位置，见下表。默认浏览模式会将新视频放进第一个空格；若该视频已经占有格子，再选它会复用原格并重播，不另选空格。
4. 想指定位置时，把视频卡拖到那个格子；也可右键空格，选「选择稍后再看视频…」，看到「播放至 第 N 格」再选视频。没有空格时，普通列表播放不会擅自替换直播，需主动拖到目标格。
5. 列表是选片窗口，实际画面在主窗口的画面墙中。单击播放可保留列表；双击会播放一次并关闭选片窗口。关闭选片窗口不会停止已经开始的点播。
6. 播放起来后先检查画面、声音、进度和暂停，再依次测试画质、字幕、预览、全屏、画中画。结束卡上的「下一个视频」需要主动点击；多 P 先切下一 P，全部 P 结束后再到列表下一条，不是自动连播。

| 操作 | 网格视图 | 列表视图 |
| --- | --- | --- |
| 单击封面或标题 | 播放到画面墙 | 播放到画面墙 |
| 双击封面、标题或卡片空白处 | 播放一次并关闭选片窗口 | 播放一次并关闭选片窗口 |
| 标题旁／操作区的外链图标 ↗ | 在浏览器打开对应视频页 | 在浏览器打开对应视频页 |
| 行内「播放」或右键菜单「播放到格子」 | 右键菜单可用 | 行内按钮及右键菜单可用 |
| 拖动视频卡到格子 | 播放到指定格 | 播放到指定格 |

两种视图的封面和标题操作一致；只有外链图标或明确的浏览器菜单项会打开浏览器。
默认选格排除已转换为弹幕的格子。例如 1+5 布局中三个主播、两格弹幕、一格空视频时，播放进入该空视频格。
顶部「快速选片」按钮本身不会让用户挑选格子，
不能把其泛称的「目标格子」当成具体位置；指定位置应使用拖放或空格右键入口。

## 换片、回到直播与列表管理

- 换成其他视频：从选片窗口把新卡片拖入要替换的点播格。拖入同一视频是重播；在普通布局里拖动格子本身才是交换位置。
- 回到直播：可以从本体关注列表把直播拖回该格，替换点播。关闭选片窗口不是停止点播。
  当前点播画面右键菜单未直接提供「还原为直播态」；底层已有恢复逻辑，但入口还不够直观，不能据此要求用户一定找得到该菜单。
- 单项删除：在选片窗口右键视频并确认移除。多选删除：点垃圾桶进入选择态，勾选后再次确认；取消或 Esc 退出。
  删除会修改 B 站账号的真实稍后再看列表，与把视频从画面墙移开是两回事。
- 列表中的蓝色进度来自 B 站返回的历史数据。本插件当前不会将本次点播进度回传 B 站；重启后不保证续上本次播放位置。

## 遇到提示时

| 提示或现象 | 含义与操作 |
| --- | --- |
| 「没有空格子了」 | 默认播放没有可投放位置；留一个空的视频格，或主动拖到要替换的格子 |
| 1+5 布局有空视频格，单击封面却看不到播放 | 旧候选可能选中弹幕格背后的空对象；本候选已排除这些对象，重启后保留原布局复测 |
| 双击后提示「当前布局暂不能无中断换格，视频保持原位」 | 初始候选会把一次双击派发成两次播放；已修复重复派发。修复前可单击网格封面后关闭列表，不必反复双击或重新登录 |
| 主动拖格时提示不能无中断换格 | 回到普通画面墙并等待布局稳定后再移动；不代表登录或取流失败 |
| 视频无声 | 先检查格子的静音、音量；再区分媒体确无音轨或 DASH 音轨挂载失败 |
| 没有字幕 | 有的视频不提供可用字幕，或当前账号无法获取；不代表视频不能播放 |
| 412 / 风控提示 | 停止重复点击，稍后再试；插件不自动循环重试 |

真实使用出现问题时，记录操作位置（封面/标题/卡片）、列表或网格、目标格是否为空、当时是否全屏/画中画，
以及本体日志时间段。反馈无需 Cookie 或完整带签名的媒体地址。

封面仍只做进程内缓存；新进程首次打开需要重新下载。滚动时优先当前可见封面，再预取邻行，
取消尚未发出的旧位置请求，网络并发保持四路。每次打开最多记录十二条 `cover timing`，
仅含排队、网络、解码和打开以来的毫秒数及队列数量，不含 URL、标题或账号。
若仍慢，保留打开窗口及滚动前后对应日志；真实网络耗时尚待用户复测，离线回归不作为提速证据。

## 快捷键

以下按键只对稍后再看的点播格生效；输入框聚焦、其它对话框以及其它按键一律让路给宿主。

| 按键 | 行为 |
| --- | --- |
| `空格` | 暂停 / 播放。全屏、画中画、画面墙行为一致，不会误触发底栏画质按钮 |
| `←` / `→` | 后退 / 前进 5 秒，可按住连发 |
| `B` | 打开 / 关闭画面弹幕（跟随本体「切换画面弹幕」快捷键设置，默认 B）；画中画浮窗激活时同样可用 |
| `F` / `Esc` | 进入 / 退出全屏（本体快捷键） |
| `↑` / `↓` | 音量（本体快捷键） |

## 字幕与播放进度说明

- 点击字幕按钮后才读取 B 站为当前分 P 提供的字幕轨；优先人工简体中文／其他中文，再选 B 站 AI 中文，最后使用可用的首条字幕。
- 下载带时间戳的字幕 JSON，转换为临时 SRT，通过本体播放器的 `sub-add` 加载并跟随视频时间显示。B 站 AI 字幕也是平台已经提供的文本；本插件不运行本地模型、不下载模型、不在本机做语音识别或翻译。没有可用字幕时提示，不自行生成。
- 本插件播放不发送 B 站历史心跳或进度上报，也不更新云端观看位置。插件内看过的位置不会同步到 B 站，退出后也不保存本次点播位置。
- 在 B 站播放后，手动刷新插件列表；如果稍后再看接口返回了最新 `progress`，新建单 P 点播绑定时以它续播。不是实时同步，不会让正在播放的格子跟随网页跳转；已绑定视频再次选择属于重播，多 P 视频从零开始，不猜分 P。
- 窄格底栏由宿主统一给进度条和字幕按钮分配宽度，两个时间标签完整容纳后才显示进度条；放不下时使用视频底边进度细线，放大格子后恢复。暂停与设置图标由本体统一提供。

## 画中画浮窗

- 浮窗拖到不同分辨率或不同缩放比例的显示器时，播放器重载画面期间会用纯黑遮盖盖住点播画面，避免短暂白屏；遮盖是纯本地视觉效果，不联网、不阻塞播放。
- 浮窗成为活动窗口后，左右方向键调进度与弹幕快捷键仍然有效。

## 隐私与安全

- 复用宿主当前登录的 B 站账号，不需要手动填写或导入 Cookie。
- 列表、Cookie 快照、点播直链、弹幕只在当前进程内存中处理，不做磁盘缓存，不写插件设置。
- 字幕开启后会生成临时 SRT，切 P、解除绑定及正常退出时清理；异常终止可能留下临时文件。
  窗口位置与尺寸使用独立 QSettings 保存。它们均不包含 Cookie。
- 插件日志不主动记录凭据，日志入口对 `SESSDATA` / `bili_jct` / `buvid3` / CSRF 等字段脱敏。
- 列表、取流、字幕和弹幕的 API 地址固定为 B 站接口，带凭据的请求拒绝重定向。
  图片、预览和点播媒体地址来自接口响应；目前这些路径尚未统一执行 CDN 域名白名单及响应大小限制。
  点播签名直链会过期，不缓存为永久地址。
- 遇到风控（412 / -352 / -401 / -403 等）不自动重试、不循环请求、不内置绕过能力。

## 已知限制

- 依赖宿主画面墙与播放器的内部结构做实例级能力探测；宿主升级若调整这些结构，可能需要同步适配。
- 清晰度档位由账号实际权限与接口返回决定，插件不绕过权限；部分视频的 DASH 分离音轨可能只有画面没有声音，此时可用「用浏览器打开」兜底。
- 画中画跨屏黑遮盖只遮挡视觉白屏，不改变播放器自身的重绘耗时。
- 卸载会取消页面请求并断开回调，短暂收尾后仍运行的请求由应用级对象保活，结束后移出集合并清除快照；应用真正退出时等待剩余线程结束。取消不能立即打断已阻塞的 HTTP，弱网退出仍可能等待既有超时。
