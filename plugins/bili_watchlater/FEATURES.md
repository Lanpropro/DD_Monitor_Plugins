# 稍后再看功能范围

> 类型：参考 ｜ 状态：草案 ｜ 适用版本：bili_watchlater 1.0 ｜ 更新：2026-11-16 ｜ 读者：验收者

| 功能 | 验收口径 |
| --- | --- |
| 列表与网格 | 登录后加载；筛选、切视图与滚动可用；账号切换后丢弃旧数据 |
| 投放到格子 | 空格起播，目标格替换，取消未完成取流不覆盖用户新房间 |
| 点播操作 | 暂停、±5 秒、弹幕键；输入框保留打字和光标行为 |
| 多 P | 下一 P 使用对应 cid；弹幕、字幕、预览均切换到新 P |
| 画面墙、全屏、画中画 | 播放状态与底栏可用，关闭窗口或更换布局不遗留控件 |
| 管理列表 | 单项和多选删除均需用户确认；测试账号的真实删除由用户主动执行 |
| 退出与重启 | 线程收尾，点播合成房间还原；重启不留下 BV 占位房间 |

本表是待验证功能范围；执行结果和人工步骤见 [ACCEPTANCE.md](ACCEPTANCE.md)。
