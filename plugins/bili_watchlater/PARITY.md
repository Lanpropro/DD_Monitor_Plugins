# 稍后再看与本体兼容边界

> 类型：参考 ｜ 状态：草案 ｜ 适用版本：bili_watchlater 1.0 ｜ 更新：2026-11-17 ｜ 读者：维护者

当前目标为晚于正式v0.7.3、含侧栏页面与共享拖影接口的本体开发源码；公开v0.7.3不满足完整要求。
清单数字下限暂留开发值，正式发布时必须更新为实际配套本体版本。使用真实 MainWindow、Tile、PluginManager 进行离线检查，
媒体引擎和 B 站请求使用替身；该结果不能代替真实播放或原生窗口验收。

| 接口 | 使用情况 |
| --- | --- |
| 公开 `credentials`、账号事件 | 在 GUI 线程读取快照；后台仅使用副本 |
| 公开 workspace control / tile control | 注册侧栏入口与三个底栏控件；无窗口宿主只加载元数据 |
| 公开 sidebar page / shared sidebar drag | 观看顺序页与共享拖影；入口逐项检查register/unregister/start/cancel四接口，正式v0.7.3缺少 |
| `window._play_on`、`_stop_tile`、`players` | 保留提交包的实例级调用；当前源码接线已检查，不是跨版本稳定的 VOD 契约 |
| `tile.room`、`wall.tiles`、播放器属性 | 保留用于合成点播房、状态轮询和恢复直播的实现；真实拖拽与布局切换仍待验收 |
| 全屏、画中画内部结构 | 保留原实现与能力探测，未把注释中的“宿主证据”视作公开保证 |

本轮没有增加宿主专属 VOD 公共 API，也没有将平台协议移入本体。
若当前人工验收暴露本体状态耦合问题，按实际操作与日志定位后，再在本体职责模块补接口。
