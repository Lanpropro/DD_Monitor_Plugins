# 企鹅体育 v1.0

> 类型：插件说明 ｜ 适用版本：DD监控室CE 0.8 或更新版本 ｜ 更新：2026-11-20

安装并启用 `qie_live-1.0.zip`，重启后在监控室的添加房间入口输入企鹅体育官方房间链接。插件读取公开房间名称、标题和开播状态。符合公开观看条件的直播可通过原生播放器上墙。

## 720p 播放与重连

- 插件读取企鹅体育官网手机房间页提供的 HLS 地址，解码首帧确认分辨率为 1280×720。影音数据保持原编码，通过宿主的通用媒体交接接口送入原生播放器。
- 旧清单或分片返回 HTTP 403 时，宿主调度重连，插件重新读取官网手机房间页并验证新的 720p 地址。

## 关注卡片与弹幕

- 桌面房间页缺少主播头像时，从相同房间的官方手机页补齐，交给监控室的头像缓存。
- 插件包包含 `icon.png`。支持插件卡片台标的宿主也会在关注卡片显示它。图标来自企鹅体育在 Apple App Store 提供的版本，经缩放和圆角处理。图标权利归原权利人所有。 [官方 App Store 页面](https://apps.apple.com/cn/app/id1098102973)
- 开启画面弹幕或关联弹幕格时，通过官网的访客连接接收普通文字弹幕。弹幕是只读的。

## 本地验证

在插件仓库执行以下命令。墙面检查启动隔离的原生窗口，通过本机 HLS 测试源验证 200 → 403 → 200。

```powershell
python tests/check_qie_live.py --host ../DD_Monitor_CE
python tests/check_qie_wall.py --host ../DD_Monitor_CE
```

安装候选包后可用 [布丁小喵](https://www.qie.tv/10210732) 验收。从关注栏把房间放进画面格，开播时确认原生播放器实际出画并显示 720p。地址失效时观察原格能否自动恢复。
