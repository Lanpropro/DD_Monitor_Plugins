# B站直播互动 v1.1

作者：[@reon-nynes](https://github.com/reon-nynes)。本体维护者完成兼容适配与验收。

需要支持公开格子控件、登录快照与条件凭据更新接口的配套软件；插件在加载时检查这些能力。
输入区由本体居中并限制最大宽度；窄格子优先保留本体操作按钮，空间不足时隐藏输入区。
弹幕请求提交后立即禁用文字框，成功、失败或超时后恢复；失败保留草稿，切房或切账号会重置输入状态。
在本体登录 B 站；各格子的输入草稿相互独立，Enter 发送，中文输入法选词回车不会误发。
小表情插入文字，大表情按当前登录权限发送。请求超时不自动重试。
配套本体的表情“+1”会先异步读取当前账号在当前直播间的表情权限，再按原表情编号发送。
未解锁、当前房间不支持或权限检测失败时提示原因，不发送描述文本、不自动重试，也不覆盖输入草稿。
检测期间切换账号、房间或关闭控件会取消此次发送；历史表情缓存不能作为权限依据。
关闭/禁用/移除插件使用本体保存并重启流程。插件不提供播放平台，不保存账号信息。
礼物按钮在表情和发送之间。面板展示当前房间分类、剩余电池与各批背包；
只有单次数量且没有子礼物选项的普通礼物点击即赠送；其余礼物首次点击打开数量窗，
默认填入 1（接口禁止 1 时使用允许的数量），点击数量窗「赠送」发送所选数量。
“送花花”等组合礼物首次点击会在同一小窗列出主礼物及“真好听 / 贴贴 / 摸摸头”等子礼物与价格。
选择具体礼物后，数量选项、可否自定义数量及总价按该礼物更新；点击「赠送」发送所选礼物。
再次点击原礼物图标时赠送 1 个原礼物并收起小窗；移到其他礼物或离开小窗会收起。
100 原始单位显示为 1 电池，未知余额会禁止购买，但可赠送有效背包。
支持普通电池、普通电池盲盒、背包、大航海开通类及已解锁装扮礼物。
舰长一号、提督一号、总督一号等大航海开通类礼物，赠送前显示金额与服务协议确认。
其他尚未实现的购买流程保留名称和禁用原因；不提供充值、SC 或自动购买。
同一账号同时只提交一次；背包不足不会转为购买，超时结果未确认时先核对余额/背包。
首次成功前移出面板仍可浏览；成功后移出主窗与数量窗关闭，两窗间提供短暂过渡。
赠送中不会因移出关闭，Esc、外部点击、按钮切换及房间/账号变更仍可关闭。
关闭窗口不会再次提交，迟到的响应不会重新打开。
表情窗、礼物窗和数量窗共用圆角浮窗样式，居中显示在入口上方，空间不足时避让屏幕边缘。
外部点击直接交给目标控件；拖动主窗口时浮窗跟随移动。
礼物窗默认选择礼物分类；发送进度及失败信息位于余额后面，成功后清除状态。
余额刷新保留当前数值；电池礼物确认赠送成功后，先减去单价乘以数量，再后台读取真实余额并直接替换。
同账号各 tile 同步扣减，连续成功的赠送累计扣减；背包礼物不扣电池，失败不扣减。
结果未确认时保留显示，但读取真实余额前禁止继续购买；过期响应不能覆盖更新后的余额。
数量窗与所选礼物之间的窄过渡区域保留小窗，即使这段路径经过上一排或下一排礼物。
移到该路径以外的其他礼物仍会立即收起；靠近屏幕上缘时向下弹出的数量窗行为相同。
图片最多四路并发读取，礼物静态缩略图优先于动图；表情兼容此前的本地图片缓存。
刷新表情时保留已加载的分类、图标和滚动位置，同一房间/账号下仍可使用旧内容；
刷新失败保留原列表，结果未变化不重建。切房或切账号立即清理旧内容及权限。
表情和礼物读取状态显示在刷新按钮旁的小转圈，隐藏面板暂停动画；礼物不再显示额外加载文字行。

分类封面可横向拖动，分类内表情可拖到目标位置，靠近滚动区边缘可滚动；拖动结束不会触发发送。
同一程序中的多个表情窗共享顺序，刷新和重启后继续保留；当前房间没有出现的分类、表情顺序不会被覆盖。
首次出现的表情包保留接口默认位置，切换房间不会将新的主播表情排到已购买表情之后；已手动调整的分类继续遵循保存顺序。
排序独立保存在程序旁的 `utils/bili_live/emoticon_order.json`，不写入账号配置。

表情目录按房间和账号隔离，原子保存到 `cache/bili_live/catalogs/`，文件名使用不可逆摘要，不保存 Cookie。
重启后可先显示最近七天内的目录，后台重新确认当前权限；确认前的缓存表情只供浏览，不能直接发送。
缓存最多保留 32 份，每份限制 4 MiB；损坏或不可写不会阻止重新获取目录。
已确认的同房间目录在手动刷新期间继续可用，刷新失败不清空已有内容。
图片同时复用插件缓存及本体原有 `cache/emoticons/`，解码后的图片保留在 16 MiB/256 张的内存缓存中。
同一图片的并发读取合并，重开和多格浏览可避免重复下载。

配套本体提供 `PluginContext.notify` 和 `request_login` 时，发送及读取失败显示在本体通知栏，附带主播名和房间号。
明确登录失效或凭据不完整时可点击重新登录；通知先收起，随后才打开登录流程。
网络、余额不足、权限和特殊购买流程不会被误判为登录问题；发送超时保留结果未确认的提示。
较旧宿主没有通知接口时继续使用输入区提示。通知不会使已关闭格子或过期房间请求恢复活动。

安装包为 `bili_live-1.1.zip`；1.1 补齐了独立表情“+1”的配套发送接口。
表情“+1”需要支持结构化表情发送的本体，已核对 v0.7、v0.7.1 包含该接口。
没有插件时本体仍保留登录、必要 Cookie 持久化、播放和接收弹幕；弹幕与礼物发送由本插件提供。
