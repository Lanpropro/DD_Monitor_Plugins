# 软件内功能统一验收

版本保持0.1.3，候选以交付提交SHA为准。下面均待用户人工验收；自动检查使用隔离数据、本地媒体和脚本弹幕，没有替代真实直播、听感、OBS/网络或界面验收。源码与记录见[功能对照](FEATURES.md)和[对齐计划](PARITY.md)。

停止当前需要保留的录制后，在方便时正常退出并从宿主根 `run.cmd` 启动，使已暂存更新生效；开发操作未替用户重启客户端。左侧功能区“录制切片”打开同一主窗口内的工作区。

| 流程 | 操作 | 预期 |
| --- | --- | --- |
| 录制方式 | 关闭“仅录制切片素材”测试原按钮完整录制与即时重放；停止录制/缓存后切到开启再录制 | 两种方式互斥，切片模式保存HLS素材，原版两种输出不会同时生成；通知、文件名含房间关键信息 |
| 录像库和回看 | 查看封面、平台/主播、标题/房间、起止时间与时长；打开正在录制或历史录像，暂停/定位/开启声音并返回画面墙 | 同页替换，不弹独立录播窗口；录制继续，时间轴随已封口分段增长，停止后仍能回看 |
| 格式识别 | 查看切片素材目录与手动导出成品 | `.m3u8`是索引；AVC/HEVC的实际分段为TS，AV1为fMP4。导出完整录像或选区后得到MP4；快速复制为MKV。索引存在不等于缺少视频 |
| 亮点和多选区 | 调整热度阈值/关键词，点击推荐和全部添加；增删、启停、排序选区，分别导出及拼接，保存重开 | 推荐来自普通弹幕数量，需用户判断内容；重复全部添加不重复同一候选，输出顺序/时长正确，取消保留已完成独立片段 |
| 弹幕链路 | 新HLS录制回放普通弹幕、SC及表情；搜索/过滤/点击定位、倍速/暂停/偏移，导出JSON/ASS及压制视频 | 画面与列表随媒体时间，切片/拼接后时间重新映射，已压制成品不默认重复叠加。旧日志缺失数据不能补回；ASS为文字回退 |
| 剪辑工程 | 从启用选区建工程，或导入外部视频/音频/图片；排序、裁剪、分割、复制、变速/音量、主轨与画中画互转、纵向换轨 | 主轨磁吸，附加内容/字幕按来源锚点跟随；操作可撤销/重做，删除工程不删外部原文件；保存重开和缺失文件重新定位可用 |
| 实时预览 | 播放跨片段、快速定位；暂停后移动/缩放/旋转文字、贴纸与画中画，中心吸附、双击文字、Esc取消 | 手势松开前内容更新，取消恢复、松开一步保存；不等待8秒预编码片段。预览宽度上限960，导出保持工程分辨率；长工程负载和真实音画同步需实测 |
| 文字/字幕 | 应用字体、粗斜体、描边/背景/阴影和对齐；手动打轴、SRT导入导出、字幕拖动/分割/样式和压制 | 样式和字幕随工程保存，片段移动/裁剪/变速后仍对齐；中文多行与成品内容一致，关闭字幕压制仍可交付SRT |
| 编码和后台任务 | 测试H.264/H.265、速度/画质与目标码率；切换软件/自动硬件，取消任务并重开软件查看历史 | 输出可播放，任务提示记录实际编码器；没有可用硬件回退软件。目标码率不保证平均码率，不覆盖已有同名文件；进行中任务重开标中断，不自动续跑 |
| 封面 | 从录像/工程取帧，测试16:9/4:3裁切、同步/独立图文、样式、手势、草稿重开和PNG/JPEG双图导出 | 两张尺寸正确，4:3为中央裁切，边缘元素可被裁掉；失败/取消清理本次部分输出，不覆盖已有文件 |
| 管理 | 测试搜索/排序/日期、12/24小时日历与跨日平移、多选/清除、仅移除和删除测试副本 | 移除保留文件，重新导入可恢复；删除明确范围，活动录制/任务/已登记工程引用受保护。统计来自实际已索引文件，未知时长和原版即时缓存统计缺口明确显示 |
| OBS输入 | “外部输入”添加RTMP，OBS自定义服务复制地址和密钥，使用H.264/AAC、2秒关键帧；推流、断开、重连、停用、移除 | 首段封口后可回看/切片，真实封面、状态/时间更新；重连另存一份，停用拒绝推流、移除保留录像、退出收尾。局域网模式需使用本机IP并放行端口，HEVC/AV1增强RTMP未接入 |
| 浏览器快捷添加 | 在“外部输入”启用ddcut快捷链接；打开 `ddcut://live.bilibili.com/123`，取消或确认，再停用 | 原添加框预填链接，确认后才添加，继续使用已有平台解析/账号；软件未运行时可唤起，停用移除本安装关联，不覆盖bsr。浏览器许可/系统PowerShell策略需实测 |
| 界面和收尾 | 深/浅主题、920×600及常用DPI；关闭/重开工作区、正常退出与再次启动 | 原侧栏账号/关注/导入与录制入口可用，页面可返回，任务/录制不因关闭工作区而丢失；退出回收播放器、推流和后台进程 |

本阶段暂缓：投稿、AI与自动识别、新增自动化、内置素材库，以及Web/headless/Docker独立部署。素材管理由外部软件承担，目前交付文件导入/导出；专用接口待选定软件后确定。其他厂商硬件编码器、真实平台延迟/高密度弹幕、长时高码率OBS和多轨负载仍需本次人工实测。
