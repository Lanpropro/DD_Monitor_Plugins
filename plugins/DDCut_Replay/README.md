# DDCut Replay v0.1.3（开发候选）

专门用于 DD监控室CE 的录制与切片插件。加载后接管本体新建录制会话，保留原录制按钮；内嵌页用于增长时间轴、回看、标记、单个起止选区及后台导出。尚未公开发布，真实直播与人工界面验收待完成。

## 安装与兼容

候选包为 `ddcut_replay-0.1.3.zip`，ZIP 顶层和安装目录均为小写 `ddcut_replay/`。源码按维护者要求保留 `plugins/DDCut_Replay/`，由构建器映射，禁止将源码目录直接改名安装。

**需要配套本体录制服务 v1**（`context.recording.api_version == 1`），宿主分支 `function/ddcut-replay-host`，还需包含新增的 `register_backend` / `live_recording` 能力。已发布的 0.7.1 仅满足清单最低版本，不保证包含该开发接口；旧本体点击入口会说明缺少配套接口。需要 FFmpeg 与同目录或 PATH 中的 ffprobe，预览使用本体自带 libmpv。

在配套本体“设置 → 插件”导入候选 ZIP，勾选并按正常流程保存重启。插件不自动重启程序、不登录账号、不发弹幕或上传。

## 操作流程

1. 左侧“录制切片”或 `Ctrl+Shift+R` 在软件主界面中打开功能页，替换画面墙区域；格子右键可定位当前房间。点击“返回画面墙”或再次点击入口返回；与比赛二路互斥切换。需要配套本体嵌入页接口 `7f70cdf`，不再弹出独立工作窗口。
2. **画面墙录制**：仍使用格子原来的录制按钮或右键开始/停止，保留本体录制目录、编码、画质锁定、快速保存与退出收尾。插件加载后新建的录制和缓存由插件会话接管；已有会话不会被强制中断。
3. **直接回看**：进入切片页会打开当前录制，也可在上方选择房间并点击“打开录制”。约 2 秒为分段目标，实际需等待源关键帧；未封口尾段不显示，时间轴随已完成片段增长。“跳到可读末尾”定位最新范围。无需生成回看副本。
4. **录播档案**：扫描指定录制目录、`replays/` 成品和 `DDCut_Replay/` 分段录播，或手动导入本地视频。每个新录播保存为独立文件夹，包含原始分段、`review.edl` 时间轴入口及 `recording.json`；保留整个文件夹，切勿只移动索引。原录像不迁移。
5. **回看与选区**：默认静音，可主动开启声音；输入起止秒数，或在预览区域用 `I`/`O` 标记当前点、`M` 加标记、Space 播放暂停。标记和选区保存在插件本地状态。
6. **导出选区**：快速复制保留原编码、输出 MKV，边界可能按关键帧扩展；精确剪辑重编码 H.264/AAC、输出 MP4，耗时及画质有所变化。必须使用新文件名，不覆盖已有成品。
7. **任务中心**：查看进度、取消或打开成品。返回画面墙仅停止预览，任务继续；退出/禁用插件会取消插件任务并回收进程，原录像和已有成品保留。重启后未完成任务标为中断，需要重新提交。

时间轴使用连续媒体时间，断流等待不计入录像长度；自动轮转或编码变化后生成另一录播，当前选区不自动跳到新录播。格式沿用设置：TS、MP4、MKV 均可使用；AV1 与 TS/MOV 不兼容时沿用本体兼容规则改为 MP4，不擅自转码。仅精确切片或用户选择 H.264 录制时重编码。MPV 原生 EDL 将已完成的小文件呈现为一条时间轴；不是正在写入的普通 MP4 必须可读，也不保证最新一帧零延迟。

导出提交时冻结可读分段与时间范围。返回仅停止预览，录制和导出继续；卸载恢复本体默认录制，已经开始的会话继续由本体持有并收尾。

0.1.0 历史自动验证：7 项本地媒体/离屏界面检查、3 项宿主桥接检查、插件安装包源码一致性、原生 libmpv 出图/定位/暂停/默认静音，以及本体原录制与退出回归通过。宿主根目录集成提交 `870b93b`；普通 `run.cmd` 在临时配置/专用插件目录/离屏条件下通过本地回看与 1.5 秒精确导出检查。此处没有把隔离功能验证记为真实直播或人工验收。


底部操作区右上角的向下箭头仅将录制/比赛功能区滑动收起，功能区下沿“展开功能区”可重新打开；账号、布局/设置、导入关注/添加直播间保持常驻。收起仅隐藏入口，后台录制与导出继续；鼠标触发 200ms 动画，可中途反向，键盘和系统关闭动画时立即切换。该位置及主界面页面依赖宿主工作区接口提交 `7f70cdf`。

0.1.3 自动验证：TS/MP4/MKV 增长时间轴、录制中切片、原按钮接管、轮转/卸载收尾、无音轨 TS 精确选区、Windows 屏幕外出图及根 run.cmd 隔离入口通过；详见增量记录。真实直播与人工验收仍待完成。
