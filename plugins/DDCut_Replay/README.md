# DDCut Replay v0.1.3（开发候选）

专门用于 DD监控室CE 的录制与切片插件。保留原录制按钮，通过“仅录制切片素材”在原版录制与切片格式之间互斥切换；录像页直接提供回看、时间轴、标记、选区及后台导出。尚未公开发布，真实直播与人工界面验收待完成。

后续对齐范围已按用户要求暂缓AI、自动化与内置素材库；素材管理准备交给其他软件。录像库保留，剪辑工程直接引用外部视频、音频与图片；先使用文件导入/导出，具体软件的接口待选定后确定。字幕先覆盖手动编辑、SRT与压制，自动识别暂缓。当前实现与计划分别见[功能对照](FEATURES.md)和[对齐计划](PARITY.md)。

UI也按用户最新要求先参考ShadowReplay，再做定制。当前回看工作区已调整为大画面、底部时间轴与右侧片段检查器；选区和亮点推荐在一起，生成按钮固定在检查器底部。尚未实现的功能页面按计划逐批接入。

剪辑工程已接入同一主窗口：顶部“剪辑工程”打开工程列表，回看选区页也可“用启用选区新建工程”。编辑器参考对方的左侧文件、中央预览、右侧属性与底部多轨时间轴，使用本体Qt控件和主题。

## 剪辑工程

1. 新建工程后导入外部视频、音频或图片，选择文件并添加到主轨、画中画、音频或贴纸；文件列表只保存本工程引用，不建立素材库。视频和图片显示真实缩略图，缺失文件可重新定位。
2. 主视频首尾相接；拖动片段排序、拖动边缘裁剪，用S分割、Ctrl+D复制、Delete删除、Ctrl+Z/Ctrl+Shift+Z撤销/重做。属性栏可修改来源入出点、0.25～4倍速度和音量，点击“应用属性”保存。吸附对齐播放头/边界，时间轴可缩放与滚动。
3. 文字支持多行、颜色/字号、位置/尺寸与透明度；贴纸引用外部图片，画中画引用外部视频，音频支持来源入点、速度、音量及淡入淡出。图文与画中画统一按“画面”轨道层级排列，高编号在上；可用属性栏“上移一层/下移一层”交换轨道，或修改编号，重叠内容自动分轨，音频轨独立。附加内容锚定主视频，移动/分割时跟随；裁剪掉起点时隐藏，恢复边界后重现。旧工程重开保留原先图文高于画中画的视觉顺序。
4. “波形”从选中文件真实音轨提取，显示在相应时间轴块中；没有音轨不会伪造波形。画布支持横屏/竖屏/方形及1～60fps；可勾选压制主轨来源弹幕。
5. 修改自动保存为 `.ddcut.json`，Ctrl+S手动保存，另存为可交付工程文件；相对路径在同盘时使用，跨盘保留绝对路径。移动工程时保留引用文件的相对位置，或使用“重新定位文件”。删除片段或工程JSON不删除外部源文件。
6. 预览与导出共用FFmpeg合成链路，预览按当前位置生成8秒缓存，默认静音；修改后自动更新，跨预览段播放会等待合成，不能等同即时实时多轨预览。导出完整H.264/AAC MP4，统一画布/帧率，保留项目对应弹幕JSON；取消清理未完成输出，已有外部文件不覆盖。

暂停后可直接点击画面内的文字、图片或画中画：拖动边框内调整位置，四角等比缩放，顶部圆点旋转；松开后更新合成预览，一次拖动对应一步撤销，Esc取消未提交手势。原生MPV窗口接收鼠标，不使用独立浮窗；黑边不计入画布坐标。属性栏也能输入旋转角度，并支持居中、按来源比例铺满与取消旋转；选中预览后方向键微调位置，Qt键盘输入支持Shift加速。

当前尚未对齐的编辑细节包括拖动时实时重绘内容、转场和复杂样式；封面制作已接入，投稿按用户要求暂缓。当前拖动实时显示选择框，视频内容在松开并完成合成后更新；预览仍是8秒分段缓存。真实长工程负载、音画听感与高DPI交互待人工验收。

## 录像批量管理与录播日历

历史录播/成品页提供批量选择、当前结果全选、清除选择，以及按日期、标题、时长和实际文件大小排序；默认最新优先。批量模式点击卡片只选中，选择一项后仍可使用“回看并切片”。过滤会清除隐藏项的选择，刷新保留仍可见的选择。

“录播日历”在同页切换12/24小时时间范围，按录像分行，跨午夜按可见范围裁切；日期控件可弹出月历。上一/下一时段每次移动半个跨度，也可拖动画面或横向滚轮（Shift+竖向滚轮）平移；普通竖向滚轮继续滚动录像行。空时段保留时间尺和导航。单击选择，非批量模式双击回看，拖动不误选；短录像保留最小可点宽度，下方列完整起止时间。日历与关键词/分类共用过滤结果，关闭“按日期”退出日历并恢复全部日期。

顶部统计由后台读取真实文件与侧车，每30秒或点击刷新更新：已索引录像/回放、切片归档、成品和插件即时缓存的文件大小、已知时长、录制磁盘剩余空间及房间录制/缓存状态。重复路径只计一次；未探测时长和缺失文件明确标注。原版即时缓存没有开放文件统计，不计入占用；不是整盘或所有外部工程素材的统计。

“从列表移除”仅隐藏索引，文件保留，目录刷新不会自动重新加入；重新导入可恢复。“删除文件”确认后永久删除所选视频及其同名弹幕/录制侧车，HLS删除整个已核验的插件归档目录内文件；空目录可保留。不会删除其他外部文件。活动录制/缓存、当前回看、后台任务及已登记工程引用会阻止删除；外部未登记工程无法自动发现，删除前仍需确认文件用途。失败记录留在列表，错误写入任务；取消在录像之间生效，已完成删除不会撤销。只在临时隔离目录验证删除，不操作用户真实录像。

## 手动字幕与导出设置

工程右侧“字幕”页可在播放头处添加字幕，编辑多行文字及入出点，或用当前时间打轴；双击列表定位，也可拖动时间轴最上方的字幕块和边缘。字幕锚定主片段的来源时间，随排序、分割和变速重新映射；被裁掉的范围隐藏，恢复裁剪后重新出现。编辑、删除和分割沿用工程撤销/重做及自动保存。

SRT导入按当前工程时间轴追加，跨片段拆成各片段锚点，主轨范围外不导入。支持UTF-8/BOM与GB18030中文，时间格式错误整体拒绝。SRT导出使用当前可见时间并保留多行中文。样式包含字体、字号、颜色、描边、上中下居中、边距、粗斜体和半透明背景；“应用样式”后预览与成品共用绘制。默认压制，关闭“将字幕压入视频”可只交付同名SRT；工程成品同时保存SRT，不覆盖已有文件。自动识别仍暂缓。

工程属性和录像选区页共用H.264/H.265、速度/画质优先和视频目标码率，0为自动画质CRF20。画质优先使用更慢的软件编码预设；目标码率不是输出文件平均码率的保证，音频为AAC。工程预览固定快速H.264；精确切片、弹幕压制、分别导出和拼接使用所选编码，快速MKV仍复制原编码并禁用这些控件。

录像导出范围新增“完整录像：冻结当前可读范围”，手动生成单个成品；录制中只包含提交时已封口的可读分段，不跟随之后增长。硬件编码或自动整场处理未纳入本批；投稿暂缓，转场与复杂样式继续按计划推进。

## 封面制作

顶部“封面制作”在当前主窗口内打开编辑页。从录像回看进入时使用当前录像，从剪辑工程进入时按工程画面取帧，包含当时的图文、画中画及字幕；可调整取帧时间，也可导入背景图片。后台取帧期间手动换背景会取消旧请求，迟到结果不会覆盖新选择。

参照参考项目提供16:9（1920×1080）与4:3（1440×1080）双封面，背景各自缩放/拖动裁切。文字与贴纸默认同步，关闭同步后可分别修改。两种比例共享1920×1080设计坐标，4:3显示中间区域，因此文字在两张封面上保持尺寸和位置；放在画面边缘的元素可能被4:3裁掉。

添加多行文字或导入外部贴纸，支持字体、字号、粗斜体、文字/描边/底色、投影、对齐、透明度、图片翻转、图层排序/复制/删除。画布中拖动移动，角点等比缩放，圆点旋转；文字缩放同时改变字号，一次手势一步撤销，Esc取消。左侧显示另一比例预览。继续复用本体Qt组件与深浅主题，不建设贴纸素材库。

草稿自动保存为`.ddcover.json`，可打开、另存与撤销/重做，工程只保存草稿引用。外部图片使用相对路径；移动草稿时保留图片相对位置，缺图会明确报错。PNG/JPEG一次导出两张，文件名自动增加`-16x9`与`-4x3`，保留名称中的其他点号；已有文件不覆盖，失败或取消清理本次未完整交付的文件。这里仅制作并导出本地封面，投稿上传仍待后续实现。


## 安装与兼容

候选包为 `ddcut_replay-0.1.3.zip`，ZIP 顶层和安装目录均为小写 `ddcut_replay/`。源码按维护者要求保留 `plugins/DDCut_Replay/`，由构建器映射，禁止将源码目录直接改名安装。

**需要配套本体录制服务 v1**（`context.recording.api_version == 1`），宿主分支 `function/ddcut-replay-host`，还需包含新增的 `register_backend(enabled=...)` / `set_backend_enabled` / `live_recording` 能力。已发布的 0.7.1 仅满足清单最低版本，不保证包含该开发接口；旧本体点击入口会说明缺少配套接口。需要宿主会话的 export_input / snapshot_info 能力、FFmpeg 与同目录或 PATH 中的 ffprobe；预览使用本体自带 libmpv。

在配套本体“设置 → 插件”导入候选 ZIP，勾选并按正常流程保存重启。插件不自动重启程序、不登录账号、不发弹幕或上传。

## 操作流程

1. 左侧“录制切片”或 `Ctrl+Shift+R` 在软件主界面中打开功能页，替换画面墙区域；格子右键可定位当前房间。点击“返回画面墙”或再次点击入口返回；与比赛二路互斥切换。需要配套本体嵌入页接口 `7f70cdf`，不再弹出独立工作窗口。
2. **录制方式**：顶部“仅录制切片素材”默认关闭，关闭时使用本体原版完整录像与即时重放（即时重放仍遵循本体设置）；开启后只保存HLS切片素材，不建立纯回放缓存、不再手动或自动导出即时重放。选择会记住；先停止当前录制/缓存再切换，已有会话不强制中断。
3. **同页回看**：录像页包含正在录制、历史录播、已生成切片筛选，显示平台标识、主播/头像、封面、直播标题、日期/起止时间及可读时长。打开素材后收起列表，在同页以大画面回看并默认展开右侧检查器；“录像列表”返回浏览，“收起/展开检查器”切换工具。切片模式约2秒为分段目标，实际等待关键帧，“跳到最新”定位可读末尾；原版完整录像停止保存后可打开。
4. **保存与查找**：切片素材的 `.m3u8` 入口名称包含平台、主播、标题、房间号和时间，目录保留媒体分段、可能的初始化段、封面/头像及 `recording.json`；保留整个目录，不能只移动索引。通知明确显示“已保存切片素材”。原版视频和即时重放是普通文件，并带同名录像信息与图片文件，供录像库查询。旧档案不迁移或删除。
5. **回看与切片**：默认静音，可开启声音；拖动入出点或输入 `HH:mm:ss.mmm`，点击时间轴定位、缩放/滚动，用 `I`/`O` 标记当前点、`M` 添加标记、Space 播放暂停。标记和选区保存在本地，预览选区到出点暂停。封面优先使用本体缓存与归档图片；本地导入视频生成缩略图，没有来源信息时明确标注本地视频。
6. **多选区与导出**：右侧新建、选择、删除、启停选区，用↑/↓调整顺序；每段独立保存入出点。可导出当前选区、每段单独导出，或按列表顺序精确拼接。快速复制保留原编码、输出MKV，可能有关键帧前滚；带弹幕录像默认使用精确H.264/AAC MP4以同步侧车。必须使用新文件名；取消保留已完成的独立片段。
7. **后台任务**：从顶部打开共用右侧面板，录像与回看过程中均可查看进度、取消或打开成品。关闭面板不会取消任务；打开任务面板暂时收起检查器，关闭任务后恢复原开合状态。返回画面墙仅停止预览，任务继续；退出/禁用插件会取消插件任务并回收进程，原录像和已有成品保留。重启后未完成任务标为中断，需要重新提交。
8. **弹幕亮点**：满30秒可读内容后显示30秒窗口/5秒步长热度；默认阈值80%，支持50%～100%及逗号分隔关键词。点击推荐添加选区，也可“全部添加亮点”；重复全部添加会跳过已存在的同一候选。阈值是相对数量，不能代替人工判断。
9. **完整弹幕回放**：新切片素材记录普通弹幕、SC/删除和表情，复用本体连接与过滤。右侧“弹幕”提供画面开关、字号/透明度、±120秒偏移、搜索、普通/SC筛选、点击定位和列表跟随；画面弹幕随暂停、跳转和0.5/1/1.5/2/5倍速同步。SC卡片保留发送者、金额、内容和有效时长。旧日志只能回放已有字段，原版录像没有日志时不能补回。
10. **弹幕文件交付与压制**：整份或当前选区可导出JSON与文字ASS；切片自动附带同名 `.danmaku.json` 并复制已有表情到相邻 `.danmaku.images` 目录。选区页勾选“将弹幕压入视频”后，文字、表情与SC永久合成进MP4，沿用弹幕页字号/透明度/时间偏移，支持单段、分别导出与拼接；重编码可能改变画质。预览画面开关不影响这项选择。压制成品侧车带 `video_burned` 标记，重新导入默认关闭额外画面弹幕，避免重复；旧数组JSON仍兼容。移动成品时一起保留侧车/图片。ASS使用文字回退；变帧率输入按探测帧率输出，缺失本地表情回退文字。文件交给外部软件管理，不建立内部素材库。

切片素材模式采用与 [BiliBili ShadowReplay](https://github.com/Xinrea/bili-shadowreplay) 相同的核心链路：本地 HLS 分段归档 → 活动 EVENT 播放列表 → 内部本地读取服务 → 结束转 VOD → 从归档选区生成切片。普通 AVC/HEVC 使用 TS；AV1 使用 fMP4 初始化段和媒体分段，保持原编码。无需用户固定选择 TS，也不为满足 TS 容器而自动转码。本体单文件格式选项用于默认录制后端；插件接管后的内部存储由 HLS 归档管理，导出成品仍按快速 MKV / 精确 MP4 选择。

录制中保留已录内容，播放器持续读取同一 EVENT 时间轴，不因每次增长而重新打开。回看通过仅监听127.0.0.1的内部读取服务取得清单/分段，支持字节范围请求，避免 Windows 播放器占用正在更新的清单文件；软件关闭/插件卸载时一起收尾，不需要安装额外服务。

时间轴按媒体时间计时，断流等待不补帧；续录在清单标明断点，自动轮转或编码变化生成新录播并保留当前选区。导出冻结可读范围并保留初始化信息，录制仍继续。已有 EDL 录播及普通视频保持可读，不迁移或删除旧录像。

同一开发候选以 commit 和原 PR 验收记录区分，不为每次修改增加版本号。当前清单维持0.1.3，验收包用提交编号识别；这不是公开发布。

插件页面布局与交互先参考ShadowReplay，继续使用Qt控件并支持本体深浅主题。录像库采用自适应封面卡片；单击打开大画面回看，收起列表释放空间，后台刷新与检查器开合不会重载播放器。卡片集中显示平台、主播、标题、录制时间、时长与用途，无内容或搜索无结果时给出说明。小窗口检查器可滚动，选区摘要与生成按钮固定底部。

`.m3u8` 是 HLS 播放清单，引用归档目录内的 TS（或 fMP4）分段，本身不是视频文件；这类条目标为“切片素材”。单文件录像标为“完整录像”，原版 `replays` 目录的历史文件标为“即时重放”；手动导入且来源未知的文件标为“本地视频”。文件扩展名不能单独决定用途，旧文件不会重命名或迁移。保留 HLS 时应保留整个归档目录，不能只复制清单。
