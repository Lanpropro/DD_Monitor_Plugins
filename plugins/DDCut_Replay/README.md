# DDCut Replay v0.1.3（开发候选）

专门用于 DD监控室CE 的录制与切片插件。加载后接管本体新建录制会话，保留原录制按钮；内嵌页用于增长时间轴、回看、标记、单个起止选区及后台导出。尚未公开发布，真实直播与人工界面验收待完成。

## 安装与兼容

候选包为 `ddcut_replay-0.1.3.zip`，ZIP 顶层和安装目录均为小写 `ddcut_replay/`。源码按维护者要求保留 `plugins/DDCut_Replay/`，由构建器映射，禁止将源码目录直接改名安装。

**需要配套本体录制服务 v1**（`context.recording.api_version == 1`），宿主分支 `function/ddcut-replay-host`，还需包含新增的 `register_backend` / `live_recording` 能力。已发布的 0.7.1 仅满足清单最低版本，不保证包含该开发接口；旧本体点击入口会说明缺少配套接口。需要宿主会话的 export_input / snapshot_info 能力、FFmpeg 与同目录或 PATH 中的 ffprobe；预览使用本体自带 libmpv。

在配套本体“设置 → 插件”导入候选 ZIP，勾选并按正常流程保存重启。插件不自动重启程序、不登录账号、不发弹幕或上传。

## 操作流程

1. 左侧“录制切片”或 `Ctrl+Shift+R` 在软件主界面中打开功能页，替换画面墙区域；格子右键可定位当前房间。点击“返回画面墙”或再次点击入口返回；与比赛二路互斥切换。需要配套本体嵌入页接口 `7f70cdf`，不再弹出独立工作窗口。
2. **画面墙录制**：仍使用格子原来的录制按钮或右键开始/停止，保留本体录制目录、编码、画质锁定、快速保存与退出收尾；录播改由插件保存为 HLS 归档。插件加载后新建的录制和缓存由插件会话接管；已有会话不会被强制中断。
3. **直接回看**：进入切片页会打开当前录制，也可在“录像库 → 正在录制”选择房间并回看。约 2 秒为分段目标，实际需等待源关键帧；未封口尾段不显示，时间轴随已完成片段增长。“跳到最新”定位最新范围。无需生成回看副本。
4. **录像库**：内部分为正在录制、历史录播、已生成切片，支持搜索。扫描指定录制目录、`replays/` 成品和 `DDCut_Replay/` 分段录播，或手动导入本地视频。每个新录播保存为独立文件夹，包含原始分段、`playlist.m3u8` 录播入口、可能的初始化段及 `recording.json`；保留整个文件夹，切勿只移动索引。原录像不迁移。
5. **回看与切片**：默认静音，可主动开启声音；时间轴点击定位、拖动入出点、缩放及横向查看，或输入 `HH:mm:ss.mmm` 起止时间，或在预览区域用 `I`/`O` 标记当前点、`M` 加标记、Space 播放暂停。标记和选区保存在插件本地状态；右侧“选区 / 标记”切换工具，可预览选区，到出点暂停。
6. **导出选区**：快速复制保留原编码、输出 MKV，边界可能按关键帧扩展；精确剪辑重编码 H.264/AAC、输出 MP4，耗时及画质有所变化。可先填写成品文件名，确认保存位置；必须使用新文件名，不覆盖已有成品。成功结果自动进入“已生成切片”。
7. **后台任务**：从顶部打开共用右侧面板，两个主页面都可查看进度、取消或打开成品。关闭面板不会取消任务；窄窗口打开任务时暂时收起选区工具，关闭任务即可恢复。返回画面墙仅停止预览，任务继续；退出/禁用插件会取消插件任务并回收进程，原录像和已有成品保留。重启后未完成任务标为中断，需要重新提交。

录播采用与 [BiliBili ShadowReplay](https://github.com/Xinrea/bili-shadowreplay) 相同的核心链路：本地 HLS 分段归档 → 活动 EVENT 播放列表 → 内部本地读取服务 → 结束转 VOD → 从归档选区生成切片。普通 AVC/HEVC 使用 TS；AV1 使用 fMP4 初始化段和媒体分段，保持原编码。无需用户固定选择 TS，也不为满足 TS 容器而自动转码。本体单文件格式选项用于默认录制后端；插件接管后的内部存储由 HLS 归档管理，导出成品仍按快速 MKV / 精确 MP4 选择。

录制中保留已录内容，播放器持续读取同一 EVENT 时间轴，不因每次增长而重新打开。回看通过仅监听127.0.0.1的内部读取服务取得清单/分段，支持字节范围请求，避免 Windows 播放器占用正在更新的清单文件；软件关闭/插件卸载时一起收尾，不需要安装额外服务。

时间轴按媒体时间计时，断流等待不补帧；续录在清单标明断点，自动轮转或编码变化生成新录播并保留当前选区。导出冻结可读范围并保留初始化信息，录制仍继续。已有 EDL 录播及普通视频保持可读，不迁移或删除旧录像。

同一开发候选以 commit 和原 PR 验收记录区分，不为每次修改增加版本号。当前清单维持0.1.3，验收包用提交编号识别；这不是公开发布。
