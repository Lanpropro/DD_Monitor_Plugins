# ShadowReplay 功能对照与当前边界

核对日期：2026-11-05。参考固定源码 `e340951fa500d3977f5b9981329a1939650da82f`（2.25.1）及用户提供的实际界面；不是对参考项目未来版本的保证。“已实现”指开发候选中有实现和自动功能验证，真实直播与人工验收仍待完成。

此前只概括了录制、回看、切片，没有完整区分素材、剪辑工程及弹幕链路；此表补齐遗漏。2026-11-05用户提出先对齐参考功能、再做定制，随后明确暂缓AI、自动化与内置素材库，素材管理准备接入其他软件。当前分批范围与验收见[对齐计划](PARITY.md)。下表保留参考能力对照，暂缓项不计入当前必须完成的范围，也不标为已实现。 UI也先参照ShadowReplay，当前已落实回看工作区的大画面/底部时间轴/右侧检查器，其他尚未落地的页面仍待逐批实现。

执行顺序：多选区/批量导出 → 完整弹幕链路 → 外部文件与剪辑工程 → 手动字幕与高级导出 → 投稿/封面 → 其他输入与部署 → 管理与完整流程回归；具体完成标准见[对齐计划](PARITY.md)。暂缓AI、自动化与内置素材库，现有账号、关注和录制入口继续复用本体。

## 本轮亮点功能怎样使用

1. 没有活动录制/缓存时开启“仅录制切片素材”，使用原格子按钮开始新录制；本体需要已连接该房间的弹幕。
2. 从录像页打开素材，点击“弹幕亮点”；可读录像满30秒后显示热度和候选区间，约每2秒批量更新。
3. 默认阈值是当前录像最高30秒窗口数量的80%，可调50%～100%。它不是“亮点置信度80%”；观众少、刷屏和剧情延迟都会影响结果。
4. 关键词用中英文逗号分隔，按“任意词匹配”统计；输入后回车或移开焦点生效。阈值和关键词随该录像保存在插件状态中。
5. 点击推荐添加选区并定位，或全部添加；选区可分别启停、排序、编辑和删除。确认后导出当前选区、分别导出启用选区，或按列表顺序精确拼接。不会自动导出、删除或投稿。
6. 旧档案、导入视频、原版单文件没有弹幕记录时明确显示空态，不根据画面或文件名猜造热度。新归档需要一起保留 `danmaku.jsonl`、`recording.json`、清单和分段。

记录本体传来的普通弹幕、SC和删除事件，不保存账号凭证或观众ID，不额外建立弹幕连接；SC消息ID用于去重与删除。本体过滤后的普通弹幕才进入统计。断流等待不映射到无视频区间，未封口尾段等视频可读后再纳入。缺失的表情图片保留文字回退，不能凭空恢复旧日志未记录的信息。

回看右侧“弹幕”可搜索内容/发送者、筛选普通弹幕或SC、点击定位和跟随播放。画面弹幕直接绘入现有MPV，不新开窗口；时间偏移同时用于列表、热度、画面和导出。精确切片按所选媒体区间同步；快速复制可能增加关键帧前滚，侧车按请求区间裁剪，需同步弹幕时使用精确切片。导出普通视频与同名 `.danmaku.json`，若附有 `.danmaku.images` 目录应一起保留；导入同名视频自动关联侧车。素材仍由外部软件管理。

“将弹幕压入视频”默认关闭，开启后强制精确MP4，画面中永久包含弹幕；预览的画面弹幕开关不会改变此导出选择。压制按原录像时间绘制，因此裁剪开头保留正在移动的弹幕，SC按有效时长显示；每个选区单独处理后顺序拼接。变帧率输入按探测帧率输出，旋转/非方形像素归一为显示尺寸；缺失本地表情用文字回退，不在导出时联网补图。
