# F1 Play v0.1

在监控室赛事页播放比赛主画面。排行、解说控制台、弹幕输入和车载视角可以分别打开。

## 安装与使用

1. 从配套本体源码运行根目录 `run.cmd`。最低本体版本为 0.8，且须包含 `create_workspace_player`。解说和弹幕还需要 `create_plugin_widget` 及配套的比赛二路同步候选包。
2. 在「设置 → 插件」导入并启用 `f1_play-0.1.zip`，重启后从「功能中心 → F1 Play」进入。
3. 把可播放的 HLS 地址粘贴到「比赛画面」，点击「播放」。主画面默认静音，可点「开启声音」。点击「返回画面墙」会停止 F1 Play 播放并恢复普通画面墙。

### 排行与车载

- 在 OpenF1 的匿名历史接口可用时，从插件仓库运行 `python tools/fetch_f1_history.py 11245 china-race.json` 缓存上海正赛。排行面板点击「载入数据」，出画后点击「对齐」，输入当前画面相对 OpenF1 场次起点的秒数。可回看的主画面拖动进度后，排行会读取相应时点的数据。[OpenF1 接口](https://openf1.org/docs/)
- 点右上「车载视角」后输入已有的可播放 HLS 地址。小窗默认静音，可关闭或和主画面互换。交换画面会重新连接两个源，已对齐的排行需要重新校准。当前候选通过手工输入接入车载地址。

### 比赛二路和弹幕

- 「解说控制台」复用比赛二路的房间行、音量、偏移和各路弹幕开关。第一次打开控制台或弹幕功能时，主画面交给二路播放器重新缓冲。收起控制台后，已经播放的各路继续播放。
- 「发弹幕」打开比赛二路的发送台。发送对象、登录和平台能力沿用比赛二路。显示画面弹幕与打开输入相互独立。
