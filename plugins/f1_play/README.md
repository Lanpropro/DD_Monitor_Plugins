# F1 Play v0.2

在监控室赛事页播放比赛主画面。排行、解说控制台、弹幕输入和车载视角可以分别打开。

## 安装与使用

1. 从配套本体源码运行根目录 `run.cmd`。最低本体版本为 0.8，且须包含功能页蒙版接口。启用 `f1_play-0.2.zip` 和同分支构建的比赛二路候选包，重启后从「功能中心 → F1 Play」进入。
2. 把左侧关注卡片拖入画面。首张卡片立即作为主画面开播，后续卡片加入比赛二路。CCTV-5+ 等 HLS 源可通过 IPTV Play 导入关注，再把频道卡片拖进来。
3. 悬浮播放控件沿用比赛二路。打开 F1 Play 时，普通画面墙暂停观看，录制继续进行。点击「返回画面墙」会停止 F1 Play 播放并恢复原画面墙的播放状态。页面背景随本体的背景蒙版开关和强度调整。

### 排行与车载

- 在 OpenF1 的匿名历史接口可用时，从插件仓库运行 `python tools/fetch_f1_history.py 11245 china-race.json` 缓存上海正赛。排行面板点击「载入数据」，出画后点击「对齐」，输入当前画面相对 OpenF1 场次起点的秒数。可回看的主画面拖动进度后，排行会读取相应时点的数据。[OpenF1 接口](https://openf1.org/docs/)
- 点右上「车载视角」，把已经加入关注的车载来源拖入小窗。小窗默认静音，可关闭或和主画面互换。切换主画面后需重新对齐排行。

### 比赛二路和弹幕

- 「解说控制台」使用比赛二路的房间行、音量、偏移和各路弹幕开关。打开或收起控制台，已经播放的各路继续播放。
- 「发弹幕」打开比赛二路的发送台。发送对象、登录和平台能力沿用比赛二路。显示画面弹幕与打开输入相互独立。
