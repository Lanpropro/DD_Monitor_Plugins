# F1 Play v0.1

在监控室中央赛事页面播放比赛主画面。右侧预留即时排行，底部预留二路解说。

## 安装与使用

1. 从配套本体源码运行根目录 `run.cmd`。最低本体版本为 0.8，且须包含 `create_workspace_player` 功能页播放器接口。
2. 在「设置 → 插件」导入并启用 `f1_play-0.1.zip`，重启后从「功能中心 → F1 Play」进入。
3. 把可播放的 HLS 地址粘贴到「比赛画面」，点击「播放」。主画面默认静音，可点「开启声音」。点击「返回画面墙」会停止 F1 Play 播放并恢复普通画面墙。

直接播放 HLS 无需其他插件。频道播放地址由用户提供。央视官网直播页和频道列表导入仍需单独处理。排行、二路同步和 F1 TV 视角等待后续接入。
