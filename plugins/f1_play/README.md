# F1 Play v0.2

在监控室使用比赛二路的完整页面观看赛事。排行和车载视角可从页内「赛事工具」打开。

## 安装与使用

1. 从配套本体源码运行根目录 `run.cmd`。最低本体版本为 0.8，且须支持插件功能页。启用 `f1_play-0.2.zip` 和同分支构建的比赛二路候选包，重启后从「功能中心 → F1 Play」进入。
2. 把左侧关注卡片拖入画面。首张卡片立即作为主画面开播，后续卡片加入比赛二路。CCTV-5+ 等 HLS 源可通过 IPTV Play 导入关注，再把频道卡片拖进来。IPTV 卡片选为主画面后，由本体 libmpv 播放，解说仍由比赛二路播放。
3. 播放、控制台、弹幕栏和背景蒙版沿用比赛二路。打开 F1 Play 时，普通画面墙暂停观看，录制继续进行。再次点击 F1 Play 图标或点击关注图标可返回画面墙，恢复原播放状态。

### 排行与车载

- 在播放控制台点「赛事工具」，右侧会展开可收起的排行和车载区域。在 OpenF1 的匿名历史接口可用时，从插件仓库运行 `python tools/fetch_f1_history.py 11245 china-race.json` 缓存上海正赛。排行面板点击「载入数据」，出画后点击「对齐」，输入当前画面相对 OpenF1 场次起点的秒数。可回看的主画面拖动进度后，排行会读取相应时点的数据。[OpenF1 接口](https://openf1.org/docs/)
- 在「赛事工具」中点「车载视角」，把已经加入关注的车载来源拖入小窗。小窗默认静音，可关闭或和主画面互换。切换主画面后需重新对齐排行。

### 比赛二路和弹幕

- 使用比赛二路的房间行调整音量、偏移和各路弹幕开关。打开或收起控制台，已经播放的各路继续播放。
- IPTV 主画面支持暂停、刷新、音量和缓存区间内的手动偏移。主画面偏移只移动主画面，解说偏移从该路已有的播放位置计算。解说断流时继续播放主画面。
- IPTV 原生模式使用手动偏移。整组回看、赛事取帧、原生主画面裁取和录制待接入。主播的画中画和弹幕继续沿用二路。
- 右侧弹幕栏和发送台沿用比赛二路的发送对象、登录和平台能力。主画面的弹幕开关可以单独操作。
