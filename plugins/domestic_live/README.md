# 国内直播平台 v1.1

一个插件支持虎牙、斗鱼、抖音。添加关注卡片后，可拖入软件格子播放公开直播流，也可右键“加入画面墙”。
格子使用本体现有 VLC 播放器，支持音量、静音、暂停、换位及失败重连。
抖音 FLV 线路不可用时自动回退到同画质 HLS，保持格子和预览各自的画质选择。
当前提供房间实际画质档位、封面、头像和平台官网图标；三个平台均不查询或显示人数。
支持静音悬停预览，以及画面墙弹幕格中的聊天弹幕。

## 使用

1. 在软件“设置 → 插件”中导入 Releases 的 `domestic_live-1.1.zip`。
   源码运行软件时，先在软件仓库执行 `python -m pip install -r requirements.txt`。
   三个平台播放均需要 FFmpeg（便携包自带，源码环境可放在程序目录或 PATH 中）。
2. 在“设置 → 插件”启用“国内直播平台”，保存并重启。
   插件 ID 与安装目录改为 `domestic_live`（国内直播）。使用最新版软件时，
   旧 `huya_watch` 的启用状态和插件设置会迁移，原关注、画质和格子位置继续保留。
3. 添加带平台前缀的房间号或完整官方直播间链接：

   | 平台 | 房间号 | 官方链接格式 |
   | --- | --- | --- |
   | 虎牙 | `huya:660000` | `https://www.huya.com/660000` |
   | 斗鱼 | `douyu:36252` | `https://www.douyu.com/36252` |
   | 抖音 | `douyin:557481980778` | `https://live.douyin.com/557481980778` |

   虎牙支持字母房间标识，虎牙和斗鱼支持官方手机直播间链接；纯数字仍是 B 站房间号。
   抖音支持数字房间链接，以及带 `live_web_rid` 的分类页链接（如 `https://live.douyin.com/categorynew/4_103?live_web_rid=557481980778`）。
   分类页按 `live_web_rid` 识别直播间，`anchor_id` 不作为房间号；分享短链需先在浏览器打开并取得完整链接。
   添加窗口的支持说明由本插件提供，只在装载本插件后显示。
4. 房间查询完成后，关注卡片显示主播昵称、标题与直播状态，新增房间沿用
   B 站的自动上墙行为。将卡片拖入指定格子即可在该位置观看。
5. 在“设置”启用悬停预览，鼠标在已开播关注上停留 1 秒即可观看静音预览。
   展开的大卡片直接在封面内播放；简洁列表和收起后的头像使用浮层。
   竖屏顶部关注栏的浮层居中显示在卡片或头像下方，并限制在窗口内。
   移开鼠标、切换横竖屏、主播下播、删除关注或禁用插件会停止预览并清理转流进程。
   竖屏收起头像排在常规状态刷新时保留控件，避免中断正在播放的预览。
   预览独立选择网页提供的最低档位，缺少档位时沿用可用流；不会修改格子的手选画质。

## 账号登录

在底部账号条选择“登录其他平台”，可在统一窗口切换虎牙、斗鱼、抖音。
在官方页面完成登录后点击“确认登录”，后台确认当前账号的头像、昵称和 ID；
已登录平台只显示身份页，右侧“退出”只清除对应平台在软件内的登录。
“记住登录”使用 Windows DPAPI 加密保存；不勾选时仅在本次运行内保留会话。
虎牙、斗鱼、抖音均提供关注导入入口；登录和导入窗口仅展示已装载插件的平台。
虎牙使用官网 `getAllSubscribeToUidList` 和 `getUserProfile` 读取全部关注账号及直播间；
导入前复用直播间网页状态查询，填充当前开播状态、标题、头像与封面，
导入列表和关注卡片直接使用这份状态；查询失败时提示重试，不将其当作未开播。
抖音打开官网关注面板并滚动翻页，收集官网自行返回的列表数据。
列表缺少网页房间号时，通过主播 UID 查询最近直播记录，再解析官方分享页的房间号、状态和封面；
未开播记录也可导入，查询失败时提示重试，不将其当作没有直播间。
已知网页房间号时复用公开房间查询，补齐当前标题、头像、封面和开播状态。
读取包括未开播的直播账号，跳过没有直播间的普通用户，分页去重并支持取消。
公开直播播放和聊天仍使用原来的访客流程，不读取登录会话。

## 弹幕

选择包含弹幕格的布局，弹幕跟随主画面；切换主画面时自动切换直播间。
虎牙、斗鱼、抖音沿用本体弹幕字体、字号、屏蔽词及保留条数设置，横竖屏均可使用。
普通聊天和 Unicode 表情可显示，抖音表情消息保留文字；本次不接收礼物、进场、点赞及人数统计。
不发送弹幕，不读取账号登录态，不加载隐藏网页，不影响 VLC 视频播放。

- 虎牙：网页主播标识、TARS WebSocket 订阅，收到注册成功响应后显示已连接。
- 斗鱼：公开 TCP 弹幕服务，处理 STT 分片/合包与转义，登录成功后加入房间分组。
- 抖音：网页真实房间标识、Protobuf/gzip WebSocket 消息，及时返回 ACK 确认。
  网页请求仅使用内存中的临时访客信息，连接关闭后丢弃。
- 连接后台独立运行，定期心跳、断开后重连；切换房间、关闭弹幕布局、禁用插件或退出软件时停止。
  旧连接排队中的消息和状态不会覆盖当前房间。平台协议变化可能影响连接。

协议字段及抖音 signature 算法参考 [biliup 的弹幕实现](https://github.com/biliup/biliup/tree/master/crates/danmaku/src/protocols)。
改写部分的 MIT 许可保留在本目录 `biliup-MIT.txt`。

## 画质

- 虎牙：读取房间的 `vMultiStreamInfo`，沿用 `sDisplayName`，使用对应的 `iBitRate/ratio`。
  “蓝光8M”“蓝光4M”等是码率档位，不能直接视为不同像素分辨率。
- 斗鱼：读取房间的 `multirates`，沿用 `name`，用对应 `rate` 请求 AVC 直播流。
  使用软件已记住的斗鱼登录状态请求画质；原画和高码率档位按账号实际可用权限返回。登录 Cookie 仅用于斗鱼官方接口，不传给 CDN、FFmpeg 或其他平台。
  原画 `rate=0` 也明确请求，不能复用接口默认蓝光 4M；所选画质请求失败时明确报错。以接口实际返回的 `rate` 更新画质显示，二路保留手选档位供重试。
- 抖音：按公开页面中的具名 FLV 档位选择；保留网页 SDK 的名称、分辨率及帧率。
  分辨率和帧率只显示本房间提供的数据；缺少元数据时显示原始档位名，不猜测 720P/1080P。
- 格子取流完成后才显示该房间的菜单；换平台/直播间时清空旧菜单。
  竖屏小格子的按钮保留短名称，分辨率和帧率放在完整菜单及提示中。
  旧配置的通用画质值自动落到当前最高可用档位，并保存实际选择。
  主画面“原画”、副画面“720P”的自动策略仅适用于 B 站，这三个平台保留手选档位。
  软件保存的整数画质标识仅用于菜单和配置，不是像素高度或平台原生参数。

卡片点击沿用本体的选择行为；只有额外的“用默认浏览器打开直播间”菜单会打开网页。
旧 v0.1.0 虎牙网页卡片自动迁移为格子播放。关注、排序、置顶和格子音量随配置保留。
禁用插件并保存后，三个平台的关注卡片及格子中的房间一起转为暂存，停止播放与状态查询。
重新启用并重启后恢复关注、排序、置顶与原空闲格子；原格子已被其他直播间占用时保留新内容。
关注栏只有一个平台时隐藏平台图标，混合多个平台时才显示。

使用 Streamlink 8.6.1 的网页取流协议，不是平台官方 SDK。仅处理公开直播流，
斗鱼播放仅使用软件已记住的本平台登录状态读取账号可用的普通直播画质；不接入付费或 DRM 内容。网页或 CDN 变化可能导致取流失败。
虎牙使用网页 HLS，斗鱼和抖音使用对应档位的公开 FLV。
斗鱼优先选择接口提供的普通 CDN，播放地址仅交给播放器连接，避免提前探流导致短时断开。
房间状态查询与取流独立，网络错误保留上次状态，不误报下播。
抖音网页请求生成临时访客 nonce，不读取浏览器 Cookie，也不保存该 nonce。
由 FFmpeg 复制音视频并转封装为 VLC 可播放的本机流，
归一化时间戳；不重新编码、不写录像文件、不保存带签名的地址。起播缓存约 4 秒。
首帧出现前不会触发画面静止刷新，HLS 分片允许 8 秒停帧等待，持续异常仍会恢复。

取流协议参考：[斗鱼解析器](https://github.com/streamlink/streamlink/blob/8.6.1/src/streamlink/plugins/douyu.py)、
[抖音解析器](https://github.com/streamlink/streamlink/blob/8.6.1/src/streamlink/plugins/douyin.py)。

## 斗鱼关注导入（试用）

需要支持平台关注导入的新版宿主软件。点击原 B 站账号位置的「登录」，选择「斗鱼」，
在斗鱼官方页面完成登录后点击「确认登录」，软件读取账号头像、昵称和 ID。
窗口直接展示斗鱼官方独立登录页，提供 App 扫码、密码及验证码登录。
已登录的账号菜单可选择「登录其他平台」；账号栏优先展示 B 站，否则展示斗鱼，头像角落显示平台图标。
导入列表时点击关注栏「导入关注」，选择「斗鱼」后点击「读取关注」，勾选要加入软件的直播间。
后台读取所有分页，保留未开播主播，重复导入不会重复添加；不自动加入播放格子。
斗鱼初版仅接入斗鱼；当前版本也提供虎牙与抖音关注导入。
可选择记住登录，Windows 下使用当前系统用户的 DPAPI 加密保存至软件目录
`utils/accounts/douyu.bin`；「退出账号」清除本机登录状态，不删除已导入关注。
浏览器仅在主动导入时打开；登录 Cookie 用于斗鱼官方关注和取流接口，不传给 CDN、FFmpeg 与弹幕。
关注接口来自[斗鱼官方关注页](https://www.douyu.com/directory/myFollow?from=normalFollow)，
属于网页接口，可能随网站调整。实际账号的完整列表仍需登录实测。

- 关注分页离线回归：`python tests/check_douyu_follows.py --host ../DD_Monitor_CE`。
- 宿主登录、加密存储及取消回归：`python dev/selfcheck_platform_follows.py`。
- 统一账号入口、优先级及横竖屏显示回归：`python dev/selfcheck_accounts.py`。

虎牙登录入口使用官网 `evt_fe=login` 参数自动弹出官方登录框。
本体仓库 `python dev/selfcheck_domestic_follows.py` 覆盖官网 WUP、分页、未开播账号、
去重、异常响应、取消及真实 WebEngine 请求桥；测试使用模拟账号，不访问用户保存的凭证。
抖音关注打开官网个人页的关注面板，优先读取面板已经加载的账号数据，
兼容监听官网自行发出的 XHR/fetch 响应；滚动间隔避开官网的防抖，正常加载下一页。
不自行构造关注请求；只在官网明确显示分页结束或返回结束标记后完成导入。
读取期间保留网页可见以处理验证；找不到入口时可手动点开数字旁的「关注」再读取。
自动打开列表时排除侧栏的信息流导航，只点击个人页已经可操作的关注计数。
读取中可停止、切换平台或退出账号；取消后不会接收迟到的读取结果。
关注导入仅加入官网提供直播间号的账号，普通关注账号不会作为直播间加入。
成功读取的抖音关注按账号加密保存；记住登录时，重启后直接进入上次的选择列表。
需要更新列表时点击「重新读取」；退出账号或取消记住登录会清除该缓存。
房间资料、视频和弹幕共用主播身份与官方分享页数据，不再因直播网页要求验证而阻断已读取的关注。
弹幕握手携带官网返回的访客凭证，资料读取仍可及时取消。
缓存只保留主播身份和房间信息，不保留 Cookie、签名请求地址或直播流地址。
本体仓库 `python dev/selfcheck_douyin_restart_cache.py` 验证加密保存、独立实例恢复、账号隔离和退出清理；
`python dev/selfcheck_douyin_room_source.py` 验证分享页资料、当前内场 ID、直播状态与正常取流入口。
本体仓库 `python dev/selfcheck_douyin_ui_follows.py` 使用本地 HTTP 和真实 WebEngine，
覆盖已显示列表（无请求捕获）、官网防抖翻页、请求监听、跨页去重、未开播、
账号/关注与粉丝/搜索隔离、入口缺失、不完整列表、异常与取消。
抖音登录与关注统一使用主站浏览器会话，通过 `user/profile/self` 确认主站身份，
不再用直播站身份判断主站已登录；抖音登录浏览器禁止外部协议跳转，避免唤起商店或客户端。
