# CHZZK 人工验收

> 类型：指南 ｜ 状态：草案 ｜ 适用版本：chzzk_live 0.1 ｜ 更新：2026-11-16 ｜ 读者：维护者

本清单用于 [PR #67](https://github.com/Lanpropro/DD_Monitor_Plugins/pull/67) 的公开直播验收。维护者于 2026-11-19 确认正常播放。配套本体需支持平台替代迁移接口及 CHZZK 媒体转发；日常验收从本体根 `run.cmd` 启动。离线测试通过不能代替以下真实操作。[PR #76](https://github.com/Lanpropro/DD_Monitor_Plugins/pull/76) 的后续重构不在本次范围。

## 准备

- 在“设置 → 插件”确认 `CHZZK直播`（`chzzk_live`）0.1 已启用；未安装时导入本 PR 源码构建的 `chzzk_live-0.1.zip`，按提示重启。不要从尚未发布的商店版本判断本候选。
- 用浏览器找到一个不要求登录或年龄验证、正在直播的公开频道，确认官网有声音、画面及可选画质。复制 `https://chzzk.naver.com/live/<32位十六进制频道ID>`；另备一个确实存在但未开播的频道。
- 记录本体版本／源码提交、插件版本、频道链接、验收时间及是否使用代理。同一轮比较保持网络与代理不变。原始签名媒体地址、Cookie、令牌不放进反馈。

## 操作与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1. 添加与资料 | 添加直播链接，查看关注卡片；再用同频道主页 `https://chzzk.naver.com/<频道ID>` 检索 | 正确识别为 CHZZK，同一频道身份一致；名称、标题、头像、封面和开播状态与官网相符，不产生两个平台来源 |
| 2. 起播与声音 | 将频道拖入空格子，先保持“自动”播放至少 2 分钟；取消静音并调节音量 | 有连续画面和声音，音画同步，无长期转圈、黑屏或重复声音；自动模式可从低档起播，不要求立即到最高画质 |
| 3. 手动画质 | 在实际画质菜单中选最低视频档播放约 1 分钟，再选最高可用 H.264 档持续 10 分钟；若有 1080p，必须单独检查 | 档位与实际流分辨率相符，切换后能恢复播放，声音正常，画质不无故跳回；记录转圈次数、持续时间及出错提示。只过低画质不能记为高画质通过 |
| 4. 预览隔离 | 格子保持手选高画质，开启悬停预览并反复移入／移出关注卡片 | 预览有画面且静音；关闭后消失，不改变格子手选画质，也不多出一路声音。若当前设置关闭预览，应先开启再验收 |
| 5. 停止与重播 | 停止该格子，等待声音结束，再拖入同频道播放，重复 3 次；其中一次关闭播放窗口 | 每次都能停止并重新播放，无残留声音、重复播放或关闭后重新弹出的窗口；重播不长期使用过期流地址 |
| 6. 本地关注与重启 | 关注频道并调整分组／手动画质，正常退出，再从根 `run.cmd` 启动 | 频道、分组及所选画质模式保留，状态能刷新，不重复增加频道；保存的是频道身份，不要求保存某次媒体地址 |
| 7. 未开播与错误 | 添加已存在的未开播频道；另尝试 `https://chzzk.naver.com/video/123` 及明显无效的频道 ID | 未开播频道显示未开播，不错误播放；回放／错误链接被拒绝或明确报错，不冒充直播。若真实发生网络失败，记录错误，不将其当作已证实未开播 |
| 8. 禁用与共存 | 禁用 CHZZK 插件并重启；检查原 Twitch／YouTube 状态，再启用 CHZZK 并重启 | 禁用后 CHZZK 不被海外组合包重新注册；原关注数据保留，Twitch／YouTube 原启用状态不被改变；重新启用恢复 CHZZK，无重复平台 |

## 功能边界与判定

本候选提供公开直播、本地关注、资料、画质和预览，不提供 CHZZK 登录、官网关注导入、聊天／弹幕、回放或年龄验证。若遇到仅登录或年龄验证可看的频道，应明确提示限制，不反复尝试登录或绕过限制；此类频道不替代公开频道验收。

历史真实样本仅确认过 144p 静音解码，1080p 曾出现 `ReadTimeout`，因此步骤 2 的声音和步骤 3 的最高档持续播放必须分别反馈。出现缓冲时保留频道、时间、所选档位、实际分辨率、代理状态及错误摘要；同频道在官网的表现作为对照，不能只凭一次失败推断平台或网络根因。

反馈格式：`本体提交／插件版本；频道；时间；代理开或关；步骤 1～8 各自通过／失败／未测；画质、声音和持续时长；错误与复现操作`。只有实际执行通过的项目记为通过，未测或受当前直播条件限制的项目继续保留。
