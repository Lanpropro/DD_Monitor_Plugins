# 从下载到第一面直播墙

## 启动软件

1. 从[下载页](/download)获取 Windows 便携版 ZIP。
2. 将整个 ZIP 解压到一个可写目录，不要在压缩包里直接启动。
3. 双击 `DD监控室CE-v0.2.exe`。保留 `_internal` 等随包目录，它们包含运行所需组件。
4. 首次启动时添加 B 站直播间号或官方链接；需要导入 B 站关注时再扫码登录。
5. 从关注列表拖入画面格子，选择布局，调整各路音量。

源码启动方式、VLC 运行库准备与完整依赖见[软件 README](https://github.com/Lanpropro/DD_Monitor_CE#快速开始)。

## 安装插件

::: warning 先确认配套软件
公开 v0.2 EXE 缺少两个 1.0 插件所需模块。请先阅读[兼容说明](/download#插件兼容性)，确认自己使用的是配套更新的软件。
:::

1. 到[插件列表](/plugins/)下载需要的插件 ZIP，名称应为 `domestic_live-1.0.zip` 或 `global_live-1.0.zip`。
2. 打开软件「设置 → 插件」，点击「装载插件…」选择 ZIP，也可将 ZIP 拖入插件页面。
3. 确认插件出现在列表中，勾选启用。
4. 点击「保存并重启」。重启后再添加该平台直播间。

每个 ZIP 顶层只有与插件 ID 相同的文件夹。**不要导入 GitHub 的 Source code ZIP**，也不要将两个插件包合并。

手动安装时，将对应插件文件夹复制到软件的 `plugins_user/<ID>`，再在设置中启用并重启。

## 添加其他平台直播间

- 国内平台：使用官方完整直播间链接，或 `huya:房间号`、`douyu:房间号`、`douyin:房间号`。
- Twitch：使用 `https://www.twitch.tv/频道名` 或 `twitch:频道名`。
- YouTube：使用直播视频链接，或频道的 `/live` 链接。关注频道可跟随其下一场直播；视频链接固定到单场直播。
- 纯数字房间号仍按 B 站处理。具体格式见[国内插件](/plugins/domestic_live)和[海外插件](/plugins/global_live)。

添加后将关注卡片拖入格子。聊天弹幕需要选择包含弹幕格的布局；弹幕会跟随主画面。

## 升级或禁用插件

同 ID 的插件不能重复导入。升级时先通过插件页面删除旧版本，再导入新 ZIP，勾选后保存并重启。操作前建议退出软件并备份自己本机的软件目录。

如果只是暂时不用，取消勾选并保存重启即可。两个直播插件禁用后，对应关注与格子转为暂存；重新启用后恢复，已被其他内容占用的格子会保留新内容。

国内插件的旧 ID 是 `huya_watch`，现为 `domestic_live`。配套最新版软件会迁移旧启用选择和插件设置，保留原关注、位置与画质；不要把两者当作两个独立插件同时安装。

## 常见问题

### 插件导入成功，却不能播放？

先确认软件构建是否包含插件所需接口，再检查网络能否访问平台、直播是否正在进行，以及 FFmpeg 是否可用。便携版随包提供 FFmpeg；源码环境需按软件说明安装依赖，包含固定版本 `streamlink==8.6.1`。

### 有画面，没有聊天？

选择弹幕布局，确认主画面是对应平台直播间。部分 YouTube 直播关闭聊天。插件只读取公开聊天，不发送消息；平台协议变更也可能影响连接。

### 画质名称为什么不是统一的 1080P？

插件显示直播间实际提供的档位。虎牙的蓝光码率名称不等于像素分辨率；其他平台也以返回的尺寸、帧率或档位名称为准。海外插件额外提供自动画质。

### 海外直播加载失败？

确认当前网络可访问相应平台。登录限制、年龄验证、会员内容或地区权限不在插件匿名公开直播的支持范围内。
