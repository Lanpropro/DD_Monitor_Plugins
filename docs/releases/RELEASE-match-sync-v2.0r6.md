# 比赛二路同步 v2.0r6

发布日期：2026-11-02（本地构建，待维护者实测后决定是否发布 Release）

## 本次改了什么

- **自动框选全过程写进宿主日志**：前缀 `自动框选：`，包含点击时的来源与房间列表、是否找到对应行、取帧参数（`retries`、解码器、`pip_stamp`）、取到的帧数与每帧尺寸、识别结果、最终写入 `row.pip_crop` 的框；取帧或识别抛异常时连同异常文本一起记录。
- **检测输入导出到磁盘**：`%TEMP%\match_sync_autocroprame-<时间戳>.png` 与 `result.txt`（`frames=N rect=…`），只保留最近四张，重新导出问题现场不用再录屏。
- **装载日志带版本号**：`比赛二路同步 2.0r6 已就绪…`，版本从插件自己的 `plugin.json` 读取，用来确认宿主实际加载的版本。

## 没有改什么

- 识别算法（人脸聚类 + 边框打分 + 贴边吸附）、取帧回退到画中画当前帧、提示停留 6–8 秒、手动框选与中心锚定行为都与 `2.0r5` 一致。
- 配置格式不变，`2.0r5` 的 `config.json` 可直接沿用。

## 兼容性

- 宿主：DD 监控室 CE 0.6（`ddm` 插件接口版本不变）。
- Python 3.11、PySide6 6.11；`opencv-python` 可选，缺失时人脸检测关闭，其余照常。

## 安装

1. 下载 `match_sync-2.0r6.zip`（GitHub 自动生成的 Source code ZIP 不能当安装包）；
2. 在 DD 监控室 CE 的插件页导入该 ZIP；
3. 在插件列表里启用「比赛二路同步」，版本显示 `2.0r6`。

## 发布状态

## 排查方法

点一次「自动框选」后：

1. 打开 `E:\DDMonitorCE-v0.6-exe\DD监控室CE\logs\ddm-<日期>.log`，搜索 `自动框选：`；
2. 若日志里连「点击」都没有，说明按钮回调没触发（前端事件问题）；
3. 若有「取到 0 帧」，看 `pip_stamp`/解码器状态；
4. 若有「识别 None」，把 `%TEMP%\match_sync_autocrop` 里的帧与 `result.txt` 一起保留，可直接按导出的帧复算。
