# 抖音直播 v1.0

抖音直播播放、登录关注及实验性的官网弹幕输入；官网输入取决于登录和网页状态。

本次从原组合插件中独立发布，可以按平台安装、更新、启用和回滚。保留本地最新平台协议、账号及播放修复，并提供独立插件图标。

请使用DD监控室CE 0.8或更新版本，建议先升级到0.8热修复1，获得完整的独立平台商城识别修复。安装后首次启动迁移旧组合包中声明的设置和启用状态，沿用原有账号、关注、房间ID和分组；不需要重新添加主播。安装新平台插件后，不再由旧组合包重复注册对应平台。

安装包为 `douyin_live-1.0.zip`，在本体插件管理中导入。包内包含所需的平台协议组件，无需另装组合包。原组合插件的已发布标签及附件保持不变。

源码与许可见仓库及随包LICENSE/NOTICE。真实平台可用画质、登录及网络限制以平台实际返回为准；本次发布不增加自动发送弹幕行为。
