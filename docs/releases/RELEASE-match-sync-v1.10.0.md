# 比赛二路同步 v1.10.0

## 变更

1. 画中画新增「自动跟随摄像头」：勾选后在副直播间画面里自动识别摄像头窗口，按 1.5 秒的节拍把小窗裁剪区域移过去，主播挪动摄像头位置时小窗跟着走，不必手动回框。
2. 识别以当前框选区域为起点：先用上一帧的裁剪内容做模板匹配跟住窗口，跟丢后按边框与内部画面差异重新找窗口，两者都没有结果时沿用上一次裁剪，不会突然闪回整个画面。
3. 取消勾选回到手动框选；手动重新框选会清掉自动结果。识别只在本地缩略图上做，不额外拉流，不影响声音混合、时间对齐与自动匹配。
4. 画质按钮、声道按钮、分隔条与对齐行为不变。

## 安装

先删除旧的 `plugins_user/match_sync`（或设置页里的卡片），再装载 `match_sync-1.10.0.zip`，保存并重启；卡片应显示「比赛二路同步 / 1.10.0 / 已加载」。
