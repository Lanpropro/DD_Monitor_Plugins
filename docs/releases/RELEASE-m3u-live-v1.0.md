# IPTV Play v1.0

需要支持通用频道列表、预设和关注卡片台标接口的 DD 监控室 CE。初版 v0.8 缺少这些接口。

- 从「添加直播间」面板的电视图标查看 CCTV-1、CCTV-5+、CCTV-6 和 CCTV-13 预设，点选即可加入当前关注文件夹。
- 支持在线 M3U、本地 M3U／M3U8 文件和公开 HLS。多频道列表支持按名称搜索、按分组筛选并勾选导入。
- 卡片显示频道名称和可用台标。首次正常播放生成首帧封面。关注栏刷新会检测可用频道，并按「直播优先」排序。
- 原生播放器显示实际分辨率。节目内容、清晰度和预设线路可用性取决于频道源。

在配套宿主的插件管理中安装 `m3u_live-1.0.zip`，启用后重启。已导入的频道可以继续使用。
