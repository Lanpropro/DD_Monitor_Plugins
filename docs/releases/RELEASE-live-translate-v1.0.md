# 实时翻译 v1.0

实时翻译可在所选直播格显示本地识别原文和译文，支持本地翻译、兼容 API 和仅显示原文。1.0 增加商店图标，默认采用两套 1.7B 模型，并保留 R13 音乐与清唱检测、短上下文、房间术语和译文复核。

## 默认模型

| 用途 | 模型 | 权重来源 |
| --- | --- | --- |
| 语音识别 | Qwen3-ASR 1.7B INT8，ONNX | [Qwen 上游模型](https://huggingface.co/Qwen/Qwen3-ASR-1.7B) 和 [sherpa-onnx 格式的量化导出](https://huggingface.co/thieunv-asilla/sherpa-onnx-qwen3-asr-1.7B-int8) |
| 文本翻译 | Qwen3 1.7B Q8_0，GGUF | [Qwen 官方 GGUF 权重](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF) |

## 安装与使用

在插件商店安装“实时翻译”，或者在本体“设置 → 插件”导入 `live_translate-1.0.zip`。首次启用且模型尚未准备时，点击“下载默认模型”。两套权重合计约 4.24 GB，连同音乐检测模型和运行库约下载 4.5 GB，建议预留 6 GB 磁盘空间。

下载完成后，插件会填入识别、翻译和运行库路径。本地模式可离线运行。升级已有预览版时会保留用户选择的模型路径，可在“模型 → 模型准备”下载默认 1.7B，或继续使用已配置的模型。

自动准备需要 Windows x64、采用 CPython 3.12 的 DD 监控室 CE 宿主。达到插件清单的最低版本 0.7.3 后，实际字幕显示位置仍取决于宿主可用的字幕接口。识别准确率、译文和延迟随直播内容及机器负载变化。
