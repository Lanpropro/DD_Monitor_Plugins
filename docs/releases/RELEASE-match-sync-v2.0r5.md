# 比赛二路同步 v2.0r5

本版本基于原作者 `1.5` 修改，修复 `2.0r3` / `2.0r4` 引入的每帧异常，并保留自动框选的全部修正。

## 修复

- **`2.0r3` / `2.0r4` 每一帧都在抛异常。** 提示辅助方法 `say()` 与 `_status_says()` 被误加进了 `CompactStatus` 类，而 `Viewer.render()` 里调用的是 `self._status_says(...)`，因此每 33 毫秒都会报
  `AttributeError: 'Viewer' object has no attribute '_status_says'` 并中断 `render()`——状态行、画中画、同步与弹幕刷新全部停更，界面上表现为「点了没反应，也没有任何变化」。
  两个方法已移入 `Viewer` 类，`render()` 恢复正常执行。
- 自动框选的取帧回退、重试与报错提示保持不变：取样全空时用画中画正在显示的那一帧；仍取不到时 250 毫秒后重试两次；取帧/识别/写裁剪出错都会在状态行停留 8 秒说明原因。
- 识别参数的修正保持不变：摄像头贴画面边缘时只量得到两条边，旧逻辑要求三条边导致全部候选 0 分；现在两条边即可计分，候选高度比从「3.0–4.2 倍脸高」放宽到「1.8–3.6 倍脸高」，并取边框分最高的候选。

## 兼容性

- 相对 `2.0r4` 只修类归属错误，识别算法、取帧逻辑、`config.json` 里的 `pip` 配置都没有变化。
- 识别依赖 OpenCV 自带的人脸级联；没有 OpenCV 时按钮仍在，点击会提示改用手动框选。
- 只对 CNCS 解说一哥 `6657` 直播间的画面做过适配测试，其他布局可能认不出；认不出时只提示，不改动现有裁剪。

## 安装

1. 下载 `match_sync-2.0r5.zip`（GitHub 自动生成的 Source code ZIP 不能当安装包）；
2. 打开 DD 监控室 CE 的「插件」→「安装插件」，选择该 ZIP；
3. 在插件列表里启用「比赛二路同步」，版本显示 `2.0r5`。
