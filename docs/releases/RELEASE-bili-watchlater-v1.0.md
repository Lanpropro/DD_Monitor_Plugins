# B站稍后再看 v1.0

在DD监控室CE中浏览和管理B站稍后再看，将视频置入画面墙，复用本体登录态、播放器和弹幕。

- 列表与大卡片网格，支持搜索、观看筛选、排序、列数和卡片大小设置；完成状态使用图标。
- 点击视频后在当前布局缩略图中选择空格置入或替换内容；设置和选位均在同一窗口内完成。
- 关注栏观看顺序支持双击播放、拖入格子和拖动排序；排序只影响软件内连播，可选择是否包含已看完视频。
- 支持分P、画质切换、字幕、历史弹幕、进度拖动及有数据时的悬停预览，适配主墙、全屏和画中画。
- 设置自动保存，可选择入格播放、连播、提前加载及正常退出后恢复格子和进度。浏览位置只在本次软件运行中保留。
- 删除成功后显示头像和标题，支持逐项／全部撤回；多选提示可展开，撤回保留删除后的本地排序。

请先安装**DD监控室CE 0.8热修复1**或具备相同能力的更新版本，再导入`bili_watchlater-1.0.zip`。原始0.8和0.7.3缺少所需接口；插件会检查并提示升级。清单的数字最低版本0.8还需同时满足共享拖影及实时弹幕来源能力检查。

视频格不会出现在本体直播弹幕来源中，视频自身历史弹幕不受影响。预览使用B站图片帧，不使用本地模型；插件不向B站上传播放进度。预加载默认关闭，仅连播开启时可用，每路最多约10MiB缓存，额外占用内存和流量；真实等待时间取决于网络。
