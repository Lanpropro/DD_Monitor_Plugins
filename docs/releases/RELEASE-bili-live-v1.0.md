# B站直播互动 v1.0

作者：[@reon-nynes](https://github.com/reon-nynes)。感谢作者提供独立的B站直播互动插件；本体维护者完成兼容适配、补充修复与验收。

- 使用本体登录，逐格发送文字弹幕、小表情和大表情；按账号及房间隔离异步响应，失败保留当前草稿。
- 支持分类及分类内表情拖动排序、持久目录缓存与图片缓存复用。
- 支持礼物目录、背包、电池余额、数量和子礼物选择，以及已实现的普通电池盲盒、大航海和装扮流程；不提供充值、SC或自动购买。
- 保留本体Enter聚焦、全屏两步唤出及长按Enter防重复发送。来自[Soraray](https://github.com/Soraray)
- 修复分类拖动图标残留、相邻分类让位和房间号误拖入输入框，改善背包布局及高DPI媒体显示。
- 支持将错误交给本体通知栏；宿主支持时，登录失效通知可点击重新登录。

**赠送提示：部分普通礼物单击即赠送，大表情单击即发送。特殊流程不支持时显示原因；超时不自动重试，结果未确认时先核对余额和背包。**
