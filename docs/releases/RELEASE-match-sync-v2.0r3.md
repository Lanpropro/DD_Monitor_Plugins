# 比赛二路同步 v2.0r3

本版本基于原作者 `1.5` 修改，只修「自动框选」，不改其他功能与配置格式。

## 修复

- **自动框选在真实二路画面上认不出摄像头。** 解说画面贴着画面右上角时，摄像头小窗的上边与右边就是画面边缘，旧逻辑要求至少量到三条边才计分，结果所有候选都得 0 分，点击后毫无反应。现在量到两条边就能打分，候选窗口的高度比从「3.0–4.2 倍脸高」放宽到「1.8–3.6 倍脸高」，并在及格候选里取边框分最高的一个。真实 530×320 二路帧上的识别结果是右上角 `96×57` 的小窗，正好套住人脸与背景。
- **点击后看不到反馈。** 底部状态行每帧都被主画面状态重写，提示一亮就被盖住，看起来像没生效。现在识别结果（成功、认不出、这一路没有画面、还没选来源）会在状态行停留 6 秒，期间的播放状态不再覆盖它。
- **取帧时刻与画中画显示的那一帧对齐。** 原先按 `live_clock()` 取帧，画中画实际显示的是回看/延后处理之后的 `shown_clock + 偏移`，延后量大或整组回看时容易取空、表现为「这一路还没有画面」。

## 兼容性

- 相对 `2.0r2` 只改识别与提示：手动框选、中心锚定、`config.json` 里的 `pip` 配置都没有变化，无需迁移。
- 识别依赖 OpenCV 自带的人脸级联；环境里没有 OpenCV 时按钮仍在，点击会提示改用手动框选。
- 只对 CNCS 解说一哥 `6657` 直播间的画面做过适配测试，其他直播间的摄像头布局可能认不出，认不出时只提示、不改动现有裁剪。

## 安装

1. 下载 `match_sync-2.0r3.zip`（GitHub 自动生成的 Source code ZIP 不能当安装包）；
2. 打开 DD 监控室 CE 的「插件」→「安装插件」，选择该 ZIP；
3. 在插件列表里启用「比赛二路同步」，版本显示 `2.0r3`。
