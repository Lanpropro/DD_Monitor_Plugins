# 比赛二路同步 v2.0.0

本版只修界面布局：弹幕控制台被挤窄后，左侧的房间（主播）选择列会压到输入框上，看起来像「只剩弹幕输入框」。

**修复**

- 紧凑布局下房间选择列恢复独立的一条带，输入框排在它下面，不再重叠。
- 常规宽度下房间列重新固定为 `176 px`（与作者 `1.5` 一致）；此前只限制了最大宽度，列会被输入框挤到 0 宽。
- 切换布局后立即重排并同步控制台高度，不再等下一次无关的窗口尺寸变化才生效。

**兼容性**

- 与 `1.11.0` 功能相同：画中画、自动框选、手动框选边缘贴合、每路画质、声道按钮都不变。
- 配置无需迁移；旧 `follow` 键仍被忽略。

**安装**

先删除旧的 `plugins_user/match_sync`（或设置页里的卡片），再装载 `match_sync-2.0.0.zip`，保存并重启；卡片应显示「比赛二路同步 / 2.0.0 / 已加载」。

**发布状态**

按维护者要求，`2.0.0` 先在本地构建并归档，暂不创建 Tag 与 Release；实测确认后再发布。
