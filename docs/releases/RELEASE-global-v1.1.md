# 海外直播平台 v1.1

本 Release 将海外直播平台从原“多平台插件 v1.1”中单独列出，安装包与原发布附件完全相同，版本不变，无需重复升级。

- 支持 Twitch、YouTube 关注卡片、格子播放、自动选择画质、静音悬停预览与聊天弹幕。
- 提供海外平台 Logo 显示开关，仅在装载插件后显示于常规设置，位于开播提醒下方。
- 安装及启用更改按软件提示重启后生效，保留用户配置。

安装包：`global_live-1.1.zip`。

SHA-256：`04b4fa6c24d17b44143c3b091826b01a4d68db97944c685f2690716132682094`。

此 Release 只提供海外直播平台插件；国内直播平台和比赛二路同步均在各自独立的 Release 中发布。
