# 比赛二路同步 v1.7

画中画小窗去掉边框。

## 变更

- 画中画不再绘制蓝色描边：小窗就是画面本身，边缘不再有高亮框，和主画面衔接更干净。
- 右下角缩放手柄只在鼠标移到小窗上或正在拖动时出现，静止时不显示任何装饰。
- 位置、大小、裁剪区域以及拖动/缩放方式都不变，仍随插件设置保存。

## 安装

1. 通过「设置 → 插件」删除已安装的旧版 `match_sync`。
2. 「装载插件…」选择 `match_sync-1.7.zip`（或把 ZIP 拖入插件页面）。
3. 保存并重启；插件卡片应显示「比赛二路同步 / 1.7 / 已加载」。

源码版需宿主已更新 `requirements.txt` 中的 PyAV 与 NumPy；EXE 版需要包含这两个组件的新版完整程序。
