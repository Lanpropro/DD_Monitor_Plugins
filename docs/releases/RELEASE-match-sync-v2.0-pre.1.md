# 比赛二路同步 2.0 preview

**如果播放卡顿，可以尝试关闭滚动弹幕观看。我们正在努力优化播放和弹幕的流畅度。**

这次预览修复了比赛二路加载 YouTube 自适应直播时无法出画的问题。比赛二路现在会独立取流并正确接管媒体源。原反馈的直播间欢迎帮忙复测。 [问题 #269](https://github.com/Lanpropro/DD_Monitor_CE/issues/269)

预览也包含 1.7.0 以来的主画面重绘、画中画裁切和层级、画质切换等改进。

下载 `match_sync-2.0.zip`，在 DD 监控室 CE 的「设置 → 插件 → 装载插件」导入后重启。建议使用已验证安装和升级的本体 v0.9.1。预览包通过本页手动下载。
