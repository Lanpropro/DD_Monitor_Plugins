# 实时翻译 v0.1

开发预览。对用户主动选择的单个直播间音轨做本地识别，并按设置显示原文、译文或两者。一次只服务一个直播间。

## 版本选择

**源码版：`live_translate-0.1.zip`**

- 可通过 DD监控室CE 的“设置 → 插件 → 装载插件…”直接安装。
- 不包含识别模型、翻译模型、llama.cpp 和 Python 运行环境。
- 安装后在插件目录运行 `prepare_runtime.py` 准备本地模型；也可只使用 API 翻译或仅原文模式。
- 由仓库 `tools/build_plugins.py` 从 Git 跟踪文件构建，并通过 `tests/check_packages.py` 校验。

**离线完整包：`live_translate-0.1-offline.zip`**

- 包含 ReazonSpeech 日英识别、Silero VAD、Qwen3 0.6B Q8、llama.cpp `b12211` 和 Python 3.12 便携运行环境。
- 超过宿主插件导入器的 100 MB/256 文件限制，不能从“设置 → 插件”直接导入。
- 解压后关闭宿主，在解压目录执行：

```powershell
.\install.ps1 -HostRoot "E:\path\to\DD监控室CE"
```

目标已存在同名插件时脚本会拒绝覆盖；确认替换后加 `-Force`。脚本只写入宿主的 `plugins_user\live_translate`，不修改账号、其他插件或宿主源码。

## 主要功能

- 本地识别在 `DD监控室CE.exe` 进程内以后台线程运行；FFmpeg 和本地翻译服务是与宿主同名的 native 子进程，停止后回收。
- 字幕优先嵌入当前直播格；旧宿主自动回退独立字幕窗。
- 字幕支持显示开关、原文/译文组合、行数、字号、透明度、宽高、逐行文字背景、全屏显示和播放栏避让；PiP 不显示。
- 更换画质、线路或签名地址后自动接续传译，不重新加载本地翻译模型。
- API Key 使用当前 Windows 用户 DPAPI 加密保存，不写入明文配置。

## 宿主兼容

- 最低清单版本：DD监控室CE `0.7.2`。
- 进程内识别、进程归组和独立字幕窗使用当前公开插件接口。
- 内嵌字幕需要宿主提供 `set_tile_caption()` / `clear_tile_caption()`；接口缺失时不会报错，继续使用独立字幕窗。

## 已知限制

- 当前不延后画面，也没有按播放器 PTS 对齐字幕；不承诺 2 秒/5 秒端到端延迟。
- 本地小模型可能漏译或措辞不准；真实直播精度、CPU、内存和连续 30 分钟趋势仍需按实际硬件采样。
- 不采集系统混音，不支持多房间并发，不内置代理内核。
