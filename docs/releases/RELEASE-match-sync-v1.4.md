# 比赛二路同步 v1.4

## 增加了对于4k阿B直播流的适配

- 优化 4K 采集与缓存播放的并行解码，我们现在可以观看4k的主画面同时畅听你希望听的二路解说了

## 尝试环节了使用插件时的卡顿

- 视频完全覆盖画面时减少背后皮肤的重复绘制，保留透明留边显示。
- 改善多路播放时的界面响应：读取音频时钟不再等待混音锁；连续匹配失败按 2/4/8 秒逐步降低搜索频率，手动重试和重连会重置等待。
- 减少匹配候选的重复对象及无关界面事件处理，后台搜索适时让出执行机会，保留原有匹配证据和精度判定。

## 问题修复

- 修复二路全屏底部仍显示任务栏的问题：使用无边框窗口并向 Windows 标记全屏；Esc、切换、停止或关闭后撤销标记并还原画面与鼠标控制，不全局隐藏任务栏、不永久置顶。

该次插件配合暂未发布的v0.5.1版本可以实现4k主画面的情况下同时3路对齐，可能需要相应的配置，会尝试尽量的优化。非常感谢你的使用
