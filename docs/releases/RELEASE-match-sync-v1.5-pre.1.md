# 比赛二路同步 v1.5

预发布版本：`match-sync-v1.5-pre.1`。插件清单版本为 `1.5`，本次用于公开测试，不替换正式版更新目录。

- 增加最多十分钟整组回看：主画面、各路声音和弹幕同步回退，后台继续直播和自动对齐；支持精细时间轴、时间输入/拖动调节与返回直播。
- 增加副路悬浮裁切：自由移动、等比缩放、重新裁切及全屏恢复；显示来源主播头像，修复缩放突跳、画面叠加、移动/关闭失效、圆角锯齿和右侧边缝。
- 改版弹幕控制台：头像选择单人或多人发送，统一输入框完成发送与书签暂存；保留草稿、暂存文字持久化、点击发送、长按排序、删除及弹幕转存。
- 统一深浅主题、按钮悬停反馈、图标与主播选中动效，修复画面滚动弹幕不显示的问题。
- 增加共同游戏区域匹配备用流程：全画面匹配失败时尝试自动识别共同动态区域，不依赖计时器。不同视角缺少共同内容时仍可能无法对齐。

安装包：`match_sync-1.5.zip`。在软件插件管理中导入，按提示重启；手动覆盖时先完全退出软件，将 ZIP 内的 `match_sync` 文件夹覆盖至 `plugins_user/match_sync/`，保留用户配置。需要 v0.6 或更新的配套本体及 PyAV、NumPy、Qt/FFmpeg 依赖；发送互动还需对应平台互动插件及登录状态。

本次仅发布二路插件。未包含 AI 超分、分音轨录制或纯解说自动对齐方案。

验证：插件包完整性、Git 源码一致性、宿主安装与升级保留数据检查；根目录 run.cmd 隔离复测覆盖发送/暂存、十分钟回看、PCM 音画对齐、悬浮裁切、共同区域匹配及无托盘提示退出。未读取真实账号或发送真实弹幕。当前功能已获用户验收；不同设备、多路高分辨率和不同游戏布局仍请在预发布版中持续反馈。
