# 比赛二路同步 v2.0r4

本版本基于原作者 `1.5` 修改，只修「自动框选」，不改其他功能与配置格式。

## 修复

- **实机上点「自动框选」仍然毫无反应。** 取帧走的是 `picture_at()`，而图片是由后台线程异步解码的：取样时刻还没解出来就返回 `None`。四个取样点（0.75 / 0.5 / 0.25 / 0 秒前）全落空时 `frames` 是空列表，检测器根本没被调用；提示又被每帧刷新的播放状态盖掉，于是看起来「点了没反应」。
  - 现在取样全空时，直接拿**画中画里正在显示的那一帧**（`canvas.pip_image`）作为输入——用户眼睛看到的就是它，一定拿得到；
  - 仍然取不到时，250 毫秒后重试，最多两次；
  - 取帧、识别、写裁剪任意一步出错，都会把原因写在状态行并停留 8 秒，不再静默失败。
- **取帧返回值补了 `QImage` 类型校验**：图片缓存命中时返回的是 `(帧号, 图片)` 元组，旧代码可能把元组直接当图片传给检测器。
- 沿用 `2.0r3` 的识别修正：摄像头贴画面边缘时只量得到两条边，旧逻辑要求三条边才计分，全部候选得 0 分；现在量到两条边就能打分，候选窗口高度比从「3.0–4.2 倍脸高」放宽到「1.8–3.6 倍脸高」，并取边框分最高的候选。

## 兼容性

- 相对 `2.0r3` 只改取帧与报错路径，识别算法参数不变；`config.json` 里的 `pip` 配置无需迁移。
- 识别依赖 OpenCV 自带的人脸级联；没有 OpenCV 时按钮仍在，点击会提示改用手动框选。
- 只对 CNCS 解说一哥 `6657` 直播间的画面做过适配测试，其他布局可能认不出；认不出时只提示，不改动现有裁剪。

## 安装

1. 下载 `match_sync-2.0r4.zip`（GitHub 自动生成的 Source code ZIP 不能当安装包）；
2. 打开 DD 监控室 CE 的「插件」→「安装插件」，选择该 ZIP；
3. 在插件列表里启用「比赛二路同步」，版本显示 `2.0r4`。
