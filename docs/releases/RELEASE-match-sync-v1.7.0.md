# 比赛二路同步 v1.7.0

候选发布说明：本版本基于公开的 `match-sync-v1.6.1`，源码候选位于 `function/match-console-notices` 分支。当前仅完成源码、安装包和验证准备，尚未创建公开 GitHub Release 或插件商店目录。

## 计时器辅助对齐

- 每路偏移控制区提供计时器图标入口，打开计时器对齐窗口时自动获取一次当前预览；缺帧来源才从现有缓存后台采样。
- 支持正计时和倒计时，首帧输入接受 `0130`、`130` 或 `01:30`；计算后展示逐路建议提前/延后与采样误差，确认应用后复用现有手动偏移。
- 计时器窗口改为无标题栏、连续圆角、普通深浅主题材质，顶部空白区域可拖动；移除每路独立开关和重复的顶部计时器按钮。
- 采样任务保持单任务、可取消和按需执行，不进入常驻观看 OCR 或额外拉流流程。

## 对照画面与全屏控制

- 对照微调沿用控制台的主题、圆角和间距；两路画面按原视频比例显示，布局保持纵向对齐，头像作为每路标识。
- 全屏控制复用宿主的透明渐变控制栏与空闲隐藏行为，进入和退出全屏恢复原窗口属性；按钮和图标保留悬停/点击反馈。
- 对照和计时器相关职责继续由独立模块承接，保留旧入口兼容。

## 播放恢复与稳定性

- 主路缓冲恢复沿用安全余量，副路缺少确认或缓存时不拖停主路。
- 断流恢复中的计时器采样在原期限内重试，过期来源和旧任务不会覆盖用户当前操作。
- 延后计时器窗口的历史取帧，优先复用当前主画面或对照预览；关闭窗口可取消未完成采样。

## 兼容与安装

- 最低本体版本：`0.6`。
- 安装包：`match_sync-1.7.0.zip`。在「设置 → 插件」装载，保存并按提示重启；旧版设置保留。
- 本版本不改变其他平台插件的版本和安装包。

## 验证与限制

- 已执行计时器、对照布局、全屏、模块边界、编译、插件打包及隔离安装检查。
- 检查使用替身数据和隔离配置，不读取真实账号、不发送弹幕；真实直播长时间播放、低配置机器上的卡顿和 OCR 识别效果仍需人工验收。
- 正式发布前需核对候选 ZIP 的 SHA256、Git 标签源码和插件商店目录中的版本/大小/校验值完全一致。
