# 比赛二路同步 v1.6

是一个比较简单的功能修复以及补全版本

## 新增功能

- 拖动进度条时会同步打开预览视窗，可以更清楚得找到你想要回放的时间了。视窗可以在控制台设置中调整大小与位置。
- 新增了多轨录制的mp4格式转码，以及开始结束保存录制的通知提示。

## 功能补全

- 优化了控制台的设置页面UI。
- 优化了L/R声道显示的控制，现在可以关闭两个声道来关闭该路声音了。
- 当主画面短时内多次耗尽缓冲时，会提示您建议切换主画面以获得更好的观看体验

## 修复

- 修复预览在鼠标悬停时启动，以及设置示意图与实际画面比例不一致的问题。
- 弹幕右键操作改用非阻塞菜单，避免嵌套菜单循环影响播放交互。
- 取流失败分类排除地址中的干扰字样，减少错误归因。
- 增加取流阶段、预览生命周期、音频供给及混音阶段诊断，并支持保留跨日志轮转的采集证据，方便定位长期播放问题。
