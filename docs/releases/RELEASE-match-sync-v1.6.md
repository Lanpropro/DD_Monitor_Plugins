# 比赛二路同步 v1.6

本地打包版本，尚未上传 GitHub Releases。维护者可另行补充正式发布说明。

包含 1.5 后的 MKV／MP4 多音轨录制选择、录制开始与完成通知、L／R 静音联动、仅拖动时的连续回看预览及可拖拽比例设置、扩大重排的设置页、控制台缓冲反复耗尽提醒，以及消息调度、音频控件读取和预览缓存优化。

连续预览复用已解码帧，以约 8fps 准备低分辨率小图，不额外拉流；实际覆盖与流畅度受负载影响。本地功能回归不代表低配置实机或真实直播性能验收。

插件安装包为 `match_sync-1.6.zip`，最低宿主版本维持 `0.6`。使用已包含 PyAV 和 NumPy 的完整宿主；本包不包含宿主、用户配置、账号、日志或录制。
