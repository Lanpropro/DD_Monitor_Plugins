# 比赛二路同步 v1.11.0

## 变更

1. 画中画新增「自动框选」：在副直播间画面里识别摄像头窗口，直接把小窗裁剪区域设成识别结果，省掉手动拖框。
2. 开启画中画时自动尝试一次（延迟 1.2 秒，仅在裁剪区域仍是整帧）；识别不到保持原状，随时可以点「框选画面」手动微调。
3. 识别在多档缩略图上择优：优先按四条边的配对关系找独立窗口，没有矩形时用 OpenCV 人脸框兜底；只在本地缩略图上做一次，不额外拉流、不影响声音混合与时间对齐。
4. 手动「框选画面」松手后四条边会自动贴合最近的画面分界（范围是画面的 4.5%），修掉拖框时常见的多裁 / 少裁；自动框选的结果同样会再贴合一次。
5. 移除 1.10.0 的「自动跟随摄像头」与周期跟踪——摄像头窗口通常一个赛事只挪一次，改为按需一次性框选。
6. 画质按钮、声道按钮、分隔条与对齐行为不变。

## 安装

先删除旧的 `plugins_user/match_sync`（或设置页里的卡片），再装载 `match_sync-1.11.0.zip`，保存并重启；卡片应显示「比赛二路同步 / 1.11.0 / 已加载」。
