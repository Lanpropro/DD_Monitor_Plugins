# 比赛二路同步 v2.0.3

对外版本名为「比赛二路同步 2.0」。安装包版本为 2.0.3，最低本体版本为 0.9.1。

- 好友同看最多三人。大家播放同一主画面，通过六位码加入，用共同画面复核进度。成员列表显示公开头像和昵称。复核与退出按钮固定在底部，切到弹幕页后同看继续。
- 播放控制台可一键校准共同比赛声。单路应用的声音补偿显示在对应控制卡片，可独立撤销。
- 回看最长可选 30 分钟，按实际缓存写入量动态估算磁盘空间。短暂重连可接续回看，鼠标悬停时从缓存补取缺失的预览。
- 弹幕栏可用主播头像标识来源。滚动弹幕保留颜色区分。
- 新安装默认使用 D3D11 主画面渲染。已保存的渲染选择继续生效。

已有 2.0.2 的用户可从「设置 → 插件」更新，重启后启用。首次安装可使用插件商店或装载 `match_sync-2.0.3.zip`。

好友同看提供本机建房与云端建房。新版成员资料已通过本机房间和本地云端服务验证。公网房间服务升级后可分发头像和昵称，旧房间按平台与 ID 显示。
