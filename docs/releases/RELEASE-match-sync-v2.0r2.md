# 比赛二路同步 v2.0r2

基于原作者 `match_sync-1.5` 的修改版。本版只恢复并重做画中画的「自动框选」，手动框选、中心锚定与其他功能与 `2.0r1` 相同。

## 变化

- 重新加上「自动框选」：点一下就在来源画面里找出解说摄像头的小窗，直接裁成画中画。
- 识别改为按人脸定位：先找在至少两帧里出现在同一位置的人脸（一次取最近约 0.75 秒的 4 帧），按人脸大小估计摄像头窗口高宽（窗口高约为人脸高的 3.0–4.2 倍、16:9），再用窗口四边的亮度跃变复核，最后把四条边微调到真实分界上。
- 认不出时只提示一句，不改动已有裁剪：不会退回整帧，也不会覆盖你手动框好的区域。
- 不再有「开启画中画 1.2 秒后自动识别」的行为；识别只在你点按钮时发生。

## 安装

1. 先在「设置 → 插件」删除旧的 `match_sync`（宿主不支持同 ID 覆盖安装）。
2. 「装载插件…」选择 `match_sync-2.0r2.zip`，或把 ZIP 拖入插件页面。
3. 勾选插件，点「保存并重启」。
