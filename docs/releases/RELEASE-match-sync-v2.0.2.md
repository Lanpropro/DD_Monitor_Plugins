# 比赛二路同步 v2.0.2

**2.0 Pre-release 2**

**主画面卡顿时，可在「比赛二路设置 → 主画面渲染」选择「D3D11（试验，推荐用于减轻卡顿）」。** 在 1666×1131、60 帧主路、三路混音、双增强画中画和滚动弹幕的实播对照中，D3D11 明显减少了主画面的长间隔。实际效果随片源、硬件和负载变化。Windows x64 可通过设置或 `Ctrl+Alt+G` 在光栅和 D3D11 之间切换。插件会记住手动选择的渲染方式。

- 二路窗口使用独立的 Qt Quick 滚动弹幕层。若卡顿仍明显，可尝试关闭滚动弹幕观看，我们还在优化。
- 增强画中画在可用的 OpenCV 环境下减少 CPU 滤镜耗时。画中画框选时可以继续调音量，选区在确认后应用。
- 改善打开计时器和对照微调时的界面响应，修复声道选择时上下键被播放快捷键截获的问题。
- 保留上一预览版的 YouTube 独立取流修复。

请使用 DD 监控室 CE v0.9.1 或更新版本。从软件的插件商店更新，或下载 `match_sync-2.0.2.zip` 导入，重启后生效。
