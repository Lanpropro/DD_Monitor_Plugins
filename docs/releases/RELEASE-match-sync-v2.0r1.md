# 比赛二路同步 v2.0r1

基于原作者 `match_sync-1.5` 的修改版。本版只动画中画的裁剪逻辑，其他功能与 `2.0.0` 相同。

## 变化

- 移除「自动框选」：画中画不再自动识别摄像头区域，裁剪只由手动「框选画面」决定。识别按钮、开启画中画 1.2 秒后的自动识别、手动框选松手后的四边贴合同时移除。
- 修复手动框选后小窗跳位：裁剪比例变化时，小窗以中心为锚重算高度，高度放不下时先让出宽度；不再从左上角往下长、再被画面边界顶回去。只有调整后仍越界时才平移。

## 安装

1. 先在「设置 → 插件」删除旧的 `match_sync`（宿主不支持同 ID 覆盖安装）。
2. 「装载插件…」选择 `match_sync-2.0r1.zip`，或把 ZIP 拖入插件页面。
3. 勾选插件，点「保存并重启」。
