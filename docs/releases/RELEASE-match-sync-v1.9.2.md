# 比赛二路同步 v1.9.2

## 变更

1. 分隔条拖动改由插件自己处理：按下分隔条时记下光标横坐标与当时的左右宽度，移动时按像素差直接设置两栏宽度，不再交给 `QSplitterHandle` 用子控件的最小宽度做约束计算。
2. 主画面栏与弹幕栏各自只声明 140 像素的最小宽度提示（`PaneHost.minimumSizeHint()`），弹幕列表或发送台内容再宽也不会抬高整栏地板——这是「往右拖却往左跳」的直接原因。
3. 手柄光标改为水平分隔光标；双击仍恢复默认宽度（可用宽度的 42%），释放后 220ms 才重新计算内部布局。
4. 画质按钮、画中画与自动对齐行为不变。

## 安装

先删除旧的 `plugins_user/match_sync`（或设置页里的卡片），再装载 `match_sync-1.9.2.zip`，保存并重启；卡片应显示「比赛二路同步 / 1.9.2 / 已加载」。
