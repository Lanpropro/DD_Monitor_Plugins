# B站稍后再看 v1.0（发布草稿）

> 类型：发布草稿 ｜ 状态：已验收，准备0.8热修复1及七个插件1.0联发 ｜ 更新：2026-11-19 ｜ 候选供审查，未正式发布

## 发布正文草稿

在 DD监控室CE 内浏览和管理 B 站稍后再看，把视频置入画面墙，复用本体播放器、弹幕和登录状态。

- 列表与大卡片网格，支持搜索、观看状态筛选、排序、自定义列数和卡片大小；头像与置入、外链、删除操作同列，完成状态使用勾选图标。
- 点击视频后在当前窗口的布局缩略图中选位置，空格置入、已有内容替换；设置和选位均在同一窗口内完成，窗口可拖动边缘调整大小。
- 关注栏可切换观看顺序，双击快捷播放、拖入格子、拖动排序；仅改变软件内连播次序，可设置是否包含已看完视频。
- 清晰度切换、B站字幕、画面弹幕、进度条与支持视频的悬停预览，适配主墙、全屏和画中画。
- 设置自动保存；可选择入格自动播放、自动连播、提前加载下一条。浏览留存只在本次软件运行中恢复选片页面的位置、搜索和筛选，退出后从顶部开始；另可独立开启正常退出后恢复视频格和播放进度。
- 删除成功后底部提示显示头像与标题，支持逐项／全部撤回；多选提示可展开，展开条数可设置。撤回保留删除后的本地调序。

预览使用 B 站图片帧，不使用本地模型；插件播放进度不上传 B 站。提前加载默认关闭，仅连播开启时可用，每路最多约10 MiB缓存，额外占用内存和流量。字幕和预览取决于视频及账号能获取的数据。

重启恢复保留UP名称/头像，旧快照异步补齐；恢复格首显使用视频底栏，定位期间保留已保存时间。观看顺序为入墙视频显示独立蓝色标识，移出或替换后清除。

## 本体发布依赖

## 发布前完成项

1. 配套宿主接口及完整本体改动按本体流程提交、集成和验收，发布实际版本。
2. 更新最低本体版本，执行[验收清单](../../plugins/bili_watchlater/ACCEPTANCE.md)，记录真实播放、跨屏和拖放结果。
3. 插件功能分支通过面向develop的PR集成，再按仓库流程进入main。[草稿PR #82](https://github.com/Lanpropro/DD_Monitor_Plugins/pull/82)已建立并附候选源码/大小/SHA256，等待配套版本明确后完成集成。
4. 当前可按日常候选流程构建ZIP并检查源码／包一致性，摘要随候选材料提供，不将其作为正式v0.7.3兼容包。配套本体版本明确、源码集成后，更新最低版本并创建标签，再用verify_plugin_release从标签Git对象生成正式包、核对大小和SHA256。
5. 正式发布时移除草稿中的维护者待办，发布插件说明及目录附件；本文件不计入“当前在线发布”。

配套本体发布后，在实际集成源码中更新最低版本并验证，再创建插件 `bili-watchlater-v1.0` 标签。从插件仓库根执行：

```powershell
python tools/verify_plugin_release.py --plugin bili_watchlater --tag bili-watchlater-v1.0 --archive dist/bili_watchlater-1.0.zip --build
```

输出目标必须不存在，不能覆盖当前审查候选；构建输入为标签Git对象，且该提交必须已进入origin/develop和origin/main。随后上传受检包至草稿Release，运行`Verify and publish plugin draft`工作流。候选不用于绕过最低版本、集成和正式包核验。

人工验收中真实删除会修改账号稍后再看；只对用户选择的测试视频执行，自动测试使用替身，不读取账号配置或执行真实写入。历史原生Qt整组测试异常仍保留记录，不把源码测试通过扩大为实机全面通过。
