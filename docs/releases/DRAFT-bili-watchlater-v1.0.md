# B站稍后再看 v1.0（发布草稿）

> 类型：发布草稿 ｜ 状态：本轮交换复验未再现，等待配套本体及源码集成 ｜ 更新：2026-11-18 ｜ 候选供审查，未正式发布

## 发布正文草稿

在 DD监控室CE 内浏览和管理 B 站稍后再看，把视频置入画面墙，复用本体播放器、弹幕和登录状态。

- 列表与大卡片网格，支持搜索、观看状态筛选、排序、自定义列数和卡片大小；头像与置入、外链、删除操作同列，完成状态使用勾选图标。
- 点击视频后在当前窗口的布局缩略图中选位置，空格置入、已有内容替换；设置和选位均在同一窗口内完成，窗口可拖动边缘调整大小。
- 关注栏可切换观看顺序，双击快捷播放、拖入格子、拖动排序；仅改变软件内连播次序，可设置是否包含已看完视频。
- 清晰度切换、B站字幕、画面弹幕、进度条与支持视频的悬停预览，适配主墙、全屏和画中画。
- 设置自动保存；可选择入格自动播放、自动连播、提前加载下一条。浏览留存只在本次软件运行中恢复选片页面的位置、搜索和筛选，退出后从顶部开始；另可独立开启正常退出后恢复视频格和播放进度。
- 删除成功后底部提示显示头像与标题，支持逐项／全部撤回；多选提示可展开，展开条数可设置。撤回保留删除后的本地调序。

预览使用 B 站图片帧，不使用本地模型；插件播放进度不上传 B 站。提前加载默认关闭，仅连播开启时可用，每路最多约10 MiB缓存，额外占用内存和流量。字幕和预览取决于视频及账号能获取的数据。

重启恢复保留UP名称/头像，旧快照异步补齐；恢复格首显使用视频底栏，定位期间保留已保存时间。观看顺序为入墙视频显示独立蓝色标识，移出或替换后清除。

## 本体发布依赖

2026-11-17 通过 GitHub API 核对，最新正式本体为 [v0.7.3](https://github.com/Lanpropro/DD_Monitor_CE/releases/tag/v0.7.3)，标签源码提交为 `50f676adf4d73834e435468cde52da3e4f2cb2e7`。该标签缺少下列4个接口：

- `PluginContext.register_sidebar_page`、`unregister_sidebar_page`：观看顺序作为关注栏的内容页。
