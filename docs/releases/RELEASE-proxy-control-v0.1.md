## 功能

- 在主窗口内提供总览、代理、配置、连接四页；管理多份订阅、Clash/Mihomo 配置和节点链接，保存每份配置的下载标识与节点选择。
- 内置代理仅作用于本软件，提供规则、全局和直连模式；停止时恢复原环境。启动软件时自动连接只恢复退出前仍开启的代理，手动暂停后不恢复。
- 节点卡片显示地区、协议、延迟、排队与检测状态；最多 50 项同时检测，支持搜索、取消和会话内保留结果。测速不代表直播带宽或播放延迟。
- 配置可显示订阅提供的剩余流量和到期信息；连接页展示实际出站链路、规则与本次会话事件。
- 复用宿主公共控件及深浅主题，采用清晰线框图标、红色暂停操作、同宽节点弹层和紧凑布局。运行时侧栏按钮右上角显示绿色圆点，收起面板后保留，停止后移除。

## 首次安装与内核

安装包为 `proxy_control-0.1.zip`，可在配套宿主的“设置 → 插件”手动导入并启用。

Windows x64 首次启用且内核缺失时，会自动联网下载固定官方 Mihomo `v1.19.33`，校验 SHA256 后安装到私有数据目录并保存路径；已有内核不重复下载，失败可在内核设置中重试。ZIP 不附带内核，无法离线完成首次自动准备；用户也可自行选择兼容的内核程序。

默认只准备内核，不开启代理。用户仍需提供自己的订阅或节点，导入并启用后才接管本软件网络；已有直播需要重新播放。校验和解压使用可取消工作线程，不依赖系统 Python，不安装系统服务或虚拟网卡，不改变 Windows 系统代理。
