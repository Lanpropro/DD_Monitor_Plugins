# 比赛二路同步 v1.5

正式版候选，尚未创建正式标签或公开发布。相对 v1.4 汇总，完整包含 v1.5-pre.1 及后续改进；原预发布说明保存在 [v1.5-pre.1](RELEASE-match-sync-v1.5-pre.1.md)。插件清单版本为 `1.5`，安装包为 `match_sync-1.5.zip`。

## 分音轨录制

- 二路控制台齿轮增加 OBS 式 1～6 音轨矩阵。每路可勾选一条或多条，同一音轨混合所选来源，不勾选则不录该路声音；按直播间保存分配，录制期间锁定。新来源优先使用未占用音轨，六轨已满时由用户手动分配。
- 主画面底栏的录制按钮输出一个 MKV，复制主画面原编码视频，并写入所选的具名 AAC 立体声音轨。例如所有来源勾选 1 作为混音，再分别勾选 2、3 等作为独立轨，后期可分别选择。
- 复用已有视频／声音缓存，不额外拉流。按当前播放偏移对齐，保留来源原始立体声，收听静音、音量及 L/R 不影响录制；尚未对齐或缺失来源写入静音。
- 从当前进度之前最近的可用关键帧开始。再次点击录制、添加／移除来源、换主画面、跳转回看、停止二路或主视频缓存重建时，结束并收尾当前文件。
- 使用主程序录制目录与剩余空间下限。二路多轨固定使用 MKV 和原视频编码，不套用其他输出格式、转码及分段设置；普通画面墙录制保持原行为。画中画和弹幕不烧录进原视频。

## 回看、画中画与对齐

- 最多十分钟整组回看，主画面、各路声音与弹幕一起回退；后台继续接收直播并自动对齐，支持精细时间轴、时间输入及返回直播。
- 副路悬浮裁切支持移动、等比缩放、来源头像和自由／画面内／固定位置三态定位。按相对尺寸与位置保存，窗口缩放及全屏切换后保持摆放。
- 首次框选后可继续拖动四边、四角或内部精调，已放置小窗提供微调入口与四角缩放。Ctrl＋滚轮按指针缩放，滚轮上下平移，Shift＋滚轮左右平移；操作按钮并排。
- 画中画提供默认「流畅优先」和「轻量增强」，两种模式切换不重新连接来源；后台限幅轻锐化兼顾无独显设备。增强跟不上时稳定回退并显示原因，不因一次界面停顿永久回退。这是插值与锐化，不是 AI 超分。
- 副路可独立播放并恢复自动对齐。增加「偏快／偏慢」方向辅助，提交后等待一轮完整搜索才能再次操作，重复同方向可增加权重；仍需可靠画面证据才能应用偏移。
- 保留 pre.1 的共同游戏区域匹配备用流程。不同视角缺少共同内容时仍可能无法自动对齐，不使用声音匹配或 OCR。

## 控制台与弹幕

- 控制台改为分组图标工具条，复用本体图标和悬停反馈，统一主画面按钮、确认位置、边沿和颜色；移除焦点虚线及点击后的残留蓝底。
- 默认保留两张卡片高度，更多主播内部滚动；抓取卡片不改变控制台高度，其他卡片让位。保留移除后的五秒撤销。
- L／R 两个按钮直接控制收听声道，双亮为双声道；不自动分配声道。收听声道与录制音轨独立。
- 弹幕控制台统一外观和竖线分隔，保留单／多选发送、各路草稿，以及书签暂存、持久化、排序、删除和弹幕转存。
- 表情与礼物在单选且平台支持时直接打开原平台面板；其他情况保留置灰并说明原因，不再经过平台／主播二级菜单，保留原平台登录和消费确认。
- 点击当前颜色横向展开色板，修复首次展开大菜单闪现。有来源颜色的滚动弹幕省略主播名前缀，右侧列表仍保留来源，直播与回看一致。
- 消息区可独立收起，发送控制台与草稿保留；连接图标区分未连接、一路和多路。恢复二路主画面的右键直播流信息，并跟随主路切换。

## 性能与稳定性

- 平滑音频时钟观测，按下一源帧调整轮询，减少显示节奏不均；保留原音频时钟与播放偏移。
- 复用分析缩放器，减少不同分析尺寸切换时的重配置和线程池创建；限制鼠标悬停事件向外层布局传播，停止 Qt 主画面不需要的原生裁剪重试。
- 界面迟取帧不再轻易触发从关键帧重新解码，保留有界显示缓存，减少卡顿后的额外追赶工作。
- 模式切换先显示反馈，再执行布局工作；减少侧栏重复刷新、重复退出清理及拖入时的同步磁盘准备。
- 降低标题／画质／缓存说明的刷新频率；缩放弹幕栏只更新分隔图，不重建全部消息；回看范围扫描复用连续区间。
- 合并画中画局部重绘，拖动期间暂缓非必要状态更新；增强任务不积压，原始帧与增强帧成对呈现，避免画面倒退。
- 修复时间戳缺口、孤立帧及换档后沿用旧播放基准导致的持续缓冲，改善斗鱼 2K 主画面恢复。
- 补充逐路接收／解码／转换／绘制、音频供给、界面停顿及画中画回退诊断；日志有界，不保存账号、流地址或弹幕正文。

## 安装与验证范围

需要 v0.6 或更新的配套本体，以及 PyAV、NumPy、Qt／FFmpeg。互动功能还需要对应平台插件和登录状态。完全退出软件后在插件管理导入 ZIP，或仅覆盖 `plugins_user/match_sync/`，保留配置与其他插件，再从根 `run.cmd` 重开。

既有主画面流畅度、模式切换、侧栏入口与斗鱼 2K 恢复已有用户实播验收；控制台与画中画相关回归、录制矩阵及实际 H.264／HEVC 本地捕获、封装和解码检查通过。根入口使用隔离配置和禁网检查，不读取真实账号或发送弹幕。

分音轨录制尚待真实直播长录、听感和剪辑软件人工验收，不把本地素材检查作为实播性能结论。验收时建议将两路都勾选 1，再分别勾选 2、3，录制后分别选择三轨检查混音／独立声音；改变收听静音和 L/R 后独立录制轨应保持完整。
