# 比赛二路同步 v1.5

## 支持十分钟的直播回放
- 现在会记录十分钟之内所有路直播的声音，画面，弹幕。回过头查看那些你漏掉的highlight细节吧

## 支持单独截出部分画面作为画中画
- 你现在可以单独截出主播的摄像头摆在软件中了，随意摆放，拖动、滚轮等比放大。并且支持轻度的锐化超分

## 控制台UI
- 尝试重构了控制台的按钮，icon。现在他们变得更加的简洁以及可读，你的操作也会更加方便

## 增加了弹幕控制台
- 你现在可以在二路同步模式下发送弹幕了，支持原版的一键复制与+1，并且还多了一个书签功能，一键收藏想要的弹幕然后轻点左键发送。

## 弹幕显示改进
- 画面中的滚动弹幕使用颜色来区分来源，终于不用再看弹幕前面的超长前缀了

## 专门为二路同步设计了录制功能
- 你可以在二路设置中选择直播流对应音轨，自由录制画面

## 性能与稳定性
- 改善主画面播放节奏：平滑音频时钟观测，按下一源帧调整轮询，减少显示节奏不均。
- 减少后台转换开销：复用分析缩放器，避免不同尺寸切换时反复重建转换器和线程池。
- 减少鼠标移动开销：限制悬停事件向外层布局传播，停止二路 Qt 主画面不需要的原生裁剪重试。
- 避免卡顿后重复解码：界面迟取帧不再轻易被误判为跳转，保留有界显示缓存，减少额外追赶开销。
- 改善模式切换与拖入响应：点击先显示反馈，再执行切换；减少侧栏重复刷新和退出清理，回看磁盘缓存延后创建。
- 减少界面重建：标题、画质和缓存说明降低刷新频率；弹幕栏缩放不再重建全部消息，回看范围查询复用连续区间。
- 改善画中画拖动：合并局部重绘、暂缓非必要状态更新，并限制手势期间单轮弹幕处理量；增强任务不积压，避免新旧帧交替倒退。
- 修复播放恢复：处理时间戳缺口、孤立帧和换档后沿用旧播放基准的问题，恢复斗鱼 2K 主画面的持续播放。
- 补齐卡顿诊断：记录各路播放、解码、转换、绘制、音频供给、界面停顿及画中画回退原因，便于继续定位实播问题。
- 完善弹幕栏的横向拖拽绘制延迟，还给每个部分都添加了最小化按钮。你可以轻松地调整整个页面的布局了
