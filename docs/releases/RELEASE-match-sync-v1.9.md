# 比赛二路同步 v1.9

每一路都能单独选画质，弹幕栏分隔条也不再回弹。

## 变更

1. 下方控制台为每一路新增画质按钮，直播间之间互不影响，换档不必再切到主画面。
2. 左键循环该路可用档位，右键直接选择；换档只重启这一路，其余路继续播放。
3. 画质档位随设置保存，重启后沿用；取流后按平台返回的实际档位刷新按钮文字，B 站房间同样按当前编码与登录状态查询可用档位。
4. 修复拖动弹幕栏分隔条时的回弹：拖动过程中不重排控制台，松手后才重新计算布局。
5. 分隔条两侧保留最小宽度并记住宽度，弹幕栏可以拖回原来的位置。
6. 保留 1.8 的内嵌画中画、整组回看、弹幕发送台、区域匹配等全部功能。

## 安装

1. 通过「设置 → 插件 → 装载插件」选择 `match_sync-1.9.zip`，重启程序。
2. 插件卡片应显示「比赛二路同步 / 1.9 / 已加载」。
3. 已有旧版时，退出程序后把 ZIP 内 `match_sync` 目录覆盖到 `plugins_user/match_sync/`，再重启。
