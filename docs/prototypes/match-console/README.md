# 比赛二路控制台图标原型

打开 [index.html](index.html)，可直接使用本地浏览器，无构建、下载或运行时依赖。
这是独立的交互设计稿，不被插件导入，不连接直播或弹幕，也不修改正式配置。

## 三种方向

| 方向 | 布局与交互 | 优势 | 代价 |
| --- | --- | --- | --- |
| 分组工具条 | 保留每路横排，常用图标直接展示，列标题表达分组 | 操作路径短，接近现有控制台 | 图标数量多，需要初期熟悉 |
| 双层卡片 | 第一层身份与状态，第二层按功能分组 | 阅读和点击更舒适，窄窗可换行 | 占用更多高度 |
| 按需展开 | 每行仅保留常用开关、裁切、偏移，其他控制展开 | 平时简洁，适合多路 | 调整声道等操作需要展开 |

顶部全局对齐模式、主播名、主画面身份、同步状态、缓存与偏移数值保留文字。
“确认对齐并加入”承担时间线确认，继续使用文字按钮。
裁切、独立播放、重新对齐、声音、弹幕、对照区域、设置等使用统一线性SVG图标。
声音开启显示扬声器，关闭显示斜杠；弹幕也使用不同开关图形，避免只靠颜色区分。
每个图标有可访问名称以及悬停、键盘聚焦提示；移除放入更多菜单，并提供撤销。

沿用现有控制台深灰背景与青色交互强调；无模糊内容背景、循环动画或额外视频绘制。
若选定方向，生产实现应继续复用 Qt 控件与 `ConsoleIconButton` 绘制，避免引入 WebView。

## 交互检查

所有数据只用于设计演示；此处不检验实际播放、对齐精度或性能。

1. 用底部选择器、1/2/3 和左右方向键切换方案；URL 的 `v` 参数应同步，刷新保留方案。
2. 声音与弹幕开关应改变选中态及图形；音量支持拖动和键盘方向键。
3. 偏移支持加减与直接输入；操作其他图标后保留输入值。
4. 声道与弹幕颜色选择弹出选项，选择后回显；设置可打开、切换和关闭。
5. 主画面切换后身份和底部摘要同步；独立播放、重新对齐、确认加入应更新状态。
6. 裁取图标开启或关闭示意浮层；对照区域开启示意对照区，不操作真实视频。
7. 更多菜单可显示示意流信息、移除与撤销；添加按钮可添加示意来源。
8. 收起控制台后可恢复；按需展开方案只同时展开一路，行内与展开区开关同步。
9. 在 900px 宽窗口检查三版，无水平溢出；恢复正常宽度检查列对齐和文字截断。
10. 检查浏览器控制台无错误，所有图标可用 Tab 聚焦并显示提示。
