# 比赛二路同步

<PluginInfo id="match_sync" />

## 功能与操作

选择一路比赛直播作为主画面，自动匹配其他主播的比赛画面，同时混合声音、合并带来源标记的弹幕。支持 B 站及已启用平台插件提供的直播源。

横屏点击关注栏底部、布局预设旁的「比赛二路」文字按钮；竖屏点击顶部刷新旁的双画面图标。将关注卡片拖入观看区域，选择主画面，开启自动对齐。再次点击入口返回原画面墙。

画面内容不同、广告、回放或长时间静止时无法可靠匹配，仍可手动调节偏移。自动对齐需要两路存在足够的共同比赛画面。

## 兼容与依赖

需要配套更新的 DD 监控室 CE 源码或完整构建，以及 PyAV 17、NumPy、FFmpeg。源码用户先安装本体 `requirements.txt` 中的依赖。插件 ZIP 不携带这些运行库；旧 EXE 仅替换插件不能补齐依赖。

虎牙、斗鱼、抖音等平台需要同时启用对应平台插件。B 站由本体提供。直播源、弹幕和网络连接沿用本体与平台插件的支持范围。
