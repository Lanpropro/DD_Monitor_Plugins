# 为画面墙加入更多平台

平台插件与比赛二路插件独立启用，按观看方式选择。B 站直播由软件本体提供，无需安装插件。

::: warning 安装前确认软件版本
1.0 插件需要配套更新的软件；比赛二路还需要 PyAV、NumPy 和 FFmpeg。公开源码已包含所需接口；公开 v0.2 EXE 安装包缺少插件所需模块。[查看兼容说明与软件下载](/download#插件兼容性)。
:::

## 下载后怎么安装？

在软件「设置 → 插件」中导入 ZIP，勾选启用，再保存并重启。[查看安装与升级步骤](/guide#安装插件)。

下载每个插件自己的 ZIP。GitHub 自动生成的 **Source code ZIP** 是整个仓库源码，不能作为单插件导入。
