# 国内直播平台

<PluginInfo id="domestic_live" />

## 功能

一个插件接入虎牙、斗鱼、抖音。支持关注卡片、格子内播放、直播实际画质档位、静音悬停预览和聊天弹幕。拖入画面墙后，沿用软件的音量、静音、暂停、换位与重连控制。

## 添加直播间

启用插件并重启软件后，在「添加直播间」输入官方完整链接或带平台前缀的房间标识。

| 平台 | 输入示例 | 官方直播间链接 |
| --- | --- | --- |
| 虎牙 | `huya:660000` | `https://www.huya.com/660000` |
| 斗鱼 | `douyu:36252` | `https://www.douyu.com/36252` |
| 抖音 | `douyin:557481980778` | `https://live.douyin.com/557481980778` |

示例仅用于说明格式，不保证对应直播间正在开播。纯数字仍按 B 站房间号处理。虎牙支持字母房间标识，虎牙与斗鱼也支持官方手机直播间链接。

抖音分类页可通过 `live_web_rid` 识别直播间，`anchor_id` 不是房间号。分享短链请先用浏览器打开，再复制完整直播间链接。

## 画质、预览与聊天

- 画质使用平台实际档位名称。虎牙蓝光档位是码率名称，不等于像素分辨率；缺少尺寸数据时不猜测 720P / 1080P。
- 在设置中启用悬停预览，鼠标停留在已开播卡片上约 1 秒即可静音预览。预览使用独立的低档位，不改变格子的手选画质。
- 弹幕布局的聊天跟随主画面，支持普通文字、表情文字、字号、屏蔽词与保留条数；不接收礼物、进场、点赞或人数统计。
- 禁用并保存后，对应关注与格子暂存；重新启用后恢复。

## 安装与旧版本迁移

[按安装教程导入 ZIP](/guide#安装插件)。三个平台的播放需要 FFmpeg；源码运行时需安装软件 `requirements.txt` 中的依赖。

旧 ID `huya_watch` 已更名为 `domestic_live`。配套最新版软件会迁移启用状态和设置，原关注、位置及画质保留；旧新目录共存时只装载新插件。

## 支持范围

插件通过网页协议读取公开直播，不读取浏览器登录资料，不支持付费、登录限制或 DRM 内容。平台网页、CDN 或弹幕协议变更可能需要更新插件。观看功能不包含发送弹幕。
