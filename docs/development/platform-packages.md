# 按平台发布与组合包迁移

> 类型：设计 ｜ 状态：发布候选 ｜ 适用版本：DD Monitor CE 0.8 及以上 ｜ 更新：2026-11-19 ｜ 读者：开发者与维护者

## 安装和发布边界

新增`huya_live`、`douyu_live`、`douyin_live`、`twitch_live`、`youtube_live`、`chzzk_live`六个独立包，均为0.1开发候选，尚未公开发布。每个包只注册一个平台；二路、B站互动、翻译和代理仍按功能组织。

六个独立包需要本体 0.8 提供的平台接管接口。YouTube 高画质还需要本体的私有媒体交付接口。先公开兼容的本体版本，再公开独立包。0.7.3 用户继续使用旧组合包，升级本体后再安装独立 ZIP。0.7.3 的手动 ZIP 安装入口不会校验最低本体版本。

入口与清单在各自`plugins/<ID>/`目录。平台协议的唯一维护源码目前保留在`domestic_live`、`global_live`的已拆分职责模块中，旧导出继续兼容；不要在新入口复制协议。`tools/platform_bundles.json`显式列出每个包需内置的协议与共享文件，`build_plugins.py`只收集Git跟踪文件，保留LICENSE／NOTICE及国内协议MIT声明。ZIP安装后完全自足，不从相邻插件目录导入，也不要求安装基础插件。源码入口目录需要先构建，不能直接复制安装。

正式发布校验 `tools/verify_plugin_release.py` 从标签提交读取同一份依赖映射及共享源码，以标签 Git blob 核对 ZIP；`--build` 也包含这些依赖，不读取工作树中的未提交映射或模块。缺失／改写依赖、未跟踪来源及覆盖入口或许可文件的映射均不能通过。没有映射清单的旧标签仍按原单目录规则验证，当前不创建标签或发布附件。

共享HLS／图片工具、输入控件与数据值在仓库中各维护一份，构建时进入相应包。国内输入控件中的礼物展示仍是共享组件；本批没有为拆包继续改写礼物界面。互动类型独立于网络协议，虎牙／抖音不会为了初始化控件连接或导入斗鱼网络协议。

## 状态所有者

每个插件拥有一个平台实例、实例缓存和CDN锁；国内插件还独占自己的互动控制器、请求集合与诊断对象。Qt父子关系及请求取消／等待退出继续沿用既有控制器。播放器、代理、自动画质、账号加密与通用界面仍由宿主管理，不调整缓冲、超时或重试。

## 迁移契约

新清单声明`replaces`旧组合ID、`platforms`本包平台和`inherit_settings`允许继承的设置。宿主只让已经由安装器写入文件清单的完整包参与接管；仓库中的源码入口模板不触发旧组合包迁移。

首次加载时，宿主复制声明的旧设置并继承旧启用状态；已有新插件设置优先。新设置字典即使为空也表示该插件已经有独立选择，后续不再从旧组重新启用。普通安装入口先初始化设置，因此安装后手动取消启用也能保留。

平台接管与是否启用分开：新包关闭后，旧组合包不再注册它；只装部分独立包时，旧组合继续负责剩余平台。全部平台都有独立包后，旧组合不装载并从目录页隐藏，源目录和设置仍保留以便回滚。房间ID、账号存储键、关注、分组和画质不改名，不读取或重写真实账号文件。

加载失败会清理本次已注册的平台与控件，不留下无主平台。某个新包失败时，其余新包仍可加载；插件仍共用宿主进程，不是进程级崩溃隔离。

## 验证与回滚

`tests/check_platform_packages.py --host <宿主目录>`逐包安装，覆盖独立性、组合包共存、设置迁移、禁用重启、三个国内控件归属与六个Logo入口。宿主`dev/selfcheck_plugin_replacements.py`使用临时插件和内存设置，覆盖部分替代、完整替代、深复制、既有设置优先、失败清理、未构建源码与无效清单。

保留旧组合包与备份。回滚时关闭软件，移走新独立包或恢复候选安装前的插件目录，旧组合启用状态和设置仍在。若只禁用独立包而不移除，按迁移契约不会由旧组合恢复该平台。公开发布需要单独验收、标签与Release，当前候选不更改线上商店。

旧公开组合不支持接管查询时，`replaces_platforms`声明其旧平台范围；完整替代组安装后即可跳过旧组，部分安装保留旧组并给出更新／补齐提示。CHZZK不属于旧海外公开组，可单独并存。兼容组合包支持逐个平台接管。B站图标继续由宿主全局平台标识设置管理。

单独构建某个平台：`python tools/build_plugins.py --plugin youtube_live`，可重复指定`--plugin`；不需要重建或更新其他平台包。
