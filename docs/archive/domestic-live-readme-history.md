# domestic_live README 历史过程

> 从国内平台插件 v2.0 的 README 移出，原文保留；以下状态与结果以记录当时为准。

## v1.4 更新日志

- 修复新版常规设置页中平台 Logo 开关覆盖标题、脱离布局的问题。
- 国内与海外插件分别保留独立开关，两个插件同时装载时仍可分别控制和保存。
- 兼容旧版常规页布局；独立设置窗口的开关显示需要本体包含对应的控件传递修复。

## v1.3 更新日志

- 支持虎牙 `hy.fan`、抖音 `v.douyin.com` 直播短链及斗鱼官方 `s.douyu.com` 跳转链接，在后台解析，不阻塞添加窗口。
- 抖音直播分享页读取主播固定房间号，不再误用当场直播 ID 或分享者 ID；完整分享文案提取需要包含该功能的新版软件本体。
- 虎牙显示官网实际提供的 2K、4K 档位，默认最高优先选择 2K，不虚构“原画”档位。
- 虎牙手选 4K 时检查登录与对应房间 VIP 权益，使用官方账号取流令牌，并检查实际视频分辨率；失败不静默降档。
- 尚无具备相应权益的 VIP 账号完成 4K 持续播放实测，菜单保留提示；不保证所有房间均可播放 4K，2K 扫码要求也仍受官网限制。

## v1.2 更新日志

- 修复斗鱼 `6657` 等靓号链接无法添加的问题，兼容当前播放器页面的真实房间号字段。
- 斗鱼取流优先使用本次登录会话，取消“记住登录”时本次运行仍可使用账号允许的画质。
- 原画请求被官方降档时明确提示，不再静默切换为蓝光 4M；配套新版本体可通过顶部灵动岛和账号区提示登录失效。
- 国内平台 Logo 开关同时控制 B 站、虎牙、斗鱼和抖音的关注栏标识。
