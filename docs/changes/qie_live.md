## 已发布 v1.0

### 2026-11-20｜使用公开 v0.8 的通用媒体交接

- 插件读取并验证官网 720p HLS，保留视频和音频原编码交给宿主；失效时通过宿主现有重连重新读取官网地址。
- 在公开源码 `v0.8` 的隔离原生画面墙实测布丁小喵。旧清单自然返回 HTTP 403 后，同一格约 10 秒恢复 1280×720。本机 HLS 夹具另外覆盖了带 AAC 音频的 200 → 403 → 200。
- 关注卡片角标依赖宿主通用台标接口，初版 v0.8 可使用播放、头像和只读弹幕。

### 2026-11-20｜恢复头像并接入只读弹幕

- 桌面页缺少头像时用同房间的手机页补齐。关注卡片和已安装插件卡片读取随包的 128×128 企鹅体育图标。
- 通过官网访客 WebSocket 订阅普通文字弹幕，复用宿主画面弹幕与弹幕格。测试覆盖匿名加入、心跳、批量消息和非法长度处理。
- 实际开发版卡片显示了布丁小喵的头像和平台图标。布丁小喵下播后，从燕雨春风直播间实测收到公开观众弹幕，待人工验收。

### 2026-11-20｜官网 720p 原生取流和续播

- 0.2 从企鹅体育公开手机房间页读取对应房间的 HLS 地址，解码首帧确认 1280×720，交给宿主原生播放器。该流程使用 Requests、PyAV 和 libmpv。
- 实测布丁小喵（10210732）在隔离开发版原生上墙。旧 HLS 清单随后自然返回 HTTP 403，宿主首次重连取得新的官网地址，同一格约 9 秒后恢复 1280×720。验收使用访客可观看的直播。
- 专项回归覆盖无效房间、非官方来源、HTTP 403 后重新读取房间页和原有 FLV 媒体交接。HLS 自动恢复使用配套宿主开发版。

### 2026-11-19｜新增 720p 媒体交接与重连

- 支持识别企鹅体育官方数字房间链接和读取公开直播状态。播放只接收实测为 1280×720 的 HTTP-FLV 源，媒体探测与首次播放共用同一条连接。
- 专项自动验证覆盖尺寸检查、HTTP 403、重新请求地址和连接清理。原生画面墙使用本机 HTTP 测试源验证断流后经历 403 并恢复 720p。
- 功能分支为 `function/qie-live`，等待宿主内置官网取址接口及真实直播人工验收。[Issue #241](https://github.com/Lanpropro/DD_Monitor_CE/issues/241)
