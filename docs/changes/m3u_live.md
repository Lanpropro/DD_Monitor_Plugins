### 2026-11-20｜1.0 与通用宿主接口

- 沿用已验收的频道预设、列表导入、台标与首帧封面。预设、解析和频道探测随插件包提供，宿主只提供原生导入和卡片接口。
- 频道导入、预设和关注卡片接口随本体 0.8 Hotfix 2 公开。

### 2026-11-19｜更名并加入电视预设

- IPTV Play 0.2 在「添加直播间」面板提供电视预设。选中频道后直接创建关注卡片，既有 M3U／HLS 导入继续使用原有频道 ID。
- 自动回归覆盖从空格打开时的入口位置、只添加关注、重复去重和原有频道恢复。隔离宿主短测确认 CCTV-5+、CGTN 英语、广州综合和河北卫视均可出画。CCTV-5+ 首测见单帧花屏，复测画面正常；广州综合和河北卫视在宿主回退软件解码后出画。持续播放和跨网络可用性待验收。
- 使用配套宿主开发版和 `function/m3u-hls` 分支候选包。操作和实播范围见 [IPTV Play](../../plugins/m3u_live/README.md)。

### 2026-11-19｜电视预设保留央视台

- 0.3 的预设菜单提供 CCTV-1 综合、CCTV-5+、CCTV-6 电影和 CCTV-13 新闻。
- 使用宿主 libmpv 短测，四条 HLS 线路均解码到 1920×1080，播放位置至少推进 2 秒。原有卡片和自定义列表的兼容性由回归测试覆盖。

### 2026-11-19｜加入三条央视备用线路

- 0.4 在央视预设里增加 CCTV-1、CCTV-5+ 和 CCTV-6 的备用项，点选后分别生成关注卡片。线路来自 [best-fan 央视列表](https://github.com/best-fan/iptv-sources/blob/c5181316e6afe1b456d00b38602af47ca60febda/cn_cctv.m3u8)。
- 核对了三条线路的画面台标。隔离验收覆盖 0.3 升级、三个备用关注卡片及包内地址播放。三条均以 1920×1080 解码并推进约 6 秒，CCTV-6 测试中出现一次跳过已过期分片。长时间播放与赛事时段仍待人工验收。

### 2026-11-19｜插件卡片图标

- 0.5 安装包声明并自带电视播放图标。配套宿主在「已安装」卡片显示包内图标。

### 2026-11-20｜换用 IPTV 字标

- 0.5 候选包换用透明底、白色 IPTV 字标。安装包检查通过宿主插件目录读取图标，并验证 Qt 可解码、尺寸为 96×96、背景透明且字标为白色。

### 2026-11-20｜关注卡片显示电视台标

- 0.6 候选包为央视频道使用 CCTV 平台角标，并打包 CCTV-1、CCTV-5、CCTV-5+、CCTV-6、CCTV-13 的频道台标。其他央视频道优先用列表台标，缺省用 CCTV 标识。
- 地方台优先用 M3U 的 `tvg-logo` 作为头像与角标。广州综合和河北卫视也有本地台标资源，其他无台标频道使用通用 IPTV 字标。原频道 ID 和播放地址继续使用。
- 首次正常上墙时复用原生播放器取一帧并写入宿主封面缓存。导入阶段只加载台标；播放失败时卡片继续显示台标。
- 使用 CCTV-5+ 备用线路在隔离的原生播放格验收，生成并重新读出 640×360 封面。
- 台标来源为 [央视节目官网](https://tv.cctv.com/)、各央视频道官网、[广州广播电视台](https://www.gztv.com/) 与 [河北广播电视台](https://web.cmc.hebtv.com/cms/rmt0336/2/2gfwz/xw/yw/11980646.shtml)。

### 2026-11-20｜恢复关注卡片的频道名和播放状态

- 0.7 候选包从预设和插件保存的频道信息恢复既有关注卡片的名称、分组和台标。预设、M3U 和 HLS 的新卡片会保存播放方式和名称。
- 配套宿主开发版在首次出画前显示「待播放」，原生播放器出画后显示「直播中」。
- 离线回归通过预设、已保存 M3U 和直接 HLS 的名称恢复，以及关注卡片和画面格的控件更新。隔离开发版从 0.6 升级并加载旧关注，CCTV-5+ 备用线路出画后显示「直播中」和 1920×1080。候选包通过宿主安装和源码一致性检查，待人工验收。

### 2026-11-20｜IPTV 加入关注状态刷新

- 0.8 候选包在同一轮关注刷新中探测已关注的 IPTV 线路。HLS 检查直播播放列表并短读一个分片，直连 HTTP MPEG-TS 和 FLV 短读流数据。确认有直播数据的频道参与「开播优先」排序。
- 线路暂无法确认时，未播放的卡片显示「待检测」。原生播放中的频道继续以当前画面为准。
- 在配套宿主隔离窗口刷新公开的 CCTV-5+ 主线路和备用线路，两张卡片都在未上墙的情况下切换到「直播中」，并排到离线对照卡片之前。离线测试覆盖请求头、无效线路、已结束的 HLS 和正在播放时的探测失败，待人工验收。
