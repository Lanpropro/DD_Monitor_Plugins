## 验证

### 2026-11-18 有限识别复核与重译诊断

- 定稿原文为空、3 秒以上音频仅识别出不超过 3 个文字、同句内部异常重复或连续三段相同长句时，记录具体疑似原因。队列没有待处理 PCM、共享模型立即可用且本次处理尚未达到 1 秒时，最多增加一次识别：保留整句音频，在两端各补 100 ms 静音。仅在候选疑似问题更少且未过期时采用；否则保留原识别，不按“谢谢观看”等固定语句删除真实讲话。
- 原生推理不能抢占；1 秒用于决定是否启动／接受额外复核，不宣称能中断已经进入的 native 调用。队列积压或共享锁繁忙直接跳过，不排队补做；停止或换源后不发布旧结果，也不继续其重译。
- 翻译空正文、错误语言、背景／指令回抄及原文没有的重复段，会在原总等待上限内最多请求两次，追加仅翻译当前句一次的约束；真实原文的重复保留。空识别只发质量诊断，不用空字幕清除上一条定稿；迟到草稿仍不能覆盖它。
- 资源导出增加 quality_reasons、asr_review_attempts、asr_review_skipped、translation_attempts 和 asr_cached；只含原因码及次数，不含字幕正文、术语或请求内容。换源／停止清空复核历史；无额外后台请求队列。
- 新增草稿在 PCM 积压时跳过额外识别，定稿仍保留优先权。队列保持原 64,000 字节容量，但不再被 8 个小管道分片提前填满；容量不随 FFmpeg 每次读取的块大小缩减。专项回归先复现后修复，只证明此输入容量不变量，不作为实播性能结论。
- 质量复核 12 项覆盖次数／等待边界、积压与锁忙跳过、草稿让行、空结果保留上一字幕、原生返回后换源失效、译文错误和真实重复保留。最终功能 62、UI 22、文字 17、切句 10、术语 6、质量 12、多房间 12、准备／API 12、字幕 7、音乐 5、模型发现 3、文档 17，共 185 项自动回归通过。
- 现有 Qwen ASR、音乐检测、GGUF 与实际 FFmpeg 的完整本地回放最终产出译文，线程、两个子进程和临时启动目录释放通过。此前 5 秒样本在旧 2 秒静音尾部退出前未产出译文；夹具改为 6 秒静音并输出失败时序，期间发现小分片提前限流并完成上述修正。回放不等于实播；短句日文回显仍可被拒绝，真实主播误识别、否定、人称和专名是否改善需固定录音人工参考，不报告准确率提升。

人工验收：从根 run.cmd 重启，正常讲话、短促感叹和真实重复讲话都应保留；导出资源记录查看复核原因与次数上限。换源和停止后确认旧字幕不重现，持续讲话时观察音频丢弃和字幕间隔；不能用仅有次数的导出替代字幕语义对照。

### 2026-11-18 切句、原文草稿与定稿

- VAD 停顿候选改为 350 ms；不足 1.2 秒的碎片先显示原文草稿，最多再等 1 秒续接，保留片段间静音。较长语句在停顿定稿；连续语音最多收集 6 秒，优先在后半段至少 80 ms 的相对低能量停顿切分，无合适停顿则按上限切。切口后的音频留给下一句，重复的 VAD 快照不重复拼入。

- Session 通过独立 CaptionProgress 过滤旧修订及定稿后的迟到草稿；草稿诊断事件与 caption 分开，不计作定稿次数。诊断独立 worker 复用同一切句链路，正常插件仍在宿主识别线程运行。

### 音轨退出误报与 HLS 分片兼容修复

- 用户在日常根 `run.cmd` 窗口复现：FFmpeg 已成功创建并运行，随后报 `detected format ... mismatches allowed extensions` 和 `Invalid data found when processing input`，退出码为 `-1094995529`；并非 FFmpeg 文件缺失。另一次界面提示 TLS 失败，不能视为同一故障。
- Windows 将 FFmpeg 的负 AVERROR 退出码也作为 QProcess `Crashed` 通知。会话不再在这个通知中提前释放音轨、抹掉 stderr，而是在 `finished` 中保留分类与原始退出码；真正 FailedToStart 仍单独处理，旧进程的迟到错误无效。
- 宿主 HLS 中继的无扩展名分片可能映射为 `.ts`，实际内容却是 fMP4。只对中继的 `.m3u8` 输入关闭 FFmpeg `extension_picky` 格式扩展名匹配，不修改直连或普通音频输入参数。当前实际 FFmpeg 7.1.1 支持该选项。
- B站音轨与海外音轨一起使用既有宿主 HTTP 中继，复用代理选择、请求头和上游连接重试；FFmpeg 仅直连本机中继。此改动还需当前主播实播复测，不能据此断言所有 TLS 故障均已解决。
- 功能回归新增 Windows 错误通知／退出次序、真正启动失败与迟到错误、真实 FFmpeg 无效输入，以及 HTTP 中继 fMP4 音轨解码。后者为本地样本的功能验证，不是直播精度、网络或性能证据。
