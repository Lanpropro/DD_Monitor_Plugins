## 待发布

### 2026-11-01｜新增：画中画自动跟随摄像头

- 更新内容：画中画设置栏新增「自动跟随摄像头」。勾选后插件在副直播间画面的 320×180 灰度缩略图上识别摄像头窗口，先用手动框选区域做起点，用上一帧裁剪内容做模板匹配跟随，跟丢后按边框与内部画面差异重新找窗口，两者都没有结果时沿用上一次裁剪；识别节拍 1.5 秒，不额外拉流、不影响声音与对齐。
- 验收：2026-11-01，`tests/check_match_sync_autocrop.py` 18 例通过（合成五位置、纯主画面假阳性、模板匹配平移、跟丢解锁、界面接线），`check_match_sync_pip.py` 42 例无回归；真实二路直播画面的人工验收待补，主播实际挪窗的表现以实播为准。
- 追踪：本次提交（`docs/project-documentation` 分支，与文档同一提交）。
- 集成状态：尚未合入默认分支。
- 发布注意：需要宿主自带的 NumPy；无 OpenCV 时人脸线索自动跳过。
