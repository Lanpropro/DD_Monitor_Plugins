### 2026-11-04｜开发候选 0.1.3：接管本体录制与增长时间轴

- 更新内容：插件注册本体录制会话后端，原格子按钮、画质控制、取流/重连和退出流程保留；切片页默认进入回看与选区，移除重复的录制控制按钮。可读分段直接呈现为增长时间轴，不再先复制完整回看文件。

- 集成验证：屏幕外 Windows 原生 libmpv 用原格子录制按钮触发，增长时间轴、出图和定位通过；普通根 run.cmd 在隔离配置/专用插件/本地媒体下确认接管、时间轴从约3秒增长到5秒，0.5–2秒选区导出为1.5秒。均不是实际直播性能或人工验收。
- 追踪：插件 PR #43；宿主后端提交 d18ea6e、根目录集成 7b766e5，追加 PR #161。
- 集成状态：开发版候选，未合并 develop、未发布；待用户真实直播和界面体验验收。
- 发布注意：需要新增 register_backend / live_recording 的配套宿主；卸载恢复默认录制工厂，已开始的插件会话仍正常录制及收尾。不要只移动或删除录播目录中的某一索引文件。
