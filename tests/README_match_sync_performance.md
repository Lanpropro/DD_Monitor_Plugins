控制台提示和计时器入口的界面调整由`check_match_sync_buffer_notice.py`、`check_match_sync_alignment_hint.py`及`check_match_sync_quality_policy.py`覆盖：告警位于顶部中央、无黑底悬停长提示，长消息在窄窗保持单行与固定控制台高度；每路计时器图标在辅助自动对齐右侧，展开偏快/偏慢时仅图标右移96px，收起后复位且其他操作位置不变；点击仍打开原计时器窗口，未播放时仍提示至少两路。截图覆盖深浅主题和展开状态。另运行控制台布局、图标工具条及模块边界专项，确认原声道、显隐、滚动和定时器归属不变。均为禁网功能回归，不能当作手动偏移后卡顿已修复的证据。

BGRA转换、QImage分配/像素拷贝、drawImage。
`total_ms`及分位数是阶段的墙钟耗时（包含调度等待），不是CPU占比；input_wait包含等流。
`payload_bytes`是图像有效像素的数据量，不是实际内存总线带宽；drawImage不是屏幕物理呈现。
`process_cpu_cores`是整个进程的CPU时间/实际时间，也包含宿主和其他插件，不归因到单个二路阶段。
各路仅以slot序号标识，不写入房间号/媒体地址/账号。每个采样器最多2048条数字记录，

该专项另覆盖取帧/识别失败后的重试：原任务令牌和60秒期限不变，丢弃首段、至少间隔2秒重新取新读数，期间副路继续等待确认且静音；仍须通过两次进度/偏移校验，原跨回合拒绝与超时检查保留。失败样本不能成为恢复依据，也不把机制回归当实播成功率证据。

人工验收：确认计时器偏移后短时网络波动应保留偏移；重连/切画质后受影响副路等待复核，主路继续播放，新缓存与两次识别通过后恢复。计时器暂停、归零、换回合或识别失败时应提示重新确认，不自动放行；重新打开计时器对齐仍可沿用原选区。复核期间手动改变偏移或开启自动对齐，迟到结果不得覆盖操作。真实直播验收待用户执行。
